# 17. Köphadlar va ular ustida amallar

## 1-test

### 1 [D]
Qavslarni oçamiz (oldida minus bölsa işoralar almaşadi):
$x^4 + 7x - x^3 - 2x + 5 - x^4 - x^2 - 3x$.
Öxşaş hadlarni ixçamlaymiz: $-x^3 - x^2 + 2x + 5$.

Javob: $-x^3-x^2+2x+5$.

### 2 [C]
Qavslarni oçamiz: $2x^3 - 8x^2 + 6x + 4x - 8 - 2x^3$.
Öxşaş hadlarni ixçamlaymiz: $-8x^2 + 10x - 8$.

Javob: $-8x^2+10x-8$.

### 3 [A]
Kvadratlar ayirmasi formulasi: $(3 + t)(3 - t) = 9 - t^2$, bunda $t = a + b$.
$9 - (a + b)^2 = 9 - a^2 - 2ab - b^2$.

Javob: $9-a^2-2ab-b^2$.

### 4 [B]
Har bölinmani hisoblaymiz:
$(x^4 - 3x^3 + 2x^2) : x = x^3 - 3x^2 + 2x$;
$(2x^3 + x^2 - 4x) : (-x) = -2x^2 - x + 4$.
$x^3 - 3x^2 + 2x - (-2x^2 - x + 4) + x^3 = 2x^3 - x^2 + 3x - 4$.

Javob: $2x^3-x^2+3x-4$.

### 5 [B]
$256 = 2^8$, $16 = 2^4$:
$2^{8(n+1)} : 2^{4(n-2)} = 2^{8n+8-4n+8} = 2^{4n+16}$.

Javob: $2^{4n+16}$.

### 6 [D]
$2x - 2 = 2(x - 1)$, Bezu teoremasiga köra qoldiq $P(1)$ ga teng:
$P(1) = 2 + 1 - 5 + 7 = 5$.

Javob: $5$.

### 7 [C]
Koeffitsiyentlar yiğindisi $x = y = 1$ dagi qiymatga teng:
$a + b + c + d = (1 + 1)(1 - 1 + 1) = 2$.

Javob: $2$.

### 8 [A]
Har raqam har xonada bir martadan qatnaşadi:
$\overline{abc} + \overline{bca} + \overline{cab} = 111(a + b + c) = 111 \cdot 18 = 1998$.

Javob: $1998$.

### 9 [A]
$\overline{abc} - \overline{cba} = (100a + 10b + c) - (100c + 10b + a) = 99(a - c)$.
$99(a - c) = 396$, demak $a - c = 4$.

Javob: $4$.

### 10 [D]
Qavslarni oçamiz: $(a + 9)(b + 3) = ab + 3a + 9b + 27 = ab + 3(a + 3b) + 27$.
$ab + 3 \cdot 8 + 27 = 55$, demak $ab = 4$.

Javob: $4$.

### 11 [C]
$s = m + n$ deb belgilaymiz:
$(s + 3)(s + 7) - (s + 2)(s + 8) = (s^2 + 10s + 21) - (s^2 + 10s + 16) = 5$.

Javob: $5$.

### 12 [B]
Şartdan $a^2 = 2a + 1$. Darajalarni ketma-ket pasaytiramiz:
$a^3 = 2a^2 + a = 5a + 2$;
$a^4 = 5a^2 + 2a = 12a + 5$;
$a^5 = 12a^2 + 5a = 29a + 12$.
$a^5 - 29a = 12$.

Javob: $12$.

### 13 [C]
$t^2 + t + 1 = 0$ ni $(t - 1)$ ga köpaytirsak, $t^3 - 1 = 0$, ya'ni $t^3 = 1$.
$2032 = 3 \cdot 677 + 1$, demak $t^{2032} = t$.
$t^{2032} - t = 0$.

Javob: $0$.

### 14 [C]
$a^2 - 8a = a(a - 8) = a(a - (a + b)) = -ab = -8$.
$b + \dfrac{8}{b} = b + \dfrac{ab}{b} = b + a = 8$.
Köpaytma: $-8 \cdot 8 = -64$.

Javob: $-64$.

## 2-test

### 1 [C]
Qavslarni oçamiz: $x^6 + 5x^2 - x^5 - x^2 - 4 - x^6 - 2x^3 - 3x^2$.
Ixçamlaymiz: $-x^5 - 2x^3 + x^2 - 4$.

Javob: $-x^5-2x^3+x^2-4$.

### 2 [D]
Qavslarni oçamiz: $4x^3 - 12x^2 + 8x + 6x - 12 - 4x^3$.
Ixçamlaymiz: $-12x^2 + 14x - 12$.

Javob: $-12x^2+14x-12$.

### 3 [A]
Kvadratlar ayirmasi: $16 - (m - n)^2 = 16 - (m^2 - 2mn + n^2)$.
$16 - m^2 + 2mn - n^2$.

Javob: $16-m^2+2mn-n^2$.

### 4 [D]
Bölinmalarni hisoblaymiz:
$(2x^5 + x^4 - x^3) : (-x^2) = -2x^3 - x^2 + x$;
$(x^4 - 3x^3 + 2x^2) : x^2 = x^2 - 3x + 2$.
$-2x^3 - x^2 + x - x^2 + 3x - 2 + 2x^3 = -2x^2 + 4x - 2$.

Javob: $-2x^2+4x-2$.

### 5 [B]
$128 = 2^7$, $4 = 2^2$:
$2^{7n+14} : 2^{4n+2} = 2^{3n+12}$.

Javob: $2^{3n+12}$.

### 6 [C]
Bezu teoremasiga köra qoldiq $P(-1)$:
$P(-1) = -4 - 3 - 6 - 8 = -21$.

Javob: $-21$.

### 7 [A]
Koeffitsiyentlar yiğindisi $x = y = 1$ dagi qiymat:
$a + b + c + d = (2 - 1)(1 + 1 + 1) = 3$.

Javob: $3$.

### 8 [B]
$\overline{abc} + \overline{bca} + \overline{cab} = 111(a + b + c) = 111 \cdot 21 = 2331$.

Javob: $2331$.

### 9 [A]
$\overline{abc} - \overline{cba} = 99(a - c) = 495$, demak $a - c = 5$.

Javob: $5$.

### 10 [D]
$(a + 8)(b + 2) = ab + 2a + 8b + 16 = ab + 2(a + 4b) + 16$.
$ab + 18 + 16 = 37$, demak $ab = 3$.

Javob: $3$.

### 11 [B]
$s = a + b$ deb belgilaymiz:
$(s^2 + 13s + 36) - (s^2 + 13s + 30) = 6$.

Javob: $6$.

### 12 [C]
Şartdan $a^2 = a + 2$:
$a^3 = a^2 + 2a = 3a + 2$;
$a^4 = 3a^2 + 2a = 5a + 6$;
$a^5 = 5a^2 + 6a = 11a + 10$.
$a^5 - 11a = 10$.

Javob: $10$.

### 13 [A]
$(t - 1)(t^2 + t + 1) = t^3 - 1 = 0$, demak $t^3 = 1$.
$2050 = 3 \cdot 683 + 1$, demak $t^{2050} = t$ va $t^{2050} - t = 0$.

Javob: $0$.

### 14 [C]
$a^2 - 12a = a(a - (a + b)) = -ab = -12$.
$b + \dfrac{12}{b} = b + \dfrac{ab}{b} = a + b = 12$.
Köpaytma: $-12 \cdot 12 = -144$.

Javob: $-144$.

## 3-test

### 1 [D]
Qavslarni oçamiz: $x^5 + 8x - x^4 - 3x + 2 - x^5 - 2x^2 - 4x$.
Ixçamlaymiz: $-x^4 - 2x^2 + x + 2$.

Javob: $-x^4-2x^2+x+2$.

### 2 [A]
Qavslarni oçamiz: $5x^3 - 5x^2 + 15x + 8x - 12 - 5x^3$.
Ixçamlaymiz: $-5x^2 + 23x - 12$.

Javob: $-5x^2+23x-12$.

### 3 [C]
Kvadratlar ayirmasi: $25 - (p + 2q)^2 = 25 - (p^2 + 4pq + 4q^2)$.

Javob: $25-p^2-4pq-4q^2$.

### 4 [B]
Bölinmalar:
$(3x^4 - x^3 + 2x^2) : x = 3x^3 - x^2 + 2x$;
$(2x^3 - 4x^2 + x) : (-x) = -2x^2 + 4x - 1$.
$3x^3 - x^2 + 2x + 2x^2 - 4x + 1 - 3x^3 = x^2 - 2x + 1$.

Javob: $x^2-2x+1$.

### 5 [C]
$64 = 2^6$, $8 = 2^3$:
$2^{12n-6} : 2^{3n+9} = 2^{9n-15}$.

Javob: $2^{9n-15}$.

### 6 [A]
$3x - 3 = 3(x - 1)$, qoldiq $P(1)$ ga teng:
$P(1) = 1 - 6 + 4 + 9 = 8$.

Javob: $8$.

### 7 [B]
Koeffitsiyentlar yiğindisi $x = y = 1$ dagi qiymat:
$a + b + c + d = (1 - 2)(1 + 1 + 1) = -3$.

Javob: $-3$.

### 8 [D]
$\overline{abc} + \overline{bca} + \overline{cab} = 111(a + b + c) = 111 \cdot 24 = 2664$.

Javob: $2664$.

### 9 [A]
$\overline{abc} - \overline{cba} = 99(a - c) = 594$, demak $a - c = 6$.

Javob: $6$.

### 10 [D]
$(a + 15)(b + 3) = ab + 3a + 15b + 45 = ab + 3(a + 5b) + 45$.
$ab + 33 + 45 = 84$, demak $ab = 6$.

Javob: $6$.

### 11 [B]
$s = p + q$ deb belgilaymiz:
$(s^2 + 16s + 55) - (s^2 + 16s + 48) = 7$.

Javob: $7$.

### 12 [C]
Şartdan $a^2 = 3a + 1$:
$a^3 = 3a^2 + a = 10a + 3$;
$a^4 = 10a^2 + 3a = 33a + 10$;
$a^5 = 33a^2 + 10a = 109a + 33$.
$a^5 - 109a = 33$.

Javob: $33$.

### 13 [A]
$(t - 1)(t^2 + t + 1) = t^3 - 1 = 0$, demak $t^3 = 1$.
$2101 = 3 \cdot 700 + 1$, demak $t^{2101} = t$ va $t^{2101} - t = 0$.

Javob: $0$.

### 14 [B]
$a^2 - 15a = a(a - (a + b)) = -ab = -15$.
$b + \dfrac{15}{b} = b + \dfrac{ab}{b} = a + b = 15$.
Köpaytma: $-15 \cdot 15 = -225$.

Javob: $-225$.
