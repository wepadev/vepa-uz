### 3 [A]

### 4 [C]

$a_6 = a_1 + 5d = -2 + 5 \cdot 2 = -2 + 10 = 8$.

Javob: $8$.

### 5 [B]
Arifmetik progressiyaning xossasidan foydalanamiz: ikki haddan bir xil uzoqlikda turgan had ularning örta arifmetigiga teng: $a_k = \dfrac{a_{k-m} + a_{k+m}}{2}$.

Hisoblaymiz: $a_6 = \dfrac{a_3 + a_9}{2} = \dfrac{-1 + 17}{2} = \dfrac{16}{2} = 8$.

Tekşiruv: $6d = 17 - (-1) = 18$, $d = 3$, $a_6 = -1 + 3 \cdot 3 = 8$.

Javob: $8$.

### 11 [B]

Javob: $-21$.

### 24 [C]

### 4 [A]

Hamma qismga $8$ qöşamiz: $18 \le 5n \le 107$. $5$ ga bölamiz: $3{,}6 \le n \le 21{,}4$.

Bu oraliqdagi natural sonlar: $4, 5, \ldots, 21$. Ularning soni $21 - 4 + 1 = 18$.

Tekşiruv: $a_3 = 7$ bir xonali, $a_4 = 12$ ikki xonali, $a_{21} = 97$, $a_{22} = 102$.

Javob: $18$.

### 17 [A]
Progressiyaning ikki birinçi hadi berilgan. Avval ayirmani topamiz: ikkinçi haddan birinçisini ayiramiz, $d = -33 - (-37) = 4$. Ayirma musbat, demak progressiya ösuvçi: hadlar manfiydan boşlab asta-sekin musbatga ötadi.

Umumiy had formulasi $a_n = a_1 + (n - 1)d$ böyiça: $a_n = -37 + 4(n - 1)$. Hadning manfiy bölişi şartini yozamiz: $-37 + 4(n - 1) < 0$.

Yeçamiz: $4(n - 1) < 37$, $n - 1 < 9{,}25$, $n < 10{,}25$.

$n$ natural son bölgani uçun $n = 1, 2, \ldots, 10$, jami $10$ ta had manfiy. Tekşiruv: $a_{10} = -37 + 36 = -1 < 0$, keyingi had esa $a_{11} = 3 > 0$.

Javob: $10$.

### 18 [D]
Ketma-ketlik rekurrent formula bilan berilgan, birinçi bir neçta hadni hisoblab, qonuniyatni topamiz.

$x_1 = \dfrac12$, $x_2 = 4 : \dfrac12 = 8$, $x_3 = \dfrac48 = \dfrac12$, $x_4 = 8$, ...

Hadlar $\dfrac12, 8, \dfrac12, 8, \ldots$ körinişida takrorlanadi: har ikki ketma-ket hadning yiğindisi $\dfrac12 + 8 = \dfrac{17}{2}$.

$80$ ta hadda $\dfrac{80}{2} = 40$ ta şunday juftlik bor.

Yiğindi: $40 \cdot \dfrac{17}{2} = 20 \cdot 17 = 340$.

Javob: $340$.

### 19 [C]
Ketma-ketlik arifmetik progressiya bölişi uçun qöşni hadlar ayirmasi özgarmas bölişi kerak. Har bir variantda $b_{n+1} - b_n$ ni hisoblaymiz ($a_{n+1} - a_n = d$).

a) $5a_{n+1} - 5a_n = 5d$ — özgarmas, progressiya.

b) $\left(a_{n+1} + \dfrac{n + 1}{3}\right) - \left(a_n + \dfrac{n}{3}\right) = d + \dfrac13$ — özgarmas, progressiya.

c) $a_{2n+4} - a_{2n+2} = 2d$ — özgarmas, progressiya.

d) $(a_{n+1} + a_{n+2}) - (a_n + a_{n+1}) = a_{n+2} - a_n = 2d$ — progressiya.

e) $\dfrac{1}{a_n}$ umuman progressiya emas: masalan $1, 2, 3$ uçun $1, \dfrac12, \dfrac13$, ayirmalar har xil.

Javob: $a, b, c, d$.

### 20 [D]
Hamma ayirmalarni $a_m - a_k = (m - k)d$ formulasi bilan $d$ orqali ifodalaymiz.

Surat: $a_6 - a_1 = 5d$ va $a_5 - a_3 = 2d$. Demak surat $(5d)^2 + (2d)^2 = 25d^2 + 4d^2 = 29d^2$.

Maxrajdagi hadlarni juftlab guruhlaymiz: $(a_{11} - a_4) + (a_9 - a_2) = 7d + 7d = 14d$. Demak maxraj $(14d)^2 = 196d^2$.

Şartga köra $d \ne 0$, $d^2$ ga qisqartiramiz: $\dfrac{29d^2}{196d^2} = \dfrac{29}{196}$. Natija $d$ ga boğliq emas.

Javob: $\dfrac{29}{196}$.

### 21 [B]
Xossadan foydalanamiz: $a_m + a_k = 2a_s$, bunda $s = \dfrac{m + k}{2}$. Bu yerda $\dfrac{8 + 10}{2} = 9$, demak $a_8 + a_{10} = 2a_9$.

Birinçi şartdan: $2a_9 = -24$, bundan $a_9 = -12$.

Ikkinçi şartga qöyamiz: $a_8 \cdot (-12) = 174$, bundan $a_8 = -\dfrac{174}{12} = -\dfrac{29}{2}$.

Qöşni hadlar ma'lum, ayirma ularning farqi: $d = a_9 - a_8 = -12 + \dfrac{29}{2} = \dfrac52$.

Söralgan had $a_8$ dan $5$ qadam oldin: $a_3 = a_8 - 5d = -\dfrac{29}{2} - \dfrac{25}{2} = -\dfrac{54}{2} = -27$.

Javob: $-27$.

### 22 [A]
Xossadan foydalanamiz: $a_m + a_k = 2a_s$, bunda $s = \dfrac{m + k}{2}$ — had raqamlarining örtasi. $\dfrac{6 + 10}{2} = 8$ va $\dfrac{5 + 11}{2} = 8$, demak ikkala yiğindi ham $2a_8$ ga teng.

Ikkinçi şartdan: $2a_8 = -12$, bundan $a_8 = -6$. Demak birinçi şartdagi qavs içidagi $a_5 + a_{11}$ yiğindi ham $-12$ ga teng.

Birinçi şartga qöyamiz: $a_6 \cdot (-12) = 168$, bundan $a_6 = -14$.

Endi ikki had ma'lum. $a_6$ va $a_8$ orasida $2$ qadam bor: $2d = -6 - (-14) = 8$, demak $d = 4$.

Söralgan had $a_8$ dan $5$ qadam keyin turadi: $a_{13} = a_8 + 5d = -6 + 20 = 14$.

Javob: $14$.

### 23 [D]
Bu savolda progressiyaning özi noma'lum, lekin kasr qiymatini xossa yordamida topa olamiz: $a_m + a_k = 2a_s$, bunda $s = \dfrac{m + k}{2}$.

Suratda $\dfrac{3 + 15}{2} = 9$, demak $a_3 + a_{15} = 2a_9$. Unda butun surat $2a_9 + a_9 = 3a_9$.

Maxrajda ham $\dfrac{8 + 10}{2} = 9$, demak $a_8 + a_{10} = 2a_9$.

Şartga köra maxraj nol emas, demak $a_9 \ne 0$ va kasrni qisqartiramiz: $\dfrac{3a_9}{2a_9} = \dfrac32$.

Javob: $\dfrac{3}{2}$.

### 24 [C]
Uçta had $x$ orqali berilgan. Ular orasidagi farqlarni ayirma orqali ifodalaymiz: $a_7 - a_1 = 6d$ va $a_{16} - a_7 = 9d$. Ayirma noma'lum, uni yöqotiş uçun birinçi farqni $3$ ga, ikkinçisini $2$ ga köpaytiramiz, ikkalasi ham $18d$ böladi: $3(a_7 - a_1) = 2(a_{16} - a_7)$.

Farqlarni hisoblaymiz: $a_7 - a_1 = (-x + 17) - (x + 6) = -2x + 11$; $a_{16} - a_7 = \left(2x + \dfrac{19}{2}\right) - (-x + 17) = 3x - \dfrac{15}{2}$.

Tenglama tuzamiz: $3(-2x + 11) = 2\left(3x - \dfrac{15}{2}\right)$, ya'ni $-6x + 33 = 6x - 15$.

$x$ larni bir tomonga yiğamiz: $48 = 12x$, bundan $x = 4$.

Tekşiruv: $a_1 = 10$, $a_7 = 13$, $a_{16} = \dfrac{35}{2}$; ayirma $d = \dfrac12$ bilan hammasi mos keladi.

Javob: $4$.

### 25 [D]
$7$ soni $4$ va $10$ ning öqa örtasida, şuning uçun $a_7$ — $a_4$ va $a_{10}$ ning örta arifmetigi: $a_7 = \dfrac{a_4 + a_{10}}{2}$.

Tenglamani töliq yeçiş şart emas, bizga faqat ildizlar yiğindisi kerak. Viyet teoremasi: $x^2 + px + q = 0$ da $x_1 + x_2 = -p$. Bu yerda $a_4 + a_{10} = 9$.

Demak $a_7 = \dfrac{9}{2}$.

Tekşiruv: ildizlar $11$ va $-2$, örtasi $\dfrac{11 - 2}{2} = \dfrac92$.

Javob: $\dfrac{9}{2}$.
