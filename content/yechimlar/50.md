# 50. Arifmetik progressiya

## 1-test

### 1 [D]
Formulaga $n = 3$ va $n = 5$ ni qöyamiz:
$a_3 = 2\cdot 9 - 3 + 3 = 18$, $a_5 = 2\cdot 25 - 5 + 3 = 48$.
$a_3 + a_5 = 18 + 48 = 66$.

Javob: $66$.

### 2 [A]
Umumiy had formulasi: $a_n = a_1 + (n - 1)d$.
$a_8 = -4 + 7\cdot\dfrac{5}{2} = -4 + \dfrac{35}{2} = \dfrac{27}{2}$.

Javob: $\dfrac{27}{2}$.

### 3 [A]
$a_{11} - a_3 = 8d$:
$8d = 7 - (-5) = 12 \Rightarrow d = \dfrac{3}{2}$.

Javob: $\dfrac{3}{2}$.

### 4 [C]
$a_{10} - a_1 = 9d \Rightarrow 9d = 18 \Rightarrow d = 2$.
$a_6 = a_1 + 5d = -2 + 10 = 8$.

Javob: $8$.

### 5 [B]
$a_6$ had $a_3$ va $a_9$ dan bir xil uzoqlikda, şuning uçun u ularning örta arifmetigi:
$a_6 = \dfrac{a_3 + a_9}{2} = \dfrac{-1 + 17}{2} = 8$.

Javob: $8$.

### 6 [C]
$a_m + a_k = 2a_{(m+k)/2}$ xossasidan:
$a_3 + a_9 = 2a_6 = 10 \Rightarrow a_6 = 5$; $a_8 + a_{14} = 2a_{11} = 30 \Rightarrow a_{11} = 15$.
$5d = 15 - 5 = 10 \Rightarrow d = 2$, $a_{12} = 15 + 2 = 17$.

Javob: $17$.

### 7 [A]
Musbat hadlar: $47 - 4n > 0 \Rightarrow n < \dfrac{47}{4} = 11{,}75$.
$n$ natural son, demak $n = 1, 2, \ldots, 11$.

Javob: $11$.

### 8 [C]
$a_8 - a_3 = 5d \Rightarrow 5d = 15 \Rightarrow d = 3$.
$a_n = a_3 + (n - 3)d = 2 + 3n - 9 = 3n - 7$.

Javob: $a_n = 3n - 7$.

### 9 [B]
$a_n = a_1 + (n - 1)d$:
$21 = -7 + 2(n - 1) \Rightarrow n - 1 = 14 \Rightarrow n = 15$.

Javob: $15$.

### 10 [D]
$a_{20} - a_8 = 12d$, $a_9 - a_5 = 4d$, demak $a_6 = \dfrac{12d}{4d} = 3$.
$a_6 - a_2 = 4d \Rightarrow 4d = 3 - (-1) = 4 \Rightarrow d = 1$.
$a_{15} = a_6 + 9d = 3 + 9 = 12$.

Javob: $12$.

### 11 [B]
$a_7 + a_{13} = a_9 + a_{11} = 2a_{10}$, demak $4a_{10} = -28 \Rightarrow a_{10} = -7$.
$a_6 + a_{14} = 2a_{10}$, şuning uçun $a_6 + a_{10} + a_{14} = 3a_{10} = -21$.

Javob: $-21$.

### 12 [A]
Örta had qolgan ikkitasining örta arifmetigi: $2(5x - 9) = (2x - 4) + (9x - 17)$.
$10x - 18 = 11x - 21 \Rightarrow x = 3$.
$3x - 5 = 9 - 5 = 4$.

Javob: $4$.

### 13 [D]
Şart: $2\sqrt{x + 17} = \sqrt{x + 10} + \sqrt{x + 26}$. Kvadratga kötaramiz:
$4x + 68 = 2x + 36 + 2\sqrt{(x + 10)(x + 26)} \Rightarrow x + 16 = \sqrt{(x + 10)(x + 26)}$.
$x^2 + 32x + 256 = x^2 + 36x + 260 \Rightarrow -4x = 4 \Rightarrow x = -1$.
Tekşiruv: $3, 4, 5$ — arifmetik progressiya.

Javob: $-1$.

### 14 [C]
Hosil bölgan progressiyada $9$ ta had: $a_1 = -4$, $a_9 = 20$.
$8d = 24 \Rightarrow d = 3$. Birinçi joylaştirilgan son: $a_2 = -4 + 3 = -1$.

Javob: $-1$.

### 15 [D]
Progressiyada $n + 2$ ta had, $a_{n+2} = a_1 + (n + 1)d$:
$25 = -3 + 2(n + 1) \Rightarrow n + 1 = 14 \Rightarrow n = 13$.

Javob: $13$.

### 16 [B]
$d = 6$, $a_n = 5 + 6(n - 1) = 6n - 1$.
$10 \le 6n - 1 \le 99 \Rightarrow \dfrac{11}{6} \le n \le \dfrac{100}{6}$, ya'ni $n = 2, 3, \ldots, 16$.
Hadlar soni: $16 - 2 + 1 = 15$.

Javob: $15$.

### 17 [A]
$d = -\dfrac{33}{2} + 18 = \dfrac{3}{2}$.
$a_n = -18 + \dfrac{3}{2}(n - 1) < 0 \Rightarrow n - 1 < 12 \Rightarrow n < 13$.
$n = 1, \ldots, 12$ ($a_{13} = 0$ manfiy emas).

Javob: $12$.

### 18 [C]
$x_1 = 2$, $x_2 = \dfrac{14}{2} = 7$, $x_3 = \dfrac{14}{7} = 2$, ... — hadlar $2, 7$ juftligi bilan takrorlanadi.
$2022$ ta hadda $1011$ ta juftlik: $1011\cdot(2 + 7) = 9099$.

Javob: $9099$.

### 19 [B]
Ketma-ketlik arifmetik progressiya, agar qöşni hadlar ayirmasi özgarmas bölsa.
a) ayirma $-2d$; b) ayirma $d + 5$; c) ayirma $3d$; d) ayirma $2d$ — hammasi özgarmas.
e) $\dfrac{1}{a_n}$, masalan $1, 2, 3$ uçun $1, \dfrac{1}{2}, \dfrac{1}{3}$ — progressiya emas.

Javob: $a, b, c, d$.

### 20 [D]
Ayirmalarni $d$ orqali yozamiz: $a_8 - a_3 = 5d$, $a_6 - a_4 = 2d$.
$a_{10} + a_7 - a_5 - a_3 = (a_{10} - a_5) + (a_7 - a_3) = 5d + 4d = 9d$.
$\dfrac{25d^2 + 4d^2}{81d^2} = \dfrac{29}{81}$.

Javob: $\dfrac{29}{81}$.

### 21 [A]
$a_6 + a_{10} = 2a_8 = 30 \Rightarrow a_8 = 15$.
$a_6 = \dfrac{255}{15} = 17$, $2d = a_8 - a_6 = -2 \Rightarrow d = -1$.
$a_{13} = a_8 + 5d = 15 - 5 = 10$.

Javob: $10$.

### 22 [C]
$a_7 + a_{13} = 2a_{10} = 24 \Rightarrow a_{10} = 12$; $a_6 + a_{14} = 2a_{10} = 24$.
$a_7 \cdot 24 = 432 \Rightarrow a_7 = 18$; $3d = 12 - 18 \Rightarrow d = -2$.
$a_{15} = a_{10} + 5d = 12 - 10 = 2$.

Javob: $2$.

### 23 [B]
$a_5 + a_{15} = 2a_{10}$, demak surat $3a_{10}$; maxraj $a_7 + a_{13} = 2a_{10}$.
$\dfrac{3a_{10}}{2a_{10}} = \dfrac{3}{2}$.

Javob: $\dfrac{3}{2}$.

### 24 [C]
$a_6 - a_2 = 4d$, $a_{14} - a_6 = 8d$, demak $a_{14} - a_6 = 2(a_6 - a_2)$.
$(x - 7) - (-x - 1) = 2\bigl((-x - 1) - (2x + 6)\bigr)$.
$2x - 6 = -6x - 14 \Rightarrow 8x = -8 \Rightarrow x = -1$.

Javob: $-1$.

### 25 [C]
$a_3$ had $a_1$ va $a_5$ ning örta arifmetigi. Viyet teoremasi: $a_1 + a_5 = 2$.
$a_3 = \dfrac{2}{2} = 1$.

Javob: $1$.

### 22 [C]
