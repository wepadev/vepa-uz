# 33. Ildizli ifodalar

## 1-test

### 1 [C]
Qavs oldidagi ildizni har bir hadga köpaytiramiz ($\sqrt{x}\sqrt{y} = \sqrt{xy}$):
$\sqrt{3ab} \cdot \sqrt{3ab} = 3ab$, $\sqrt{3ab} \cdot \sqrt{3b} = \sqrt{9ab^2} = 3b\sqrt{a}$.

Javob: $3ab + 3b\sqrt{a}$.

### 2 [B]
Kvadratlar ayirmasi formulasi: $(u + v)(u - v) = u^2 - v^2$.
$(\sqrt{x})^2 - (3\sqrt{2})^2 = x - 18$.

Javob: $x - 18$.

### 3 [A]
Kublar yiğindisi formulasi: $(u + v)(u^2 - uv + v^2) = u^3 + v^3$, bu yerda $u = \sqrt{a}$, $v = 3$.
$(\sqrt{a})^3 + 3^3 = a\sqrt{a} + 27$.

Javob: $a\sqrt{a} + 27$.

### 4 [D]
Qavslarni hadma-had köpaytiramiz:
$a\sqrt{a} + 3a - 9\sqrt{a} - 27$.

Javob: $a\sqrt{a} + 3a - 9\sqrt{a} - 27$.

### 5 [C]
$a = \sqrt{a} \cdot \sqrt{a}$ bölgani uçun $3a\sqrt{b} = 3\sqrt{ab} \cdot \sqrt{a}$, $3b\sqrt{a} = 3\sqrt{ab} \cdot \sqrt{b}$.
Umumiy köpaytuvçini çiqaramiz: $3\sqrt{ab}(\sqrt{a} + \sqrt{b})$.

Javob: $3\sqrt{ab}(\sqrt{a} + \sqrt{b})$.

### 6 [C]
$16a = (4\sqrt{a})^2$, $9 = 3^2$ (bunda $a \ge 0$). Kvadratlar ayirmasi:
$16a - 9 = (4\sqrt{a} - 3)(4\sqrt{a} + 3)$.

Javob: $(4\sqrt{a} - 3)(4\sqrt{a} + 3)$.

### 7 [D]
$3$ ni çiqarib, guruhlaymiz: $3\bigl[(a\sqrt{a} + b\sqrt{b}) + \sqrt{ab}(\sqrt{a} + \sqrt{b})\bigr]$.
Kublar yiğindisi: $a\sqrt{a} + b\sqrt{b} = (\sqrt{a} + \sqrt{b})(a - \sqrt{ab} + b)$.
$3(\sqrt{a} + \sqrt{b})(a - \sqrt{ab} + b + \sqrt{ab}) = 3(a + b)(\sqrt{a} + \sqrt{b})$.

Javob: $3(a + b)(\sqrt{a} + \sqrt{b})$.

### 8 [D]
Suratni kvadratlar ayirmasi sifatida yozamiz: $b - 16 = (\sqrt{b} - 4)(\sqrt{b} + 4)$.
$\sqrt{b} - 4$ ga qisqartiramiz: $\sqrt{b} + 4$.

Javob: $\sqrt{b} + 4$.

### 9 [A]
Kublar ayirmasi: $a\sqrt{a} - 64 = (\sqrt{a})^3 - 4^3 = (\sqrt{a} - 4)(a + 4\sqrt{a} + 16)$.
Qisqartirgaç: $a + 4\sqrt{a} + 16$.

Javob: $a + 4\sqrt{a} + 16$.

### 10 [A]
Birinçi kasr: $\dfrac{2(\sqrt{x} - \sqrt{3})(\sqrt{x} + \sqrt{3})}{\sqrt{x} + \sqrt{3}} = 2(\sqrt{x} - \sqrt{3})$.
Ikkinçi kasr (kublar ayirmasi): $\dfrac{(\sqrt{x} - \sqrt{3})(x + \sqrt{3x} + 3)}{x + \sqrt{3x} + 3} = \sqrt{x} - \sqrt{3}$.
Yiğindi: $3(\sqrt{x} - \sqrt{3})$.

Javob: $3(\sqrt{x} - \sqrt{3})$.

### 11 [B]
Har bir ifodani köpaytuvçilarga ajratamiz: $c + 4\sqrt{c} + 4 = (\sqrt{c} + 2)^2$, $c + \sqrt{c} = \sqrt{c}(\sqrt{c} + 1)$, $c - 8\sqrt{c} + 16 = (\sqrt{c} - 4)^2$, $c + 2\sqrt{c} = \sqrt{c}(\sqrt{c} + 2)$.
Bölişni teskarisiga köpaytiriş bilan almaştiramiz:
$\dfrac{(\sqrt{c} + 2)^2}{3(\sqrt{c} + 1)} \cdot \dfrac{\sqrt{c}(\sqrt{c} + 1)}{(\sqrt{c} - 4)^2} \cdot \dfrac{6(\sqrt{c} - 4)}{\sqrt{c}(\sqrt{c} + 2)} = \dfrac{2(\sqrt{c} + 2)}{\sqrt{c} - 4}$.

Javob: $\dfrac{2(\sqrt{c} + 2)}{\sqrt{c} - 4}$.

### 12 [B]
$\sqrt{t^2} = |t|$. Berilgan oraliqda $x - 4 \le 0$, $x + 7 \ge 0$.
$|x - 4| + |x + 7| = (4 - x) + (x + 7) = 11$.

Javob: $11$.

### 13 [C]
Surat va maxrajni $\sqrt{a^2 - 16}$ ga köpaytiramiz:
$\dfrac{(a + 4)\sqrt{a^2 - 16}}{(a - 4)(a + 4)} = \dfrac{\sqrt{a^2 - 16}}{a - 4}$.

Javob: $\dfrac{\sqrt{a^2 - 16}}{a - 4}$.

### 14 [A]
Qöşma ifoda $5 + \sqrt{2x + 1}$ ga köpaytiramiz:
maxraj $25 - (2x + 1) = 24 - 2x$.
Natija: $\dfrac{3(5 + \sqrt{2x + 1})}{24 - 2x}$.

Javob: $\dfrac{3(5 + \sqrt{2x + 1})}{24 - 2x}$.

### 15 [B]
Surat va maxrajni $\sqrt{3} + \sqrt{5} + \sqrt{8}$ ga köpaytiramiz:
maxraj $(\sqrt{3} + \sqrt{5})^2 - 8 = 2\sqrt{15}$.
$\dfrac{(\sqrt{3} + \sqrt{5} + 2\sqrt{2})\sqrt{15}}{30} = \dfrac{3\sqrt{5} + 5\sqrt{3} + 2\sqrt{30}}{30}$.

Javob: $\dfrac{3\sqrt{5} + 5\sqrt{3} + 2\sqrt{30}}{30}$.

### 16 [A]
$t = \sqrt{a}$ belgilaymiz: $\dfrac{t - 1}{2(t + 1)} - \dfrac{t + 1}{5(t - 1)} + \dfrac{7t - 3}{5(t^2 - 1)}$.
Umumiy maxraj $10(t^2 - 1)$, surat: $5(t - 1)^2 - 2(t + 1)^2 + 2(7t - 3) = 3t^2 - 3$.
$\dfrac{3(t^2 - 1)}{10(t^2 - 1)} = \dfrac{3}{10}$.

Javob: $\dfrac{3}{10}$.

### 17 [D]
$\sqrt{x^{-1}} = \dfrac{1}{\sqrt{x}}$. Birinçi kasrni $\sqrt{xy}$ ga köpaytiramiz: $\dfrac{\sqrt{x} - \sqrt{y}}{\sqrt{y} + \sqrt{x}}$.
Köpaytma: $\dfrac{\sqrt{x} - \sqrt{y}}{\sqrt{x} + \sqrt{y}} \cdot \dfrac{\sqrt{x} + \sqrt{y}}{\sqrt{x} - \sqrt{y}} = 1$.

Javob: $1$.

### 18 [B]
Birinçi qavs: $\dfrac{x - 9}{6\sqrt{x}}$, uning kvadrati $\dfrac{(x - 9)^2}{36x}$.
Ikkinçi qavs: $\dfrac{(\sqrt{x} - 3)^2 - (\sqrt{x} + 3)^2}{x - 9} = \dfrac{-12\sqrt{x}}{x - 9}$.
Köpaytma: $-\dfrac{12\sqrt{x}(x - 9)}{36x} = -\dfrac{x - 9}{3\sqrt{x}}$; unga $\dfrac{x - 9}{3\sqrt{x}}$ qöşilsa $0$.

Javob: $0$.

### 19 [C]
$(a^m)^n = a^{mn}$. Daraja körsatkiçlari: $(\sqrt{18} + 4)(\sqrt{18} - 4) = 18 - 16 = 2$ va $(6 + \sqrt{34})(6 - \sqrt{34}) = 36 - 34 = 2$.
$(5 - \sqrt{2})^2 + (5 + \sqrt{2})^2 = 2(25 + 2) = 54$.

Javob: $54$.

### 20 [A]
Köpaytuvçilarni juftlaymiz: $x(x - 3) \cdot (x - 1)(x - 2) = (x^2 - 3x)(x^2 - 3x + 2)$.
$x - \dfrac{3}{2} = \sqrt{3}$, kvadratga oşiramiz: $x^2 - 3x + \dfrac{9}{4} = 3$, ya'ni $x^2 - 3x = \dfrac{3}{4}$.
Natija: $\dfrac{3}{4} \cdot \dfrac{11}{4} = \dfrac{33}{16}$.

Javob: $\dfrac{33}{16}$.

## 2-test

### 3 [D]

### 4 [D]

Javob: $a\sqrt{a} + 4a - 16\sqrt{a} - 64$.

### 5 [A]

Javob: $4\sqrt{ab}(\sqrt{a} + \sqrt{b})$.

### 6 [C]
$25a - 16 = (5\sqrt{a})^2 - 4^2 = (5\sqrt{a} - 4)(5\sqrt{a} + 4)$.

Javob: $(5\sqrt{a} - 4)(5\sqrt{a} + 4)$.

### 7 [B]
$4\bigl[(a\sqrt{a} + b\sqrt{b}) + \sqrt{ab}(\sqrt{a} + \sqrt{b})\bigr] = 4(\sqrt{a} + \sqrt{b})(a - \sqrt{ab} + b + \sqrt{ab})$.

Javob: $4(a + b)(\sqrt{a} + \sqrt{b})$.

### 8 [A]

Javob: $\sqrt{b} + 5$.

### 9 [D]
Kublar ayirmasi: $a\sqrt{a} - 125 = (\sqrt{a} - 5)(a + 5\sqrt{a} + 25)$.
Qisqartirgaç: $a + 5\sqrt{a} + 25$.

Javob: $a + 5\sqrt{a} + 25$.

### 10 [C]
Birinçi kasr: $\dfrac{4(x - 5)}{\sqrt{x} + \sqrt{5}} = 4(\sqrt{x} - \sqrt{5})$.
Ikkinçi kasr (kublar ayirmasi): $\sqrt{x} - \sqrt{5}$.
Yiğindi: $5(\sqrt{x} - \sqrt{5})$.

Javob: $5(\sqrt{x} - \sqrt{5})$.

### 11 [B]
$c + 6\sqrt{c} + 9 = (\sqrt{c} + 3)^2$, $c + 2\sqrt{c} = \sqrt{c}(\sqrt{c} + 2)$, $c - 2\sqrt{c} + 1 = (\sqrt{c} - 1)^2$, $c + 3\sqrt{c} = \sqrt{c}(\sqrt{c} + 3)$.
$\dfrac{(\sqrt{c} + 3)^2}{2(\sqrt{c} + 2)} \cdot \dfrac{\sqrt{c}(\sqrt{c} + 2)}{(\sqrt{c} - 1)^2} \cdot \dfrac{6(\sqrt{c} - 1)}{\sqrt{c}(\sqrt{c} + 3)} = \dfrac{3(\sqrt{c} + 3)}{\sqrt{c} - 1}$.

Javob: $\dfrac{3(\sqrt{c} + 3)}{\sqrt{c} - 1}$.

### 12 [B]
$\sqrt{t^2} = |t|$. Oraliqda $x - 6 \le 0$, $x + 2 \ge 0$:
$(6 - x) + (x + 2) = 8$.

Javob: $8$.

### 13 [A]
Surat va maxrajni $\sqrt{a^2 - 25}$ ga köpaytiramiz:
$\dfrac{(a + 5)\sqrt{a^2 - 25}}{(a - 5)(a + 5)} = \dfrac{\sqrt{a^2 - 25}}{a - 5}$.

Javob: $\dfrac{\sqrt{a^2 - 25}}{a - 5}$.

### 14 [C]
Qöşma ifoda $6 + \sqrt{5x + 1}$ ga köpaytiramiz: maxraj $36 - 5x - 1 = 35 - 5x$.

Javob: $\dfrac{4(6 + \sqrt{5x + 1})}{35 - 5x}$.

### 15 [D]
$\sqrt{9} = 3$. Surat va maxrajni $\sqrt{2} + \sqrt{7} + 3$ ga köpaytiramiz: maxraj $(\sqrt{2} + \sqrt{7})^2 - 9 = 2\sqrt{14}$.
$\dfrac{(\sqrt{2} + \sqrt{7} + 3)\sqrt{14}}{28} = \dfrac{2\sqrt{7} + 7\sqrt{2} + 3\sqrt{14}}{28}$.

Javob: $\dfrac{2\sqrt{7} + 7\sqrt{2} + 3\sqrt{14}}{28}$.

### 16 [C]
$t = \sqrt{a}$: $\dfrac{t - 1}{4(t + 1)} - \dfrac{t + 1}{6(t - 1)} + \dfrac{10t - 2}{12(t^2 - 1)}$.
Umumiy maxraj $12(t^2 - 1)$, surat: $3(t - 1)^2 - 2(t + 1)^2 + 10t - 2 = t^2 - 1$.
Natija: $\dfrac{1}{12}$.

Javob: $\dfrac{1}{12}$.

### 17 [B]
$\sqrt{a^{-2}} = \dfrac{1}{a}$ ($a > 0$). Birinçi kasrni $ab$ ga köpaytiramiz: $\dfrac{b - a}{b + a}$.
$\dfrac{b - a}{a + b} \cdot \dfrac{a + b}{a - b} = -1$.

Javob: $-1$.

### 18 [A]
Birinçi qavs: $\dfrac{\sqrt{x}}{8} - \dfrac{2}{\sqrt{x}} = \dfrac{x - 16}{8\sqrt{x}}$, kvadrati $\dfrac{(x - 16)^2}{64x}$.
Ikkinçi qavs: $\dfrac{-16\sqrt{x}}{x - 16}$.
Köpaytma: $-\dfrac{x - 16}{4\sqrt{x}}$; unga $\dfrac{x - 16}{4\sqrt{x}}$ qöşilsa $0$.

Javob: $0$.

### 19 [A]
Daraja körsatkiçlari: $27 - 25 = 2$ va $49 - 47 = 2$.
$(6 - \sqrt{5})^2 + (6 + \sqrt{5})^2 = 2(36 + 5) = 82$.

Javob: $82$.

### 20 [C]
$(x^2 - 3x)(x^2 - 3x + 2)$ körinişda yozamiz.
$x - \dfrac{3}{2} = \dfrac{\sqrt{13}}{2}$, kvadratga oşiramiz: $x^2 - 3x + \dfrac{9}{4} = \dfrac{13}{4}$, $x^2 - 3x = 1$.
Natija: $1 \cdot 3 = 3$.

Javob: $3$.
