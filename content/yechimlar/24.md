# 24. Algebraik kasrlar (2-qism)

## 1-test

### 1 [B]
Avval birinçi qavsdagi ayirmani hisoblaymiz, keyin ikkinçi qavsni soddalaştirib, köpaytiramiz.

Birinçi qavs. Maxrajlarni soliştiramiz: $a^2 - b^2 = (a - b)(a + b)$, demak umumiy maxraj $(a - b)(a + b)$. Birinçi kasrga qöşimça köpaytuvçi $(a - b)$:
$\dfrac{5(a - b) - (a - 9b)}{(a - b)(a + b)} = \dfrac{5a - 5b - a + 9b}{(a - b)(a + b)} = \dfrac{4a + 4b}{(a - b)(a + b)}$.

Suratda $4(a + b)$, uni maxrajdagi $(a + b)$ bilan qisqartiramiz: $\dfrac{4}{a - b}$.

Ikkinçi qavs: $\dfrac{1}{b^2} - \dfrac{1}{a^2} = \dfrac{a^2 - b^2}{a^2b^2} = \dfrac{(a - b)(a + b)}{a^2b^2}$.

Köpaytiramiz: $\dfrac{4}{a - b} \cdot \dfrac{(a - b)(a + b)}{a^2b^2} = \dfrac{4(a + b)}{a^2b^2} = \dfrac{4a + 4b}{a^2b^2}$.

Javob: $\dfrac{4a + 4b}{a^2b^2}$.

### 2 [A]
Birinçi qavsdagi kasrlarni qisqa köpaytiriş formulalari yordamida qisqartiramiz, keyin ayiramiz.

Birinçi kasr: $\dfrac{x^2 - 9y^2}{x - 3y} = \dfrac{(x - 3y)(x + 3y)}{x - 3y} = x + 3y$.

Ikkinçi kasr: kublar ayirmasi $x^3 - 27y^3 = (x - 3y)(x^2 + 3xy + 9y^2)$, demak $\dfrac{x^3 - 27y^3}{x^2 - 9y^2} = \dfrac{x^2 + 3xy + 9y^2}{x + 3y}$.

Ayirma: $\dfrac{(x + 3y)^2 - (x^2 + 3xy + 9y^2)}{x + 3y} = \dfrac{x^2 + 6xy + 9y^2 - x^2 - 3xy - 9y^2}{x + 3y} = \dfrac{3xy}{x + 3y}$.

Ikkinçi qavs: $\dfrac{1}{x} + \dfrac{1}{3y} = \dfrac{3y + x}{3xy}$.

Köpaytiramiz: $\dfrac{3xy}{x + 3y} \cdot \dfrac{x + 3y}{3xy} = 1$.

Bu misolda asosiy qadam — kvadratlar ayirmasi va kublar ayirmasi formulalarini tanib, kasrlarni avval qisqartiriş. Ikkinçi qavs aynan birinçi qavs natijasining teskarisi bölib çiqdi, şuning uçun köpaytma birga teng böldi va javob öznaliklarga boğliq emas.

Javob: $1$.

### 3 [C]
Bu kasr içida kasr ("köp qavatli kasr"). Avval suratni bitta kasrga keltiramiz, keyin maxrajga bölamiz.

Surat: umumiy maxraj $(a + b)(a - b)$. $\dfrac{1}{a + b} + \dfrac{4}{a - b} = \dfrac{(a - b) + 4(a + b)}{(a + b)(a - b)} = \dfrac{5a + 3b}{(a + b)(a - b)}$.

Endi bölamiz. Kasrga bölish — teskari kasrga köpaytiriş:
$\dfrac{5a + 3b}{(a + b)(a - b)} \cdot \dfrac{a + b}{5a + 3b}$.

$(5a + 3b)$ va $(a + b)$ qisqaradi, $\dfrac{1}{a - b}$ qoladi.

Javob: $\dfrac{1}{a - b}$.

### 4 [D]
Qavs içidagi kasrlarni umumiy maxrajga keltirib qöşamiz, keyin bölamiz.

Umumiy maxraj $(x + 3)(x + 4)(x + 5)$. Birinçi kasrga qöşimça köpaytuvçi $(x + 5)$, ikkinçisiga $(x + 3)$:
$\dfrac{(x + 5) + (x + 3)}{(x + 3)(x + 4)(x + 5)} = \dfrac{2x + 8}{(x + 3)(x + 4)(x + 5)}$.

Suratda $2x + 8 = 2(x + 4)$, $(x + 4)$ qisqaradi: $\dfrac{2}{(x + 3)(x + 5)}$.

$\dfrac{2}{x + 3}$ ga bölamiz, ya'ni $\dfrac{x + 3}{2}$ ga köpaytiramiz: $\dfrac{2}{(x + 3)(x + 5)} \cdot \dfrac{x + 3}{2} = \dfrac{1}{x + 5}$.

Javob: $\dfrac{1}{x + 5}$.

### 5 [B]
Avval qavs içidagi kasrni soddalaştiramiz, keyin $-1$ darajani qöllaymiz.

Qavs içidagi surat — kvadratlar ayirmasi: $(a - 5)^2 - 5^2 = (a - 5 - 5)(a - 5 + 5) = (a - 10) \cdot a$. Maxraj: $a^2 - 5a = a(a - 5)$. Kasr: $\dfrac{a(a - 10)}{a(a - 5)} = \dfrac{a - 10}{a - 5}$.

$-1$ daraja kasrni ağdaradi: $\dfrac{a - 5}{a - 10}$.

Köpaytiramiz: $\dfrac{a - 5}{a - 10} \cdot \dfrac{a - 10}{(a - 5)(a + 5)} = \dfrac{1}{a + 5}$.

Ayiramiz: $\dfrac{1}{a + 5} - \dfrac{a + 6}{a + 5} = \dfrac{1 - a - 6}{a + 5} = \dfrac{-(a + 5)}{a + 5} = -1$.

Esda tutamiz: kasrning $-1$ darajasi uni ağdariş, ya'ni surat va maxrajning örnini almaştiriş demakdir. Qisqartiriş faqat köpaytuvçilar orasida bajariladi, şuning uçun avval har bir surat va maxrajni köpaytuvçilarga ajratdik, keyingina bir xil qavslarni qisqartirdik.

Javob: $-1$.

### 6 [A]
Suratdagi manfiy darajalarni kasr körinişida yozamiz: $a^{-1} = \dfrac{1}{a}$, $a^{-2} = \dfrac{1}{a^2}$.

Surat: $1 - \dfrac{3}{a} + \dfrac{9}{a^2}$. Umumiy maxraj $a^2$: $\dfrac{a^2 - 3a + 9}{a^2}$.

Endi butun kasr: $\dfrac{a^2 - 3a + 9}{a^2} : (a^2 - 3a + 9) = \dfrac{a^2 - 3a + 9}{a^2} \cdot \dfrac{1}{a^2 - 3a + 9}$.

Bir xil uçhad qisqaradi va $\dfrac{1}{a^2}$ qoladi.

E'tibor bering: suratni $a^2$ ga köpaytirganimizda aynan maxrajdagi ifoda hosil böldi — bu misolning asosiy fikri.

Javob: $\dfrac{1}{a^2}$.

### 7 [D]
Avval köp qavatli kasrlarni soddalaştiramiz, keyin ayiramiz va bölamiz.

Birinçi had: $1 - \dfrac{9b^2}{a^2} = \dfrac{a^2 - 9b^2}{a^2}$, demak $\dfrac{a}{1 - \frac{9b^2}{a^2}} = \dfrac{a^3}{a^2 - 9b^2}$.

Ikkinçi had: $\dfrac{a^2}{9b^2} - 1 = \dfrac{a^2 - 9b^2}{9b^2}$, demak $\dfrac{3b}{\ldots} = \dfrac{27b^3}{a^2 - 9b^2}$.

Ayirma: $\dfrac{a^3 - 27b^3}{a^2 - 9b^2} = \dfrac{(a - 3b)(a^2 + 3ab + 9b^2)}{(a - 3b)(a + 3b)} = \dfrac{a^2 + 3ab + 9b^2}{a + 3b}$.

Böluvçi: $\dfrac{1}{a^2} + \dfrac{1}{3ab} + \dfrac{1}{9b^2} = \dfrac{9b^2 + 3ab + a^2}{9a^2b^2}$.

Bölamiz: $\dfrac{a^2 + 3ab + 9b^2}{a + 3b} \cdot \dfrac{9a^2b^2}{a^2 + 3ab + 9b^2} = \dfrac{9a^2b^2}{a + 3b}$.

Köp qavatli kasrni soddalaştirişda biz pastki kasrning maxrajini yuqoriga köpaytuvçi qilib çiqaramiz. Keyin kublar ayirmasi formulasi va kvadratlar ayirmasi formulasi umumiy köpaytuvçini körsatdi, böluvçidagi uçhad esa aynan şu uçhadga teng bölgani uçun qisqarib ketdi.

Javob: $\dfrac{9a^2b^2}{a + 3b}$.

### 8 [B]
$t = \dfrac{1}{2{,}5}$ deb belgilaymiz. Unda $\dfrac{1}{2{,}5^3} = t^3$, $\dfrac{1}{6{,}25} = \dfrac{1}{2{,}5^2} = t^2$, $\dfrac{3}{2{,}5} = 3t$.

Kasr: $\dfrac{t^3 + 27}{t^2 - 3t + 9}$.

Surat — kublar yiğindisi: $t^3 + 3^3 = (t + 3)(t^2 - 3t + 9)$. Maxraj aynan ikkinçi köpaytuvçi, qisqaradi.

Natija: $t + 3 = \dfrac{1}{2{,}5} + 3 = 0{,}4 + 3 = 3{,}4 = \dfrac{17}{5}$.

Bu misolda kasrli sonlar bilan töğridan-töğri hisoblaş juda noqulay böladi. Yangi öznaliq kiritib, biz ifodani kublar yiğindisi formulasiga keltirdik: maxraj aynan toliqmas kvadrat bölgani uçun kasr bitta qöşiluvçiga qisqardi va oxirida faqat bitta oddiy qöşiş qoldi.

Javob: $\dfrac{17}{5}$.

### 9 [C]
Avval kasrni soddalaştiramiz. Surat va maxrajni $m^2$ ga köpaytiramiz, şunda manfiy darajalar yöqoladi.

$\dfrac{m^{-2} - m}{m^{-1} - 1} = \dfrac{1 - m^3}{m - m^2}$.

Surat — kublar ayirmasi: $1 - m^3 = (1 - m)(1 + m + m^2)$. Maxraj: $m - m^2 = m(1 - m)$.

$(1 - m)$ ni qisqartiramiz: $\dfrac{1 + m + m^2}{m} = \dfrac{1}{m} + 1 + m$.

Şartdan $m + \dfrac{1}{m} = 6$, demak qiymat $6 + 1 = 7$.

Manfiy darajalardan qutuliş uçun surat va maxrajni bir xil songa köpaytirdik, bu kasr qiymatini özgartirmaydi. Kublar ayirmasini köpaytuvçilarga ajratib, umumiy qavsni qisqartirdik va natija aynan şartda berilgan yiğindi orqali ifodalandi, şuning uçun $m$ ning özini topiş şart emas.

Javob: $7$.

### 10 [C]
Avval ifodani soddalaştiramiz, keyin qiymatlarni qöyamiz.

Birinçi qavsni umumiy maxraj $abc$ ga keltiramiz: $\dfrac{a^2 + b^2 + c^2 + 2bc + 2ac + 2ab}{abc} = \dfrac{(a + b + c)^2}{abc}$. Bu yerda uç had yiğindisining kvadrati formulasini taniymiz.

Ikkinçi qavs: $\dfrac{1}{ab} + \dfrac{1}{bc} + \dfrac{1}{ca} = \dfrac{c + a + b}{abc}$, uning kvadrati $\dfrac{(a + b + c)^2}{(abc)^2}$.

Bölamiz: $\dfrac{(a + b + c)^2}{abc} \cdot \dfrac{(abc)^2}{(a + b + c)^2} = abc$.

Qöyamiz: $abc = \dfrac{1}{6} \cdot 3 \cdot 10 = 5$.

Javob: $5$.

### 11 [D]
Har bir qavsni bitta kasrga keltiramiz va $abc = 10$ dan foydalanamiz.

Birinçi qavs: $a - \dfrac{2}{bc} = \dfrac{abc - 2}{bc} = \dfrac{10 - 2}{bc} = \dfrac{8}{bc}$.

Ikkinçi qavs: $b - \dfrac{5}{ac} = \dfrac{abc - 5}{ac} = \dfrac{5}{ac}$.

Uçinçi qavs: $c + \dfrac{5}{ab} = \dfrac{abc + 5}{ab} = \dfrac{15}{ab}$.

Köpaytiramiz: $\dfrac{8 \cdot 5 \cdot 15}{bc \cdot ac \cdot ab} = \dfrac{600}{(abc)^2} = \dfrac{600}{100} = 6$.

Har bir qavsda öznaliqni kasr bilan birlaştiriş uçun uni umumiy maxrajga keltirdik, şunda suratda aynan $abc$ köpaytma paydo böldi va uning qiymatini töğridan-töğri qöydik. Maxrajlarning köpaytmasi esa yana $abc$ ning kvadrati bölgani uçun javob bitta songa aylandi.

Javob: $6$.

### 12 [D]
Kasrlarni çapdan önga ketma-ket birlaştiramiz. Har safar ikki kasrning maxrajlari $a - b$ va $a + b$ körinişida bölgani uçun umumiy maxraj kvadratlar ayirmasi $a^2 - b^2$ böladi, şu sababli hisob tez qisqaradi.

Birinçi ikki kasr: $\dfrac{1}{4 - x} - \dfrac{1}{4 + x} = \dfrac{(4 + x) - (4 - x)}{16 - x^2} = \dfrac{2x}{16 - x^2}$.

Uçinçisini ayiramiz: $\dfrac{2x}{16 - x^2} - \dfrac{2x}{16 + x^2} = \dfrac{2x \cdot 2x^2}{256 - x^4} = \dfrac{4x^3}{256 - x^4}$.

Törtinçisini ayiramiz: $\dfrac{4x^3}{256 - x^4} - \dfrac{4x^3}{256 + x^4} = \dfrac{4x^3 \cdot 2x^4}{65536 - x^8} = \dfrac{8x^7}{65536 - x^8}$.

Ikkinçi qavs: $1 - \dfrac{65536}{x^8} = \dfrac{x^8 - 65536}{x^8}$. Köpaytirsak: $\dfrac{8x^7}{65536 - x^8} \cdot \dfrac{-(65536 - x^8)}{x^8} = -\dfrac{8}{x}$.

$x = 40$ da: $-\dfrac{8}{40} = -\dfrac{1}{5}$.

Javob: $-\dfrac{1}{5}$.

### 13 [C]
Har bir qavsni bitta kasrga keltiramiz: $x + \dfrac{1}{y} = \dfrac{xy + 1}{y}$, $y + \dfrac{1}{x} = \dfrac{xy + 1}{x}$.

Şartdan $xy + 1 = 6 + 1 = 7$. Demak qavslar $\dfrac{7}{y}$ va $\dfrac{7}{x}$.

Kvadratlar yiğindisi: $\dfrac{49}{y^2} + \dfrac{49}{x^2} = \dfrac{49(x^2 + y^2)}{x^2y^2}$.

$x^2 + y^2 = (x + y)^2 - 2xy = 25 - 12 = 13$, $x^2y^2 = 36$.

Natija: $\dfrac{49 \cdot 13}{36} = \dfrac{637}{36}$.

Bu misolda $x$ va $y$ ning özini topiş kerak emas. Biz faqat ularning yiğindisi va köpaytmasidan foydalandik: kvadratlar yiğindisini yiğindining kvadratidan ikkilangan köpaytmani ayiriş orqali topdik, maxrajdagi köpaytmaning kvadrati esa şartdan darhol çiqdi.

Javob: $\dfrac{637}{36}$.

### 14 [A]
Maxraj $x^2 - 16 = (x - 4)(x + 4)$. Kasr qisqarişi uçun surat ham $(x - 4)$ yoki $(x + 4)$ ga bölinişi kerak, ya'ni $x = 4$ yoki $x = -4$ suratning ildizi bölişi kerak.

$x = 4$ ni suratga qöyamiz: $16 + 4m + 8 = 0$, bundan $4m = -24$, $m = -6$. Tekşiruv: $x^2 - 6x + 8 = (x - 4)(x - 2)$.

$x = -4$ ni qöyamiz: $16 - 4m + 8 = 0$, bundan $m = 6$. Tekşiruv: $x^2 + 6x + 8 = (x + 4)(x + 2)$.

Demak $m \in \{-6; 6\}$.

Javob: $\{-6; 6\}$.

### 15 [B]
Har bir qöşiluvçini ikki kasrning ayirmasi sifatida yozamiz: $\dfrac{1}{k(k + 1)} = \dfrac{1}{k} - \dfrac{1}{k + 1}$. Tekşiruv: $\dfrac{(k + 1) - k}{k(k + 1)} = \dfrac{1}{k(k + 1)}$.

Yiğindi: $\left(\dfrac{1}{12} - \dfrac{1}{13}\right) + \left(\dfrac{1}{13} - \dfrac{1}{14}\right) + \ldots + \left(\dfrac{1}{119} - \dfrac{1}{120}\right)$.

Örtadagi hadlar juft-juft qisqarib ketadi, faqat birinçi va oxirgi qoladi: $\dfrac{1}{12} - \dfrac{1}{120}$.

Hisoblaymiz: $\dfrac{10}{120} - \dfrac{1}{120} = \dfrac{9}{120} = \dfrac{3}{40}$.

Bu usul teleskopik yiğindi deb ataladi: har bir qöşiluvçining ikkinçi kasri keyingi qöşiluvçining birinçi kasri bilan qarama-qarşi işorali böladi va ular yöqoladi. Natijada uzun yiğindidan faqat eng birinçi va eng oxirgi kasrlar qoladi, qolgan hisob oson.

Javob: $\dfrac{3}{40}$.

### 16 [A]
Maxrajdagi köpaytuvçilar $3$ ga farq qiladi. Şuning uçun $\dfrac{1}{k(k + 3)} = \dfrac{1}{3}\left(\dfrac{1}{k} - \dfrac{1}{k + 3}\right)$, demak $\dfrac{6}{k(k + 3)} = 2\left(\dfrac{1}{k} - \dfrac{1}{k + 3}\right)$.

Yiğindi: $2\left(\dfrac{1}{2} - \dfrac{1}{5} + \dfrac{1}{5} - \dfrac{1}{8} + \ldots + \dfrac{1}{74} - \dfrac{1}{77}\right)$.

Örtadagi hadlar qisqaradi: $2\left(\dfrac{1}{2} - \dfrac{1}{77}\right)$.

Hisoblaymiz: $2 \cdot \dfrac{77 - 2}{154} = 2 \cdot \dfrac{75}{154} = \dfrac{75}{77}$.

Maxrajdagi köpaytuvçilar orasidagi farq birdan katta bölganda, ikki kasr ayirmasi suratda şu farqni beradi, şuning uçun oldiga tegişli koeffitsiyent qöydik. Keyin teleskopik yiğindidagi kabi örtadagi barça kasrlar juft-juft qisqarib, faqat birinçi va oxirgisi qoldi.

Javob: $\dfrac{75}{77}$.

### 17 [C]
Birinçi had $\dfrac{2}{3}$ ni alohida qoldiramiz, qolgan yiğindini teleskopik usulda hisoblaymiz.

Maxrajdagi köpaytuvçilar $5$ ga farq qiladi: $\dfrac{5}{k(k + 5)} = \dfrac{1}{k} - \dfrac{1}{k + 5}$.

Yiğindi: $\dfrac{1}{2} - \dfrac{1}{7} + \dfrac{1}{7} - \dfrac{1}{12} + \ldots + \dfrac{1}{57} - \dfrac{1}{62} = \dfrac{1}{2} - \dfrac{1}{62} = \dfrac{31 - 1}{62} = \dfrac{30}{62} = \dfrac{15}{31}$.

Endi $\dfrac{2}{3}$ ni qöşamiz: $\dfrac{2}{3} + \dfrac{15}{31} = \dfrac{62 + 45}{93} = \dfrac{107}{93}$.

Birinçi had boşqa qöşiluvçilarga öxşamagani uçun uni alohida hisobladik. Qolgan qöşiluvçilarda maxrajdagi köpaytuvçilar farqi suratga teng, demak har biri ikki kasr ayirmasiga aylanadi va örtadagi kasrlar qisqarib ketadi. Oxirida ikkala qismni umumiy maxrajda qöşdik.

Javob: $\dfrac{107}{93}$.

### 18 [D]
Ifodani soddalaştiramiz, şunda hisob juda osonlaşadi.

Suratdagi qavs: $\dfrac{1}{a} + \dfrac{1}{b} - \dfrac{c}{ab} = \dfrac{b + a - c}{ab}$. Demak surat $\dfrac{(a + b - c)(a + b + c)}{ab}$.

Maxraj: umumiy maxraj $a^2b^2$, $\dfrac{b^2 + a^2 + 2ab - c^2}{a^2b^2} = \dfrac{(a + b)^2 - c^2}{a^2b^2} = \dfrac{(a + b - c)(a + b + c)}{a^2b^2}$.

Bölamiz: $\dfrac{(a + b - c)(a + b + c)}{ab} \cdot \dfrac{a^2b^2}{(a + b - c)(a + b + c)} = ab$.

Qöyamiz: $ab = 9{,}6 \cdot \dfrac{5}{12} = \dfrac{48}{5} \cdot \dfrac{5}{12} = 4$. $c$ ning qiymati natijaga ta'sir qilmaydi.

Bu yerda surat ham, maxraj ham kvadratlar ayirmasi orqali bir xil ikki köpaytuvçiga ajraldi, şuning uçun ular qisqarib ketdi va faqat $ab$ köpaytma qoldi. Demak bitta öznaliqning qiymati javobga umuman ta'sir qilmaydi, bu hisobni ancha qisqartiradi.

Javob: $4$.

### 19 [B]
Har bir kasrning suratini $a + b + c$ orqali yozamiz: $b + c = 11 - a$, $a + c = 11 - b$, $a + b = 11 - c$.

### 20 [A]

## 2-test

### 1 [C]
Avval birinçi qavsdagi ayirmani hisoblaymiz, keyin ikkinçi qavsni soddalaştirib, köpaytiramiz.

Birinçi qavs. Umumiy maxraj $(a - b)(a + b) = a^2 - b^2$. Birinçi kasrga qöşimça köpaytuvçi $(a - b)$:
$\dfrac{6(a - b) - (a - 11b)}{(a - b)(a + b)} = \dfrac{6a - 6b - a + 11b}{(a - b)(a + b)} = \dfrac{5a + 5b}{(a - b)(a + b)}$.

Suratda $5(a + b)$, maxrajdagi $(a + b)$ bilan qisqartiramiz: $\dfrac{5}{a - b}$.

Ikkinçi qavs: $\dfrac{1}{b^2} - \dfrac{1}{a^2} = \dfrac{a^2 - b^2}{a^2b^2} = \dfrac{(a - b)(a + b)}{a^2b^2}$.

Köpaytiramiz: $\dfrac{5}{a - b} \cdot \dfrac{(a - b)(a + b)}{a^2b^2} = \dfrac{5a + 5b}{a^2b^2}$.

Javob: $\dfrac{5a + 5b}{a^2b^2}$.

### 2 [A]
Birinçi qavsdagi kasrlarni formulalar yordamida qisqartiramiz, keyin ayiramiz.

Birinçi kasr: $\dfrac{(x - 4y)(x + 4y)}{x - 4y} = x + 4y$.

Ikkinçi kasr: $x^3 - 64y^3 = (x - 4y)(x^2 + 4xy + 16y^2)$, demak kasr $\dfrac{x^2 + 4xy + 16y^2}{x + 4y}$.

Ayirma: $\dfrac{(x + 4y)^2 - (x^2 + 4xy + 16y^2)}{x + 4y} = \dfrac{x^2 + 8xy + 16y^2 - x^2 - 4xy - 16y^2}{x + 4y} = \dfrac{4xy}{x + 4y}$.

Ikkinçi qavs: $\dfrac{1}{x} + \dfrac{1}{4y} = \dfrac{4y + x}{4xy}$.

Köpaytiramiz: $\dfrac{4xy}{x + 4y} \cdot \dfrac{x + 4y}{4xy} = 1$.

Bu misolda asosiy qadam — kvadratlar ayirmasi va kublar ayirmasi formulalarini tanib, kasrlarni avval qisqartiriş. Ikkinçi qavs aynan birinçi qavs natijasining teskarisi bölib çiqdi, şuning uçun köpaytma birga teng böldi va javob öznaliklarga boğliq emas.

Javob: $1$.

### 3 [A]
Köp qavatli kasrning suratini bitta kasrga keltiramiz, keyin maxrajga bölamiz.

Surat: umumiy maxraj $(a + b)(a - b)$. $\dfrac{(a - b) + 5(a + b)}{(a + b)(a - b)} = \dfrac{6a + 4b}{(a + b)(a - b)}$.

Bölamiz — teskari kasrga köpaytiramiz:
$\dfrac{6a + 4b}{(a + b)(a - b)} \cdot \dfrac{a + b}{6a + 4b}$.

$(6a + 4b)$ va $(a + b)$ qisqaradi, $\dfrac{1}{a - b}$ qoladi.

Asosiy fikr: suratni soddalaştirganda aynan maxrajdagi ifoda $6a + 4b$ hosil böldi.

Javob: $\dfrac{1}{a - b}$.

### 4 [D]
Qavs içidagi kasrlarni umumiy maxrajga keltirib qöşamiz, keyin bölamiz.

Umumiy maxraj $(x + 4)(x + 5)(x + 6)$. Qöşimça köpaytuvçilar $(x + 6)$ va $(x + 4)$:
$\dfrac{(x + 6) + (x + 4)}{(x + 4)(x + 5)(x + 6)} = \dfrac{2(x + 5)}{(x + 4)(x + 5)(x + 6)} = \dfrac{2}{(x + 4)(x + 6)}$.

$\dfrac{2}{x + 4}$ ga bölamiz, ya'ni $\dfrac{x + 4}{2}$ ga köpaytiramiz: $\dfrac{2}{(x + 4)(x + 6)} \cdot \dfrac{x + 4}{2} = \dfrac{1}{x + 6}$.

Bu yerda umumiy maxrajni topişda har bir kasrga yetişmagan köpaytuvçini qöşimça köpaytuvçi sifatida oldik. Suratdan umumiy köpaytuvçini qavsdan çiqarganimizdan keyin u maxrajdagi örta köpaytuvçi bilan qisqarib ketdi, bölişni esa teskari kasrga köpaytiriş bilan almaştirdik.

Javob: $\dfrac{1}{x + 6}$.

### 1 [D]
Avval birinçi qavsdagi ayirmani hisoblaymiz, keyin ikkinçi qavsni soddalaştirib, köpaytiramiz.

Birinçi qavs. Umumiy maxraj $(a - b)(a + b)$. Birinçi kasrga qöşimça köpaytuvçi $(a - b)$:
$\dfrac{8(a - b) - (a - 15b)}{(a - b)(a + b)} = \dfrac{8a - 8b - a + 15b}{(a - b)(a + b)} = \dfrac{7a + 7b}{(a - b)(a + b)}$.

Suratda $7(a + b)$, maxrajdagi $(a + b)$ bilan qisqartiramiz: $\dfrac{7}{a - b}$.

Ikkinçi qavs: $\dfrac{1}{b^2} - \dfrac{1}{a^2} = \dfrac{(a - b)(a + b)}{a^2b^2}$.

Köpaytiramiz: $\dfrac{7}{a - b} \cdot \dfrac{(a - b)(a + b)}{a^2b^2} = \dfrac{7a + 7b}{a^2b^2}$.

Javob: $\dfrac{7a + 7b}{a^2b^2}$.

### 2 [C]
Birinçi qavsdagi kasrlarni formulalar yordamida qisqartiramiz, keyin ayiramiz.

Birinçi kasr: $\dfrac{(x - 5y)(x + 5y)}{x - 5y} = x + 5y$.

Ikkinçi kasr: $x^3 - 125y^3 = (x - 5y)(x^2 + 5xy + 25y^2)$, demak kasr $\dfrac{x^2 + 5xy + 25y^2}{x + 5y}$.

Ikkinçi qavs: $\dfrac{1}{x} + \dfrac{1}{5y} = \dfrac{5y + x}{5xy}$.

Köpaytiramiz: $\dfrac{5xy}{x + 5y} \cdot \dfrac{x + 5y}{5xy} = 1$.

Bu misolda asosiy qadam — kvadratlar ayirmasi va kublar ayirmasi formulalarini tanib, kasrlarni avval qisqartiriş. Ikkinçi qavs aynan birinçi qavs natijasining teskarisi bölib çiqdi, şuning uçun köpaytma birga teng böldi va javob öznaliklarga boğliq emas.

Böluvçi: $\dfrac{1}{a^2} + \dfrac{1}{5ab} + \dfrac{1}{25b^2} = \dfrac{25b^2 + 5ab + a^2}{25a^2b^2}$.

Bölamiz: $\dfrac{a^2 + 5ab + 25b^2}{a + 5b} \cdot \dfrac{25a^2b^2}{a^2 + 5ab + 25b^2} = \dfrac{25a^2b^2}{a + 5b}$.

Köp qavatli kasrni soddalaştirişda biz pastki kasrning maxrajini yuqoriga köpaytuvçi qilib çiqaramiz. Keyin kublar ayirmasi formulasi va kvadratlar ayirmasi formulasi umumiy köpaytuvçini körsatdi, böluvçidagi uçhad esa aynan şu uçhadga teng bölgani uçun qisqarib ketdi.

Javob: $\dfrac{25a^2b^2}{a + 5b}$.

### 8 [B]
$t = \dfrac{1}{1{,}6}$ deb belgilaymiz. Unda $\dfrac{1}{1{,}6^3} = t^3$, $\dfrac{1}{2{,}56} = t^2$ (çunki $1{,}6^2 = 2{,}56$), $\dfrac{5}{1{,}6} = 5t$.

Kasr: $\dfrac{t^3 + 125}{t^2 - 5t + 25}$.

Surat — kublar yiğindisi: $t^3 + 5^3 = (t + 5)(t^2 - 5t + 25)$. Maxraj qisqaradi.

Natija: $t + 5 = \dfrac{1}{1{,}6} + 5 = \dfrac{5}{8} + 5 = \dfrac{45}{8}$.

Bu misolda kasrli sonlar bilan töğridan-töğri hisoblaş juda noqulay böladi. Yangi öznaliq kiritib, biz ifodani kublar yiğindisi formulasiga keltirdik: maxraj aynan toliqmas kvadrat bölgani uçun kasr bitta qöşiluvçiga qisqardi va oxirida faqat bitta oddiy qöşiş qoldi.

Javob: $\dfrac{45}{8}$.

### 9 [C]
Kasrni soddalaştiramiz: surat va maxrajni $m^2$ ga köpaytiramiz, şunda manfiy darajalar yöqoladi.

$\dfrac{m^{-2} - m}{m^{-1} - 1} = \dfrac{1 - m^3}{m - m^2}$.

Surat — kublar ayirmasi: $1 - m^3 = (1 - m)(1 + m + m^2)$. Maxraj: $m(1 - m)$.

$(1 - m)$ ni qisqartiramiz: $\dfrac{1 + m + m^2}{m} = \dfrac{1}{m} + 1 + m$.

Şartdan $m + \dfrac{1}{m} = 9$, demak qiymat $9 + 1 = 10$.

Manfiy darajalardan qutuliş uçun surat va maxrajni bir xil songa köpaytirdik, bu kasr qiymatini özgartirmaydi. Kublar ayirmasini köpaytuvçilarga ajratib, umumiy qavsni qisqartirdik va natija aynan şartda berilgan yiğindi orqali ifodalandi, şuning uçun $m$ ning özini topiş şart emas.

Javob: $10$.

### 10 [A]
Avval ifodani soddalaştiramiz, keyin qiymatlarni qöyamiz.

Birinçi qavs, umumiy maxraj $abc$: $\dfrac{a^2 + b^2 + c^2 + 2ab + 2bc + 2ca}{abc} = \dfrac{(a + b + c)^2}{abc}$ — uç had yiğindisining kvadrati.

Ikkinçi qavs: $\dfrac{a + b + c}{abc}$, uning kvadrati $\dfrac{(a + b + c)^2}{(abc)^2}$.

Bölamiz: $\dfrac{(a + b + c)^2}{abc} \cdot \dfrac{(abc)^2}{(a + b + c)^2} = abc$.

Qöyamiz: $abc = \dfrac{1}{8} \cdot 4 \cdot 6 = 3$.

Bu yerda muhim kuzatiş: birinçi qavsning surati uç had yiğindisining kvadrati, ikkinçi qavsning surati esa şu yiğindining özi. Şuning uçun ular bölinganda $(a + b + c)$ butunlay qisqarib ketdi va natija faqat köpaytmaga boğliq böldi, qiymatlarni qöyiş esa oson böldi.

Javob: $3$.

### 11 [B]
Har bir qavsni bitta kasrga keltiramiz va $abc = 8$ dan foydalanamiz.

Birinçi qavs: $a - \dfrac{2}{bc} = \dfrac{abc - 2}{bc} = \dfrac{6}{bc}$.

Ikkinçi qavs: $b - \dfrac{4}{ac} = \dfrac{abc - 4}{ac} = \dfrac{4}{ac}$.

Uçinçi qavs: $c + \dfrac{4}{ab} = \dfrac{abc + 4}{ab} = \dfrac{12}{ab}$.

Köpaytiramiz: $\dfrac{6 \cdot 4 \cdot 12}{(abc)^2} = \dfrac{288}{64} = \dfrac{9}{2}$.

Har bir qavsda öznaliqni kasr bilan birlaştiriş uçun uni umumiy maxrajga keltirdik, şunda suratda aynan $abc$ köpaytma paydo böldi va uning qiymatini töğridan-töğri qöydik. Maxrajlarning köpaytmasi esa yana $abc$ ning kvadrati bölgani uçun javob bitta songa aylandi.

Javob: $\dfrac{9}{2}$.

### 12 [D]
Kasrlarni çapdan önga ketma-ket birlaştiramiz. Har safar ikki kasrning maxrajlari $a - b$ va $a + b$ körinişida bölgani uçun umumiy maxraj kvadratlar ayirmasi $a^2 - b^2$ böladi, şu sababli hisob tez qisqaradi.

Birinçi ikki kasr: $\dfrac{1}{6 - x} - \dfrac{1}{6 + x} = \dfrac{2x}{36 - x^2}$.

Uçinçisini ayiramiz: $\dfrac{2x}{36 - x^2} - \dfrac{2x}{36 + x^2} = \dfrac{4x^3}{1296 - x^4}$.

Törtinçisini ayiramiz: $\dfrac{4x^3}{1296 - x^4} - \dfrac{4x^3}{1296 + x^4} = \dfrac{8x^7}{1679616 - x^8}$.

Ikkinçi qavs: $\dfrac{x^8 - 1679616}{x^8}$. Köpaytirsak, $-\dfrac{8}{x}$ qoladi.

$x = 64$ da: $-\dfrac{8}{64} = -\dfrac{1}{8}$.

Javob: $-\dfrac{1}{8}$.

### 13 [A]
Har bir qavsni bitta kasrga keltiramiz: $x + \dfrac{1}{y} = \dfrac{xy + 1}{y}$, $y + \dfrac{1}{x} = \dfrac{xy + 1}{x}$.

Şartdan $xy + 1 = 10 + 1 = 11$. Demak qavslar $\dfrac{11}{y}$ va $\dfrac{11}{x}$.

Kvadratlar yiğindisi: $\dfrac{121}{y^2} + \dfrac{121}{x^2} = \dfrac{121(x^2 + y^2)}{x^2y^2}$.

$x^2 + y^2 = (x + y)^2 - 2xy = 49 - 20 = 29$, $x^2y^2 = 100$.

Natija: $\dfrac{121 \cdot 29}{100} = \dfrac{3509}{100}$.

Bu misolda $x$ va $y$ ning özini topiş kerak emas. Biz faqat ularning yiğindisi va köpaytmasidan foydalandik: kvadratlar yiğindisini yiğindining kvadratidan ikkilangan köpaytmani ayiriş orqali topdik, maxrajdagi köpaytmaning kvadrati esa şartdan darhol çiqdi.

Javob: $\dfrac{3509}{100}$.

### 14 [D]
Maxraj $x^2 - 36 = (x - 6)(x + 6)$. Kasr qisqarişi uçun $x = 6$ yoki $x = -6$ suratning ildizi bölişi kerak.

$x = 6$ ni suratga qöyamiz: $36 + 6m + 12 = 0$, bundan $6m = -48$, $m = -8$. Tekşiruv: $x^2 - 8x + 12 = (x - 6)(x - 2)$.

$x = -6$ ni qöyamiz: $36 - 6m + 12 = 0$, bundan $m = 8$. Tekşiruv: $x^2 + 8x + 12 = (x + 6)(x + 2)$.

Demak $m \in \{-8; 8\}$.

Kasr qisqarişi uçun surat va maxraj umumiy köpaytuvçiga ega bölişi kerak. Maxrajning köpaytuvçilari ma'lum, demak maxrajning har bir ildizini suratga qöyib, nolga tenglaştirdik. Har ikki holatda tekşiruv suratning haqiqatan ham köpaytuvçilarga ajralişini körsatdi.

Javob: $\{-8; 8\}$.

### 15 [C]
Har bir qöşiluvçini ayirma sifatida yozamiz: $\dfrac{1}{k(k + 1)} = \dfrac{1}{k} - \dfrac{1}{k + 1}$.

Yiğindi: $\left(\dfrac{1}{20} - \dfrac{1}{21}\right) + \left(\dfrac{1}{21} - \dfrac{1}{22}\right) + \ldots + \left(\dfrac{1}{199} - \dfrac{1}{200}\right)$.

Örtadagi hadlar juft-juft qisqaradi: $\dfrac{1}{20} - \dfrac{1}{200}$.

Hisoblaymiz: $\dfrac{10}{200} - \dfrac{1}{200} = \dfrac{9}{200}$.

Bu usul teleskopik yiğindi deb ataladi: har bir qöşiluvçining ikkinçi kasri keyingi qöşiluvçining birinçi kasri bilan qarama-qarşi işorali böladi va ular yöqoladi. Natijada uzun yiğindidan faqat eng birinçi va eng oxirgi kasrlar qoladi, qolgan hisob oson.

Javob: $\dfrac{9}{200}$.

### 16 [A]
Maxrajdagi köpaytuvçilar $5$ ga farq qiladi: $\dfrac{1}{k(k + 5)} = \dfrac{1}{5}\left(\dfrac{1}{k} - \dfrac{1}{k + 5}\right)$, demak $\dfrac{10}{k(k + 5)} = 2\left(\dfrac{1}{k} - \dfrac{1}{k + 5}\right)$.

Yiğindi: $2\left(\dfrac{1}{4} - \dfrac{1}{9} + \dfrac{1}{9} - \dfrac{1}{14} + \ldots + \dfrac{1}{89} - \dfrac{1}{94}\right)$.

Örtadagi hadlar qisqaradi: $2\left(\dfrac{1}{4} - \dfrac{1}{94}\right) = 2 \cdot \dfrac{94 - 4}{376} = \dfrac{180}{376} = \dfrac{45}{94}$.

Maxrajdagi köpaytuvçilar orasidagi farq birdan katta bölganda, ikki kasr ayirmasi suratda şu farqni beradi, şuning uçun oldiga tegişli koeffitsiyent qöydik. Keyin teleskopik yiğindidagi kabi örtadagi barça kasrlar juft-juft qisqarib, faqat birinçi va oxirgisi qoldi.

Javob: $\dfrac{45}{94}$.

### 17 [C]
Birinçi had $\dfrac{5}{6}$ ni alohida qoldiramiz, qolgan yiğindini teleskopik usulda hisoblaymiz.

Köpaytuvçilar $7$ ga farq qiladi: $\dfrac{7}{k(k + 7)} = \dfrac{1}{k} - \dfrac{1}{k + 7}$.

Yiğindi: $\dfrac{1}{3} - \dfrac{1}{10} + \dfrac{1}{10} - \ldots - \dfrac{1}{66} = \dfrac{1}{3} - \dfrac{1}{66} = \dfrac{22 - 1}{66} = \dfrac{21}{66} = \dfrac{7}{22}$.

Endi $\dfrac{5}{6}$ ni qöşamiz: $\dfrac{5}{6} + \dfrac{7}{22} = \dfrac{55 + 21}{66} = \dfrac{76}{66} = \dfrac{38}{33}$.

Birinçi had boşqa qöşiluvçilarga öxşamagani uçun uni alohida hisobladik. Qolgan qöşiluvçilarda maxrajdagi köpaytuvçilar farqi suratga teng, demak har biri ikki kasr ayirmasiga aylanadi va örtadagi kasrlar qisqarib ketadi. Oxirida ikkala qismni umumiy maxrajda qöşdik.

Javob: $\dfrac{38}{33}$.

### 18 [D]
Ifodani soddalaştiramiz.

Suratdagi qavs: $\dfrac{1}{a} + \dfrac{1}{b} - \dfrac{c}{ab} = \dfrac{a + b - c}{ab}$, demak surat $\dfrac{(a + b - c)(a + b + c)}{ab}$.

Maxraj: $\dfrac{(a + b)^2 - c^2}{a^2b^2} = \dfrac{(a + b - c)(a + b + c)}{a^2b^2}$.

Bölamiz: bir xil qavslar qisqaradi va $\dfrac{a^2b^2}{ab} = ab$ qoladi.

Qöyamiz: $ab = 6{,}25 \cdot \dfrac{8}{25} = \dfrac{25}{4} \cdot \dfrac{8}{25} = 2$. $c$ ning qiymati natijaga ta'sir qilmaydi.

Bu yerda surat ham, maxraj ham kvadratlar ayirmasi orqali bir xil ikki köpaytuvçiga ajraldi, şuning uçun ular qisqarib ketdi va faqat $ab$ köpaytma qoldi. Demak bitta öznaliqning qiymati javobga umuman ta'sir qilmaydi, bu hisobni ancha qisqartiradi.

Javob: $2$.

### 19 [B]
Har bir kasrning suratini $a + b + c = 18$ orqali yozamiz: $b + c = 18 - a$, $a + c = 18 - b$, $a + b = 18 - c$.

Unda $\dfrac{b + c}{a} = \dfrac{18}{a} - 1$, va şunga öxşaş boşqa ikkitasi.

Yiğindi: $18\left(\dfrac{1}{a} + \dfrac{1}{b} + \dfrac{1}{c}\right) - 3$.

Qöyamiz: $18 \cdot \dfrac{11}{18} - 3 = 11 - 3 = 8$.

Bu misolning asosiy usuli: har bir suratni umumiy yiğindidan bitta öznaliqni ayiriş sifatida yozamiz. Şunda har bir kasr butun son bölingan öznaliq minus bir körinişiga keladi, uçala kasrni qöşganda esa şartda berilgan teskari sonlar yiğindisi paydo böladi.

Javob: $8$.

### 20 [A]
Uçala kasrni bir xil maxrajga keltiramiz, buning uçun $xyz = 125$ dan foydalanamiz.

Birinçi kasrning surat va maxrajini $xz$ ga köpaytiramiz: $\dfrac{25xz}{x^2yz + 5xyz + 25xz} = \dfrac{25xz}{125x + 625 + 25xz} = \dfrac{xz}{5x + 25 + xz}$.

Ikkinçi kasrning surat va maxrajini $x$ ga köpaytiramiz: $\dfrac{25x}{xyz + 5xz + 25x} = \dfrac{25x}{125 + 5xz + 25x} = \dfrac{5x}{25 + xz + 5x}$.

Uçinçi kasr: $\dfrac{25}{xz + 5x + 25}$.

Endi maxrajlar bir xil, suratlar yiğindisi $xz + 5x + 25$ — maxrajga teng. Demak yiğindi $1$.

Javob: $1$.
