# 24. Algebraik kasrlar (2-qism)

## 1-test

### 1 [B]
Birinçi qavsni umumiy maxrajga keltiramiz:
$\dfrac{5(a - b) - (a - 9b)}{a^2 - b^2} = \dfrac{4a + 4b}{(a - b)(a + b)} = \dfrac{4}{a - b}$.
Ikkinçi qavs: $\dfrac{1}{b^2} - \dfrac{1}{a^2} = \dfrac{(a - b)(a + b)}{a^2b^2}$.
Köpaytma: $\dfrac{4(a + b)}{a^2b^2} = \dfrac{4a + 4b}{a^2b^2}$.

Javob: $\dfrac{4a+4b}{a^2b^2}$.

### 2 [A]
Kasrlarni qisqartiramiz: $\dfrac{x^2 - 9y^2}{x - 3y} = x + 3y$, $\dfrac{x^3 - 27y^3}{x^2 - 9y^2} = \dfrac{x^2 + 3xy + 9y^2}{x + 3y}$.
Ayirma: $\dfrac{(x + 3y)^2 - x^2 - 3xy - 9y^2}{x + 3y} = \dfrac{3xy}{x + 3y}$.
Ikkinçi qavs: $\dfrac{x + 3y}{3xy}$. Köpaytma $1$ ga teng.

Javob: $1$.

### 3 [C]
Surat: $\dfrac{(a - b) + 4(a + b)}{(a + b)(a - b)} = \dfrac{5a + 3b}{(a + b)(a - b)}$.
Uni $\dfrac{5a + 3b}{a + b}$ ga bölamiz: $\dfrac{5a + 3b}{(a + b)(a - b)} \cdot \dfrac{a + b}{5a + 3b} = \dfrac{1}{a - b}$.

Javob: $\dfrac{1}{a-b}$.

### 4 [D]
Qavs içi: $\dfrac{(x + 5) + (x + 3)}{(x + 3)(x + 4)(x + 5)} = \dfrac{2(x + 4)}{(x + 3)(x + 4)(x + 5)} = \dfrac{2}{(x + 3)(x + 5)}$.
Bölamiz: $\dfrac{2}{(x + 3)(x + 5)} \cdot \dfrac{x + 3}{2} = \dfrac{1}{x + 5}$.

Javob: $\dfrac{1}{x+5}$.

### 5 [B]
$(a - 5)^2 - 25 = a(a - 10)$, demak qavs içi $\dfrac{a(a - 10)}{a(a - 5)} = \dfrac{a - 10}{a - 5}$, teskarisi $\dfrac{a - 5}{a - 10}$.
$\dfrac{a - 5}{a - 10} \cdot \dfrac{a - 10}{(a - 5)(a + 5)} = \dfrac{1}{a + 5}$.
$\dfrac{1}{a + 5} - \dfrac{a + 6}{a + 5} = \dfrac{-(a + 5)}{a + 5} = -1$.

Javob: $-1$.

### 6 [A]
Surat: $1 - \dfrac{3}{a} + \dfrac{9}{a^2} = \dfrac{a^2 - 3a + 9}{a^2}$.
Maxrajga bölsak: $\dfrac{1}{a^2}$.

Javob: $\dfrac{1}{a^2}$.

### 7 [D]
Birinçi had: $\dfrac{a}{1 - \frac{9b^2}{a^2}} = \dfrac{a^3}{a^2 - 9b^2}$; ikkinçi had: $\dfrac{3b}{\frac{a^2}{9b^2} - 1} = \dfrac{27b^3}{a^2 - 9b^2}$.
Ayirma: $\dfrac{a^3 - 27b^3}{(a - 3b)(a + 3b)} = \dfrac{a^2 + 3ab + 9b^2}{a + 3b}$.
Bölinuvçi: $\dfrac{a^2 + 3ab + 9b^2}{9a^2b^2}$. Natija: $\dfrac{9a^2b^2}{a + 3b}$.

Javob: $\dfrac{9a^2b^2}{a+3b}$.

### 8 [B]
$t = \dfrac{1}{2{,}5} = 0{,}4$ desak, kasr $\dfrac{t^3 + 27}{t^2 - 3t + 9}$ körinişida.
Kublar yiğindisi formulasiga köra u $t + 3 = 3{,}4 = \dfrac{17}{5}$.

Javob: $\dfrac{17}{5}$.

### 9 [C]
Surat va maxrajni $m^2$ ga köpaytiramiz: $\dfrac{1 - m^3}{m - m^2} = \dfrac{(1 - m)(1 + m + m^2)}{m(1 - m)} = \dfrac{1 + m + m^2}{m}$.
Bu $m + \dfrac{1}{m} + 1 = 6 + 1 = 7$.

Javob: $7$.

### 10 [C]
Birinçi qavs: $\dfrac{a^2 + b^2 + c^2 + 2ab + 2bc + 2ca}{abc} = \dfrac{(a + b + c)^2}{abc}$.
Ikkinçi qavs: $\left(\dfrac{a + b + c}{abc}\right)^2$.
Bölinma $abc$ ga teng: $\dfrac{1}{6} \cdot 3 \cdot 10 = 5$.

Javob: $5$.

### 11 [D]
Har qavsni umumiy maxrajga keltiramiz:
$a - \dfrac{2}{bc} = \dfrac{abc - 2}{bc} = \dfrac{8}{bc}$, $b - \dfrac{5}{ac} = \dfrac{5}{ac}$, $c + \dfrac{5}{ab} = \dfrac{15}{ab}$.
Köpaytma: $\dfrac{8 \cdot 5 \cdot 15}{(abc)^2} = \dfrac{600}{100} = 6$.

Javob: $6$.

### 12 [D]
Ifodadagi qöş minusni bitta ayiriş deb olamiz. Ketma-ket qöşamiz:
$\dfrac{1}{4 - x} - \dfrac{1}{4 + x} = \dfrac{2x}{16 - x^2}$; $\dfrac{2x}{16 - x^2} - \dfrac{2x}{16 + x^2} = \dfrac{4x^3}{256 - x^4}$;
$\dfrac{4x^3}{256 - x^4} - \dfrac{4x^3}{256 + x^4} = \dfrac{8x^7}{65536 - x^8}$.
$\dfrac{8x^7}{65536 - x^8} \cdot \dfrac{x^8 - 65536}{x^8} = -\dfrac{8}{x}$. $x = 40$ da: $-\dfrac{1}{5}$.

Javob: $-\dfrac{1}{5}$.

### 13 [C]
$x + \dfrac{1}{y} = \dfrac{xy + 1}{y} = \dfrac{7}{y}$, $y + \dfrac{1}{x} = \dfrac{7}{x}$.
Yiğindi: $49\left(\dfrac{1}{x^2} + \dfrac{1}{y^2}\right) = \dfrac{49(x^2 + y^2)}{(xy)^2}$, bunda $x^2 + y^2 = 25 - 12 = 13$.
$\dfrac{49 \cdot 13}{36} = \dfrac{637}{36}$.

Javob: $\dfrac{637}{36}$.

### 14 [A]
Maxraj $(x - 4)(x + 4)$. Kasr qisqarişi uçun surat $x = 4$ yoki $x = -4$ da nolga aylanişi kerak.
$x = 4$: $16 + 4m + 8 = 0$, $m = -6$. $x = -4$: $16 - 4m + 8 = 0$, $m = 6$.

Javob: $\{-6; 6\}$.

### 15 [B]
$\dfrac{1}{k(k + 1)} = \dfrac{1}{k} - \dfrac{1}{k + 1}$, yiğindida örtadagi hadlar qisqaradi:
$\dfrac{1}{12} - \dfrac{1}{120} = \dfrac{10 - 1}{120} = \dfrac{3}{40}$.

Javob: $\dfrac{3}{40}$.

### 16 [A]
$\dfrac{6}{k(k + 3)} = 2\left(\dfrac{1}{k} - \dfrac{1}{k + 3}\right)$, qisqarişdan keyin:
$2\left(\dfrac{1}{2} - \dfrac{1}{77}\right) = 2 \cdot \dfrac{75}{154} = \dfrac{75}{77}$.

Javob: $\dfrac{75}{77}$.

### 17 [C]
$\dfrac{5}{k(k + 5)} = \dfrac{1}{k} - \dfrac{1}{k + 5}$, demak $\dfrac{2}{3}$ dan keyingi yiğindi $\dfrac{1}{2} - \dfrac{1}{62} = \dfrac{15}{31}$.
$\dfrac{2}{3} + \dfrac{15}{31} = \dfrac{62 + 45}{93} = \dfrac{107}{93}$.

Javob: $\dfrac{107}{93}$.

### 18 [D]
Surat: $\dfrac{a + b - c}{ab}(a + b + c)$. Maxraj: $\dfrac{(a + b)^2 - c^2}{a^2b^2} = \dfrac{(a + b - c)(a + b + c)}{a^2b^2}$.
Bölinma $ab$ ga teng: $9{,}6 \cdot \dfrac{5}{12} = 4$.

Javob: $4$.

### 19 [B]
$(a + b + c)\left(\dfrac{1}{a} + \dfrac{1}{b} + \dfrac{1}{c}\right) = 3 + \dfrac{b + c}{a} + \dfrac{a + c}{b} + \dfrac{a + b}{c}$.
$11 \cdot 1 = 3 + S$, demak $S = 8$.

Javob: $8$.

### 20 [A]
Birinçi kasrni $xz$ ga, ikkinçisini $x$ ga köpaytirib kengaytiramiz ($xyz = 27$):
$\dfrac{9xz}{27x + 81 + 9xz} = \dfrac{xz}{xz + 3x + 9}$, $\dfrac{9x}{27 + 3xz + 9x} = \dfrac{3x}{xz + 3x + 9}$.
Uçinçi kasr $\dfrac{9}{xz + 3x + 9}$. Yiğindi: $\dfrac{xz + 3x + 9}{xz + 3x + 9} = 1$.

Javob: $1$.

## 2-test

### 1 [C]
Birinçi qavs: $\dfrac{6(a - b) - (a - 11b)}{a^2 - b^2} = \dfrac{5a + 5b}{(a - b)(a + b)} = \dfrac{5}{a - b}$.
Ikkinçi qavs: $\dfrac{(a - b)(a + b)}{a^2b^2}$.
Köpaytma: $\dfrac{5a + 5b}{a^2b^2}$.

Javob: $\dfrac{5a+5b}{a^2b^2}$.

### 2 [A]
$\dfrac{x^2 - 16y^2}{x - 4y} = x + 4y$, $\dfrac{x^3 - 64y^3}{x^2 - 16y^2} = \dfrac{x^2 + 4xy + 16y^2}{x + 4y}$.
Ayirma: $\dfrac{4xy}{x + 4y}$. Ikkinçi qavs: $\dfrac{x + 4y}{4xy}$. Köpaytma $1$.

Javob: $1$.

### 3 [A]
Surat: $\dfrac{(a - b) + 5(a + b)}{(a + b)(a - b)} = \dfrac{6a + 4b}{(a + b)(a - b)}$.
$\dfrac{6a + 4b}{a + b}$ ga bölsak: $\dfrac{1}{a - b}$.

Javob: $\dfrac{1}{a-b}$.

### 4 [D]
Qavs içi: $\dfrac{(x + 6) + (x + 4)}{(x + 4)(x + 5)(x + 6)} = \dfrac{2}{(x + 4)(x + 6)}$.
Bölamiz: $\dfrac{2}{(x + 4)(x + 6)} \cdot \dfrac{x + 4}{2} = \dfrac{1}{x + 6}$.

Javob: $\dfrac{1}{x+6}$.

### 5 [C]
$(a - 6)^2 - 36 = a(a - 12)$, qavs içi $\dfrac{a - 12}{a - 6}$, teskarisi $\dfrac{a - 6}{a - 12}$.
$\dfrac{a - 6}{a - 12} \cdot \dfrac{a - 12}{(a - 6)(a + 6)} = \dfrac{1}{a + 6}$.
$\dfrac{1}{a + 6} - \dfrac{a + 7}{a + 6} = -1$.

Javob: $-1$.

### 6 [B]
Surat: $\dfrac{a^2 - 4a + 16}{a^2}$, maxrajga bölsak: $\dfrac{1}{a^2}$.

Javob: $\dfrac{1}{a^2}$.

### 7 [A]
Birinçi qavs: $\dfrac{a^3}{a^2 - 16b^2} - \dfrac{64b^3}{a^2 - 16b^2} = \dfrac{a^2 + 4ab + 16b^2}{a + 4b}$.
Bölinuvçi: $\dfrac{a^2 + 4ab + 16b^2}{16a^2b^2}$. Natija: $\dfrac{16a^2b^2}{a + 4b}$.

Javob: $\dfrac{16a^2b^2}{a+4b}$.

### 8 [B]
$t = \dfrac{1}{1{,}2} = \dfrac{5}{6}$ desak, kasr $\dfrac{t^3 + 64}{t^2 - 4t + 16} = t + 4$.
$\dfrac{5}{6} + 4 = \dfrac{29}{6}$.

Javob: $\dfrac{29}{6}$.

### 9 [B]
$\dfrac{1 - m^3}{m - m^2} = \dfrac{1 + m + m^2}{m} = m + \dfrac{1}{m} + 1 = 9$.

Javob: $9$.

### 10 [D]
Birinçi qavs $\dfrac{(a + b + c)^2}{abc}$, ikkinçisi $\left(\dfrac{a + b + c}{abc}\right)^2$, bölinma $abc$.
$\dfrac{1}{15} \cdot 6 \cdot 5 = 2$.

Javob: $2$.

### 11 [B]
$a - \dfrac{5}{bc} = \dfrac{10}{bc}$, $b - \dfrac{9}{ac} = \dfrac{6}{ac}$, $c + \dfrac{3}{ab} = \dfrac{18}{ab}$.
Köpaytma: $\dfrac{10 \cdot 6 \cdot 18}{(abc)^2} = \dfrac{1080}{225} = \dfrac{24}{5}$.

Javob: $\dfrac{24}{5}$.

### 12 [C]
Qöş minusni bitta ayiriş deb olamiz. Ketma-ket birlaştiramiz:
$\dfrac{2x}{25 - x^2}$, keyin $\dfrac{4x^3}{625 - x^4}$, keyin $\dfrac{8x^7}{390625 - x^8}$.
Köpaytma: $\dfrac{8x^7}{390625 - x^8} \cdot \dfrac{x^8 - 390625}{x^8} = -\dfrac{8}{x}$. $x = 32$ da: $-\dfrac{1}{4}$.

Javob: $-\dfrac{1}{4}$.

### 13 [B]
$x + \dfrac{1}{y} = \dfrac{5}{y}$, $y + \dfrac{1}{x} = \dfrac{5}{x}$ (çunki $xy + 1 = 5$).
Yiğindi: $\dfrac{25(x^2 + y^2)}{(xy)^2} = \dfrac{25 \cdot 17}{16} = \dfrac{425}{16}$, bunda $x^2 + y^2 = 25 - 8 = 17$.

Javob: $\dfrac{425}{16}$.

### 14 [D]
Surat $x = 5$ yoki $x = -5$ da nolga aylanişi kerak.
$25 + 5m + 10 = 0 \Rightarrow m = -7$; $25 - 5m + 10 = 0 \Rightarrow m = 7$.

Javob: $\{-7; 7\}$.

### 15 [C]
$\dfrac{1}{15} - \dfrac{1}{150} = \dfrac{9}{150} = \dfrac{3}{50}$.

Javob: $\dfrac{3}{50}$.

### 16 [A]
$\dfrac{8}{k(k + 4)} = 2\left(\dfrac{1}{k} - \dfrac{1}{k + 4}\right)$:
$2\left(\dfrac{1}{3} - \dfrac{1}{83}\right) = 2 \cdot \dfrac{80}{249} = \dfrac{160}{249}$.

Javob: $\dfrac{160}{249}$.

### 17 [C]
$\dfrac{4}{k(k + 6)} = \dfrac{2}{3}\left(\dfrac{1}{k} - \dfrac{1}{k + 6}\right)$, yiğindi $\dfrac{2}{3}\left(1 - \dfrac{1}{61}\right) = \dfrac{40}{61}$.
$\dfrac{3}{5} + \dfrac{40}{61} = \dfrac{183 + 200}{305} = \dfrac{383}{305}$.

Javob: $\dfrac{383}{305}$.

### 18 [D]
Ifoda soddalaştirilganda $ab$ ga teng (surat va maxrajda $(a + b - c)(a + b + c)$ qisqaradi).
$8{,}4 \cdot \dfrac{5}{14} = 3$.

Javob: $3$.

### 19 [B]
$(a + b + c)\left(\dfrac{1}{a} + \dfrac{1}{b} + \dfrac{1}{c}\right) = 3 + S$.
$14 \cdot \dfrac{7}{8} = \dfrac{49}{4}$, demak $S = \dfrac{49}{4} - 3 = \dfrac{37}{4}$.

Javob: $\dfrac{37}{4}$.

### 20 [A]
$xyz = 64$ dan foydalanib, birinçi kasrni $xz$ ga, ikkinçisini $x$ ga kengaytiramiz:
$\dfrac{xz}{xz + 4x + 16} + \dfrac{4x}{xz + 4x + 16} + \dfrac{16}{xz + 4x + 16} = 1$.

Javob: $1$.

## 3-test

### 1 [D]
Birinçi qavs: $\dfrac{8(a - b) - (a - 15b)}{a^2 - b^2} = \dfrac{7a + 7b}{(a - b)(a + b)} = \dfrac{7}{a - b}$.
Ikkinçi qavs: $\dfrac{(a - b)(a + b)}{a^2b^2}$.
Köpaytma: $\dfrac{7a + 7b}{a^2b^2}$.

Javob: $\dfrac{7a+7b}{a^2b^2}$.

### 2 [C]
$\dfrac{x^2 - 25y^2}{x - 5y} = x + 5y$, $\dfrac{x^3 - 125y^3}{x^2 - 25y^2} = \dfrac{x^2 + 5xy + 25y^2}{x + 5y}$.
Ayirma: $\dfrac{5xy}{x + 5y}$. Ikkinçi qavs: $\dfrac{x + 5y}{5xy}$. Köpaytma $1$.

Javob: $1$.

### 3 [D]
Surat: $\dfrac{(a - b) + 6(a + b)}{(a + b)(a - b)} = \dfrac{7a + 5b}{(a + b)(a - b)}$.
$\dfrac{7a + 5b}{a + b}$ ga bölsak: $\dfrac{1}{a - b}$.

Javob: $\dfrac{1}{a-b}$.

### 4 [B]
Qavs içi: $\dfrac{(x + 7) + (x + 5)}{(x + 5)(x + 6)(x + 7)} = \dfrac{2}{(x + 5)(x + 7)}$.
Bölamiz: $\dfrac{2}{(x + 5)(x + 7)} \cdot \dfrac{x + 5}{2} = \dfrac{1}{x + 7}$.

Javob: $\dfrac{1}{x+7}$.

### 5 [A]
$(a - 7)^2 - 49 = a(a - 14)$, qavs içi $\dfrac{a - 14}{a - 7}$, teskarisi $\dfrac{a - 7}{a - 14}$.
$\dfrac{a - 7}{a - 14} \cdot \dfrac{a - 14}{(a - 7)(a + 7)} = \dfrac{1}{a + 7}$.
$\dfrac{1}{a + 7} - \dfrac{a + 8}{a + 7} = -1$.

Javob: $-1$.

### 6 [C]
Surat: $\dfrac{a^2 - 5a + 25}{a^2}$, maxrajga bölsak: $\dfrac{1}{a^2}$.

Javob: $\dfrac{1}{a^2}$.

### 7 [B]
Birinçi qavs: $\dfrac{a^3 - 125b^3}{a^2 - 25b^2} = \dfrac{a^2 + 5ab + 25b^2}{a + 5b}$.
Bölinuvçi: $\dfrac{a^2 + 5ab + 25b^2}{25a^2b^2}$. Natija: $\dfrac{25a^2b^2}{a + 5b}$.

Javob: $\dfrac{25a^2b^2}{a+5b}$.

### 8 [B]
$t = \dfrac{1}{1{,}6} = \dfrac{5}{8}$ desak, kasr $\dfrac{t^3 + 125}{t^2 - 5t + 25} = t + 5$.
$\dfrac{5}{8} + 5 = \dfrac{45}{8}$.

Javob: $\dfrac{45}{8}$.

### 9 [C]
$\dfrac{1 - m^3}{m - m^2} = \dfrac{1 + m + m^2}{m} = m + \dfrac{1}{m} + 1 = 10$.

Javob: $10$.

### 10 [A]
Ifoda $abc$ ga teng (birinçi qavs $\dfrac{(a + b + c)^2}{abc}$, ikkinçisi $\dfrac{(a + b + c)^2}{(abc)^2}$).
$\dfrac{1}{8} \cdot 4 \cdot 6 = 3$.

Javob: $3$.

### 11 [B]
$a - \dfrac{2}{bc} = \dfrac{6}{bc}$, $b - \dfrac{4}{ac} = \dfrac{4}{ac}$, $c + \dfrac{4}{ab} = \dfrac{12}{ab}$.
Köpaytma: $\dfrac{6 \cdot 4 \cdot 12}{(abc)^2} = \dfrac{288}{64} = \dfrac{9}{2}$.

Javob: $\dfrac{9}{2}$.

### 12 [D]

### 13 [A]

### 14 [D]
