# 36. Viyet teoremasi 1-qism

## 1-test

### 1 [D]
Keltirilgan kvadrat tenglamada $x^2$ oldidagi koeffitsiyent $1$ ga teng. Buning uçun tenglamani $5$ ga bölamiz:
$x^2 + \dfrac{3x}{5} - \dfrac{4}{5} = 0$.

Javob: $x^2 + \dfrac{3x}{5} - \dfrac{4}{5} = 0$.

### 2 [B]
Viyet teoremasi: $x_1 + x_2 = 13$, $x_1 x_2 = 36$.
Köpaytmasi $36$, yiğindisi $13$ bölgan sonlar: $4$ va $9$.

Javob: $\{4; 9\}$.

### 3 [C]
Viyet teoremasi böyiça $x_1 + x_2 = 7$, $x_1 x_2 = 2$.
$x_1 + x_2 + x_1 x_2 = 7 + 2 = 9$.

Javob: $9$.

### 4 [A]
$ax^2 + bx + c = 0$ uçun $x_1 + x_2 = -\dfrac{b}{a}$, $x_1 x_2 = \dfrac{c}{a}$: bu yerda $-\dfrac{5}{3}$ va $-\dfrac{2}{3}$.
$\dfrac{1}{x_1} + \dfrac{1}{x_2} = \dfrac{x_1 + x_2}{x_1 x_2} = \dfrac{-5/3}{-2/3} = \dfrac{5}{2}$.

Javob: $\dfrac{5}{2}$.

### 5 [B]
$x_1 + x_2 = -4$, $x_1 x_2 = -3$.
$x_1^2 + x_2^2 = (x_1 + x_2)^2 - 2x_1 x_2 = 16 + 6 = 22$.

Javob: $22$.

### 6 [D]
$x_1 + x_2 = -4$, $x_1 x_2 = \dfrac{3}{2}$.
$\dfrac{x_1}{x_2} + \dfrac{x_2}{x_1} = \dfrac{x_1^2 + x_2^2}{x_1 x_2} = \dfrac{16 - 3}{3/2} = \dfrac{26}{3}$.

Javob: $\dfrac{26}{3}$.

### 7 [A]
$x_1 + x_2 = -5$, $x_1 x_2 = 2$.
$x_1^3 + x_2^3 = (x_1 + x_2)^3 - 3x_1 x_2(x_1 + x_2) = -125 + 30 = -95$.

Javob: $-95$.

### 8 [C]
Qavslarni oçamiz: $x_1 x_2 + x_1 + x_1 x_2 + x_2 = 2x_1 x_2 + (x_1 + x_2)$.
$x_1 + x_2 = -\dfrac{7}{3}$, $x_1 x_2 = -2$: $-4 - \dfrac{7}{3} = -\dfrac{19}{3}$.

Javob: $-\dfrac{19}{3}$.

### 9 [B]
Umumiy maxrajga keltiramiz: $\dfrac{(x_1 + x_2) + 6}{x_1 x_2 + 3(x_1 + x_2) + 9}$.
$x_1 + x_2 = -4$, $x_1 x_2 = -5$: $\dfrac{-4 + 6}{-5 - 12 + 9} = \dfrac{2}{-8} = -\dfrac{1}{4}$.

Javob: $-\dfrac{1}{4}$.

### 10 [C]
Surat: $(x_2 + 2x_1) + (x_1 + 2x_2) = 3(x_1 + x_2)$.
Maxraj: $(x_1 + 2x_2)(x_2 + 2x_1) = 5x_1 x_2 + 2(x_1^2 + x_2^2) = 2(x_1 + x_2)^2 + x_1 x_2$.
$x_1 + x_2 = 6$, $x_1 x_2 = 5$: $\dfrac{18}{72 + 5} = \dfrac{18}{77}$.

Javob: $\dfrac{18}{77}$.

### 11 [A]
Viyet teoremasidan ildizlar $4$ va $9$ (yiğindi $13$, köpaytma $36$).
$\sqrt{4} + \sqrt{9} = 2 + 3 = 5$.

Javob: $5$.

### 12 [B]
Ildizlar: yiğindi $20$, köpaytma $64$, ya'ni $x_1 = 16$, $x_2 = 4$.
$\dfrac{1}{\sqrt{16}} - \dfrac{1}{\sqrt{4}} = \dfrac{1}{4} - \dfrac{1}{2} = -\dfrac{1}{4}$.

Javob: $-\dfrac{1}{4}$.

### 13 [D]
$x$ ildiz bölsa, $\dfrac{1}{x}$ uçun tenglama hosil qiliş uçun $x$ örniga $\dfrac{1}{x}$ qöyib, $x^2$ ga köpaytiramiz:
$3 - 8x + 2x^2 = 0$, ya'ni koeffitsiyentlar teskari tartibda yoziladi.

Javob: $2x^2 - 8x + 3 = 0$.

### 14 [A]
Qarama-qarşi ildizlar uçun $x$ örniga $-x$ qöyamiz: $3x^2 - 7x - 6 = 0$.
Bunda faqat $x$ oldidagi koeffitsiyent işorasini özgartiradi.

Javob: $3x^2 - 7x - 6 = 0$.

## 2-test

### 1 [A]
Tenglamani $6$ ga bölamiz: $x^2 - \dfrac{11x}{6} - \dfrac{3}{6} = 0$, ya'ni $x^2 - \dfrac{11x}{6} - \dfrac{1}{2} = 0$.

Javob: $x^2 - \dfrac{11x}{6} - \dfrac{1}{2} = 0$.

### 2 [C]
$x_1 + x_2 = 15$, $x_1 x_2 = 50$. Bunday sonlar: $5$ va $10$.

Javob: $\{5; 10\}$.

### 3 [B]
$x_1 + x_2 = 4$, $x_1 x_2 = -5$.
$4 + (-5) = -1$.

Javob: $-1$.

### 4 [B]
$x_1 + x_2 = \dfrac{9}{4}$, $x_1 x_2 = -\dfrac{5}{4}$.
$\dfrac{1}{x_1} + \dfrac{1}{x_2} = \dfrac{x_1 + x_2}{x_1 x_2} = \dfrac{9/4}{-5/4} = -\dfrac{9}{5}$.

Javob: $-\dfrac{9}{5}$.

### 5 [D]
$x_1 + x_2 = 6$, $x_1 x_2 = \dfrac{5}{2}$.
$x_1^2 + x_2^2 = 36 - 5 = 31$.

Javob: $31$.

### 6 [A]
$x_1 + x_2 = 2$, $x_1 x_2 = -\dfrac{4}{3}$.
$\dfrac{x_1^2 + x_2^2}{x_1 x_2} = \dfrac{4 + \frac{8}{3}}{-\frac{4}{3}} = \dfrac{20/3}{-4/3} = -5$.

Javob: $-5$.

### 7 [A]
$x_1 + x_2 = 3$, $x_1 x_2 = -\dfrac{1}{2}$.
$x_1^3 + x_2^3 = 27 - 3 \cdot \left(-\dfrac{1}{2}\right) \cdot 3 = 27 + \dfrac{9}{2} = \dfrac{63}{2}$.

Javob: $\dfrac{63}{2}$.

### 8 [D]
$x_1(x_2 + 1) + x_2(x_1 + 1) = 2x_1 x_2 + (x_1 + x_2)$.
$x_1 x_2 = 7$, $x_1 + x_2 = 8$: $14 + 8 = 22$.

Javob: $22$.

### 9 [C]
$\dfrac{(x_1 + x_2) + 4}{x_1 x_2 + 2(x_1 + x_2) + 4}$, bu yerda $x_1 + x_2 = 3$, $x_1 x_2 = \dfrac{1}{2}$.
$\dfrac{7}{\frac{1}{2} + 6 + 4} = \dfrac{7}{21/2} = \dfrac{2}{3}$.

Javob: $\dfrac{2}{3}$.

### 10 [B]
Surat: $4(x_1 + x_2)$. Maxraj: $(x_1 + 3x_2)(x_2 + 3x_1) = 10x_1 x_2 + 3(x_1^2 + x_2^2) = 3(x_1 + x_2)^2 + 4x_1 x_2$.
$x_1 + x_2 = -4$, $x_1 x_2 = \dfrac{3}{2}$: $\dfrac{-16}{48 + 6} = -\dfrac{16}{54} = -\dfrac{8}{27}$.

Javob: $-\dfrac{8}{27}$.

### 11 [C]
Ildizlar: yiğindi $29$, köpaytma $100$, ya'ni $4$ va $25$.
$\sqrt{4} + \sqrt{25} = 2 + 5 = 7$.

Javob: $7$.

### 12 [A]
Ildizlar: yiğindi $34$, köpaytma $225$, ya'ni $x_1 = 25$, $x_2 = 9$.
$\dfrac{1}{5} - \dfrac{1}{3} = -\dfrac{2}{15}$.

Javob: $-\dfrac{2}{15}$.

### 13 [D]
Teskari ildizlar uçun koeffitsiyentlarni teskari tartibda yozamiz: $-6x^2 + 5x + 4 = 0$.
$-1$ ga köpaytiramiz: $6x^2 - 5x - 4 = 0$.

Javob: $6x^2 - 5x - 4 = 0$.

### 14 [C]
$x$ örniga $-x$ qöyamiz: $4x^2 + 9x + 2 = 0$.

Javob: $4x^2 + 9x + 2 = 0$.

## 3-test

### 1 [C]
Tenglamani $8$ ga bölamiz: $x^2 + \dfrac{5x}{8} + \dfrac{6}{8} = 0$, ya'ni $x^2 + \dfrac{5x}{8} + \dfrac{3}{4} = 0$.

Javob: $x^2 + \dfrac{5x}{8} + \dfrac{3}{4} = 0$.

### 2 [A]
$x_1 + x_2 = 17$, $x_1 x_2 = 66$. Bunday sonlar: $6$ va $11$.

Javob: $\{6; 11\}$.

### 3 [B]
$x_1 + x_2 = -6$, $x_1 x_2 = 4$.
$-6 + 4 = -2$.

Javob: $-2$.

### 4 [D]
$x_1 + x_2 = -\dfrac{4}{5}$, $x_1 x_2 = -\dfrac{3}{5}$.
$\dfrac{x_1 + x_2}{x_1 x_2} = \dfrac{-4/5}{-3/5} = \dfrac{4}{3}$.

Javob: $\dfrac{4}{3}$.

### 5 [D]
$x_1 + x_2 = -4$, $x_1 x_2 = \dfrac{2}{3}$.
$x_1^2 + x_2^2 = 16 - \dfrac{4}{3} = \dfrac{44}{3}$.

Javob: $\dfrac{44}{3}$.

### 6 [C]
$x_1 + x_2 = -1$, $x_1 x_2 = -\dfrac{3}{4}$.
$\dfrac{x_1^2 + x_2^2}{x_1 x_2} = \dfrac{1 + \frac{3}{2}}{-\frac{3}{4}} = \dfrac{5}{2} \cdot \left(-\dfrac{4}{3}\right) = -\dfrac{10}{3}$.

Javob: $-\dfrac{10}{3}$.

### 7 [A]
$x_1 + x_2 = -2$, $x_1 x_2 = -\dfrac{2}{3}$.
$x_1^3 + x_2^3 = -8 - 3 \cdot \left(-\dfrac{2}{3}\right) \cdot (-2) = -8 - 4 = -12$.

Javob: $-12$.

### 8 [B]
$2x_1 x_2 + (x_1 + x_2)$, bu yerda $x_1 x_2 = -\dfrac{5}{4}$, $x_1 + x_2 = -1$.
$-\dfrac{5}{2} - 1 = -\dfrac{7}{2}$.

Javob: $-\dfrac{7}{2}$.

### 9 [D]
$\dfrac{(x_1 + x_2) + 2}{x_1 x_2 + (x_1 + x_2) + 1}$, bu yerda $x_1 + x_2 = -1$, $x_1 x_2 = -\dfrac{2}{3}$.
$\dfrac{1}{-\frac{2}{3} - 1 + 1} = \dfrac{1}{-2/3} = -\dfrac{3}{2}$.

Javob: $-\dfrac{3}{2}$.

### 10 [C]
Surat: $3(x_1 + x_2)$. Maxraj: $2(x_1 + x_2)^2 + x_1 x_2$.
$x_1 + x_2 = 3$, $x_1 x_2 = \dfrac{2}{3}$: $\dfrac{9}{18 + \frac{2}{3}} = \dfrac{9}{56/3} = \dfrac{27}{56}$.

Javob: $\dfrac{27}{56}$.

### 11 [B]
Ildizlar: yiğindi $26$, köpaytma $25$, ya'ni $1$ va $25$.
$\sqrt{1} + \sqrt{25} = 1 + 5 = 6$.

Javob: $6$.

### 12 [A]
Ildizlar: yiğindi $52$, köpaytma $576$, ya'ni $x_1 = 36$, $x_2 = 16$.
$\dfrac{1}{6} - \dfrac{1}{4} = -\dfrac{1}{12}$.

Javob: $-\dfrac{1}{12}$.

### 13 [A]
Teskari ildizlar uçun koeffitsiyentlarni teskari tartibda yozamiz: $-2x^2 - 3x + 5 = 0$.
$-1$ ga köpaytiramiz: $2x^2 + 3x - 5 = 0$.

Javob: $2x^2 + 3x - 5 = 0$.

### 14 [C]
$x$ örniga $-x$ qöyamiz: $5x^2 - 4x - 7 = 0$.

Javob: $5x^2 - 4x - 7 = 0$.
