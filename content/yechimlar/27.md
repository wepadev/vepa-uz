# 27. Tenglama va sistema orqali yeçiladigan matnli masalalar

## 1-test

### 1 [C]
Kiçik sonni $x$ desak, katta son $5x$.
$x + 5x = 108$, $6x = 108$, $x = 18$.
Katta son: $5 \cdot 18 = 90$.

Javob: $90$.

### 2 [D]
Sonlar $n$, $n + 1$, $n + 2$ bölsin.
$3n + 3 = 156$, $3n = 153$, $n = 51$.

Javob: $51$.

### 3 [B]
Ketma-ket juft sonlar: $n - 4$, $n - 2$, $n$, $n + 2$, $n + 4$. Yiğindisi $5n = 150$, $n = 30$.
Eng kattasi: $30 + 4 = 34$.

Javob: $34$.

### 4 [A]
Sonlar $n$ va $n + 2$ bölsin. Kvadratlar ayirmasi: $(n + 2)^2 - n^2 = 4n + 4 = 80$.
$n = 19$, katta son $21$.

Javob: $21$.

### 5 [D]
Kasr $\dfrac{3k}{5k}$ körinişda. Şartga köra: $\dfrac{3k + 6}{5k + 6} = \dfrac{5}{7}$.
$21k + 42 = 25k + 30$, $4k = 12$, $k = 3$.
Kasr $\dfrac{9}{15}$, maxraji $15$.

Javob: $15$.

### 6 [B]
Yöl uzunligi $L$. Qolgan qism $\dfrac{5}{8}L$, bu $\dfrac{L}{2} + 5$ ga teng.
$\dfrac{5}{8}L - \dfrac{4}{8}L = 5$, $\dfrac{L}{8} = 5$, $L = 40$ km.

Javob: $40$.

### 7 [C]
Idiş siğimi $V$. Dastlab suv $\dfrac{5}{6}V$, $40$ litr olingaç $\dfrac{2}{3}V$ qoladi.
$\dfrac{5}{6}V - \dfrac{4}{6}V = 40$, $\dfrac{V}{6} = 40$, $V = 240$ litr.

Javob: $240$.

### 8 [A]
Ukaning yoşi $x$, akaniki $x + 15$.
$6$ yildan keyin: $x + 21 = 2(x + 6)$, $x = 9$.
Aka $24$ yoşda, yiğindi $9 + 24 = 33$.

Javob: $33$.

### 9 [C]
Nabiralar yoşlari yiğindisi $64 : 2 = 32$.
$t$ yildan keyin bobo $64 + t$, nabiralar yiğindisi $32 + 3t$ böladi.
$64 + t = 32 + 3t$, $2t = 32$, $t = 16$.

Javob: $16$.

### 10 [B]
Koptok narxi $P$. Dastlab har biri $\dfrac{P}{10}$, keyin $\dfrac{P}{15}$ söm beradi.
$\dfrac{P}{10} - \dfrac{P}{15} = 5000$, $\dfrac{P}{30} = 5000$, $P = 150\,000$ söm.

Javob: $150\,000$.

### 11 [D]
Reja böyiça kuniga $p$ ta: jami $30p$.
Amalda: $25(p + 18) = 30p + 50$, $25p + 450 = 30p + 50$, $5p = 400$, $p = 80$.
Reja: $30 \cdot 80 = 2400$ ta.

Javob: $2400$.

### 12 [B]
Kiçik son $x$, katta son $5x$.
$x + 5x = 72$, $x = 12$.

Javob: $12$.

### 13 [A]
Daftar $d$, ruçka $r$ söm: $4d + 3r = 26000$, $2d + 7r = 24000$.
Ikkinçisini $2$ ga köpaytirib birinçisini ayiramiz: $11r = 22000$, $r = 2000$.
$4d = 26000 - 6000 = 20000$, $d = 5000$ söm.

Javob: $5000$.

### 14 [D]
Qora qalam $q$, rangli $r$ söm. Pul miqdori bir xil: $8q + 3r = 5q + 5r$, ya'ni $3q = 2r$.
$q + r = 10000$ va $q = \dfrac{2r}{3}$: $\dfrac{5r}{3} = 10000$, $r = 6000$ söm.

Javob: $6000$.

### 15 [D]
Bir örkaçlilar $x$ ta, ikki örkaçlilar $x + 15$ ta.
$x + 2(x + 15) = 135$, $3x = 105$, $x = 35$.
Ikki örkaçlilar: $35 + 15 = 50$.

Javob: $50$.

### 16 [C]
Son $\overline{ab} = 10a + b$. Şartlar: $a + b = 13$ va $10a + b - 27 = 10b + a$.
Ikkinçisidan $9(a - b) = 27$, $a - b = 3$.
$a = 8$, $b = 5$, son $85$.

Javob: $85$.

### 17 [A]
$a = b + 4$ va $(10a + b) + (10b + a) = 11(a + b) = 154$, ya'ni $a + b = 14$.
$a = 9$, $b = 5$, son $95$.

Javob: $95$.

### 18 [B]
Narxlar $x$ va $y$: $x + y = 100000$, $0{,}75x + 1{,}2y = 102000$.
$y = 100000 - x$: $0{,}75x + 120000 - 1{,}2x = 102000$, $0{,}45x = 18000$, $x = 40000$.
$y = 60000$.

Javob: $(40\,000; 60\,000)$.

### 19 [D]
$x - y = y - z$, bundan $x + z = 2y$.
$x + y + z = 3y = 105$, $y = 35$.

Javob: $35$.

### 20 [A]
Uçburçaklar $t$, törtburçaklar $q$, beşburçaklar $f$ ta. $t + f = 2q$ va $t + q + f = 18$, demak $3q = 18$, $q = 6$, $t + f = 12$.
Uçlar: $3t + 4 \cdot 6 + 5f = 70$, $3t + 5f = 46$.
$3(12 - f) + 5f = 46$, $2f = 10$, $f = 5$.

Javob: $5$.

### 21 [A]
$x + y + z = 4z - 3 + z = 5z - 3$. Bu ifoda $z$ ösganda ösadi.
$z > 4$ natural, demak eng kiçigi $z = 5$ ($x + y = 17$, masalan $x = 1$, $y = 16$).
$5 \cdot 5 - 3 = 22$.

Javob: $22$.
