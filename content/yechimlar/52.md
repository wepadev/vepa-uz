# 52. Geometrik progressiya

## 1-test

### 1 [A]
Umumiy had formulasi: $b_n = b_1 q^{n-1}$.
$b_6 = -4\cdot(-2)^5 = -4\cdot(-32) = 128$.

Javob: $128$.

### 2 [D]
$b_8 = b_4 q^4 = -3\cdot(-2)^4 = -3\cdot 16 = -48$.

Javob: $-48$.

### 3 [B]
$b_6 = b_3 q^3 \Rightarrow q^3 = \dfrac{3}{24} = \dfrac{1}{8} \Rightarrow q = \dfrac{1}{2}$.

Javob: $\dfrac{1}{2}$.

### 4 [B]
$b_3^2 = b_1 b_5 = (-5)(-80) = 400$, ya'ni $b_3 = \pm 20$.
$b_3 = b_1 q^2$ va $q^2 > 0$, demak $b_3$ ning işorasi $b_1$ niki bilan bir xil: $b_3 = -20$.

Javob: $-20$.

### 5 [C]
$b_5 b_7 = b_6^2 = 25 \Rightarrow b_6 = \pm 5$. $b_{10} = b_6 q^4 > 0$, demak $b_6 = 5$.
$q^4 = \dfrac{b_{10}}{b_6} = \dfrac{5}{16}:5 = \dfrac{1}{16}$.
$b_2 = \dfrac{b_6}{q^4} = 5\cdot 16 = 80$.

Javob: $80$.

### 6 [A]
$b_3 b_9 = b_6^2$, demak $b_3 b_6 b_9 = b_6^3 = \dfrac{1}{27}$.
$b_6 = \dfrac{1}{3}$.

Javob: $\dfrac{1}{3}$.

### 7 [C]
Örta hadning kvadrati qöşni hadlar köpaytmasiga teng:
$(\sqrt{x})^2 = 2(2\sqrt{x} + 6) \Rightarrow x - 4\sqrt{x} - 12 = 0$.
$t = \sqrt{x} \ge 0$: $t^2 - 4t - 12 = 0 \Rightarrow t = 6$, $x = 36$.

Javob: $36$.

### 8 [D]
Progressiyada $6$ ta had: $b_6 = b_1 q^5 \Rightarrow 1 = 243q^5$.
$q^5 = \dfrac{1}{243} \Rightarrow q = \dfrac{1}{3}$.

Javob: $\dfrac{1}{3}$.

### 9 [B]
Yiğindi formulasi: $S_n = \dfrac{b_1(1 - q^n)}{1 - q}$.
$S_5 = \dfrac{3(1 - (-2)^5)}{1 + 2} = \dfrac{3\cdot 33}{3} = 33$.

Javob: $33$.

### 10 [A]
$q^3 = \dfrac{b_5}{b_2} = -8 \Rightarrow q = -2$, $b_1 = \dfrac{8}{-2} = -4$.
$S_5 = \dfrac{-4(1 + 32)}{1 + 2} = -44$.

Javob: $-44$.

### 11 [D]
$b_1 = 3\cdot(-2) = -6$, $q = -2$.
$S_5 = \dfrac{-6(1 - (-32))}{3} = -66$.

Javob: $-66$.

### 12 [C]
$b_1 = 2$, $q = 2$, $256 = 2^8$ — jami $8$ ta had.
$S_8 = \dfrac{2(2^8 - 1)}{2 - 1} = 2\cdot 255 = 510$.

Javob: $510$.

### 13 [C]
$b_1 = \dfrac{3}{16}$, $q = 2$; $48 : \dfrac{3}{16} = 256 = 2^8$, demak $9$ ta had.
$S_9 = \dfrac{3}{16}(2^9 - 1) = \dfrac{3\cdot 511}{16} = \dfrac{1533}{16}$.

Javob: $\dfrac{1533}{16}$.

### 14 [B]
$S_4 = \dfrac{b_1(3^4 - 1)}{3 - 1} = 40b_1 = 80 \Rightarrow b_1 = 2$.
$b_2 = 2\cdot 3 = 6$.

Javob: $6$.

### 15 [A]
Çeksiz kamayuvçi progressiya yiğindisi: $S = \dfrac{b_1}{1 - q}$.
$S = \dfrac{10}{1 + \frac{1}{4}} = \dfrac{10}{\frac{5}{4}} = 8$.

Javob: $8$.

### 16 [A]

Javob: $\dfrac{10}{3}$.

### 17 [D]
$b_1 = \dfrac{5}{3}$, $q = \dfrac{1}{3}$:
$S = \dfrac{\frac{5}{3}}{1 - \frac{1}{3}} = \dfrac{5}{2}$.

Javob: $\dfrac{5}{2}$.

### 18 [D]
$b_1 = 3\cdot\Bigl(-\dfrac{1}{3}\Bigr) = -1$, $q = -\dfrac{1}{3}$:
$S = \dfrac{-1}{1 + \frac{1}{3}} = -\dfrac{3}{4}$.

Javob: $-\dfrac{3}{4}$.

### 19 [C]
$b_1 = \dfrac{b_4}{q^3} = \dfrac{2}{9}\cdot 27 = 6$.
$S = \dfrac{6}{1 - \frac{1}{3}} = 9$.

Javob: $9$.

### 20 [D]
Uçinçi haddan keyingi hadlar yiğindisi $q^3 S$ ga teng: $S - S_3 = q^3 S$.
$\dfrac{16}{3} - 6 = -\dfrac{2}{3} = q^3\cdot\dfrac{16}{3} \Rightarrow q^3 = -\dfrac{1}{8} \Rightarrow q = -\dfrac{1}{2}$.

Javob: $-\dfrac{1}{2}$.

### 21 [B]
$b_1 = 3$, $q = -x$, $|q| < 1$:
$S = \dfrac{3}{1 - (-x)} = \dfrac{3}{1 + x}$.

Javob: $\dfrac{3}{1 + x}$.

### 22 [C]
Qavs içi: $b_1 = 1$, $q = \dfrac{3}{x}$, $|q| < 1$. Yiğindi $\dfrac{1}{1 - \frac{3}{x}} = \dfrac{x}{x - 3}$.
$2(x - 3)\cdot\dfrac{x}{x - 3} = 2x$.

Javob: $2x$.

### 23 [A]
$S_6 = S_3 + q^3 S_3 = S_3(1 + q^3)$.
$1 + q^3 = \dfrac{63}{32} : \dfrac{9}{4} = \dfrac{7}{8} \Rightarrow q^3 = -\dfrac{1}{8} \Rightarrow q = -\dfrac{1}{2}$.

Javob: $-\dfrac{1}{2}$.

### 24 [B]
$S_8 - S_7 = b_8 = 640$.
$b_3 = \dfrac{b_8}{q^5} = \dfrac{640}{-32} = -20$.

Javob: $-20$.

### 25 [D]
Sonlar: $a$, $a + 5$, $a + 10$. Hosil bölgan $a - 4$, $a + 2$, $a + 10$ geometrik progressiya:
$(a + 2)^2 = (a - 4)(a + 10) \Rightarrow a^2 + 4a + 4 = a^2 + 6a - 40 \Rightarrow a = 22$.
Sonlar $22, 27, 32$, yiğindisi $81$.

Javob: $81$.

### 26 [C]
Sonlar: $b$, $\dfrac{b}{2}$, $\dfrac{b}{4}$. $b$, $\dfrac{b}{2}$, $\dfrac{b}{4} - 9$ arifmetik progressiya:
$2\cdot\dfrac{b}{2} = b + \dfrac{b}{4} - 9 \Rightarrow \dfrac{b}{4} = 9 \Rightarrow b = 36$.
Hosil bölgan sonlar: $36, 18, 0$, yiğindisi $54$.

Javob: $54$.
