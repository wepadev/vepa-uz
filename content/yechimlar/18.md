# 18. Qisqa köpaytiriş formulalari (1-qism)

## 1-test

### 1 [B]
Kvadratlar ayirmasi formulasi: $(a - b)(a + b) = a^2 - b^2$.
$(a - 8)(a + 8) = a^2 - 64$.

Javob: $a^2-64$.

### 2 [D]
Kvadratlar ayirmasi formulasi:
$(2x^{-2})^2 - (y^{-1})^2 = 4x^{-4} - y^{-2}$.

Javob: $4x^{-4}-y^{-2}$.

### 3 [C]
Formulani ikki marta qöllaymiz:
$(y - 2)(y + 2) = y^2 - 4$;
$(y^2 - 4)(y^2 + 4) = y^4 - 16$.

Javob: $y^4-16$.

### 4 [A]
$205 \cdot 195 = (200 + 5)(200 - 5) = 200^2 - 5^2 = 40\,000 - 25 = 39\,975$.

Javob: $39\,975$.

### 5 [D]
Yiğindining kvadrati: $(a + b)^2 = a^2 + 2ab + b^2$.
$(2x + 5)^2 = 4x^2 + 20x + 25$.

Javob: $4x^2+20x+25$.

### 6 [C]
Ayirmaning kvadrati: $(a - b)^2 = a^2 - 2ab + b^2$.
$(2y - 5)^2 = 4y^2 - 20y + 25$.

Javob: $4y^2-20y+25$.

### 7 [A]
Yiğindining kvadrati, örta had $2 \cdot y \cdot \dfrac{3}{y} = 6$:
$\left(y + \dfrac{3}{y}\right)^2 = y^2 + 6 + \dfrac{9}{y^2}$.

Javob: $y^2+6+\dfrac{9}{y^2}$.

### 8 [B]
Ayirmaning kvadrati, örta had $2 \cdot y \cdot \dfrac{4}{y} = 8$:
$\left(y - \dfrac{4}{y}\right)^2 = y^2 - 8 + \dfrac{16}{y^2}$.

Javob: $y^2-8+\dfrac{16}{y^2}$.

### 9 [D]
$2003^2 = (2000 + 3)^2 = 4\,000\,000 + 2 \cdot 2000 \cdot 3 + 9 = 4\,000\,000 + 12\,000 + 9 = 4\,012\,009$.

Javob: $4\,012\,009$.

### 10 [B]
$1997^2 = (2000 - 3)^2 = 4\,000\,000 - 12\,000 + 9 = 3\,988\,009$.

Javob: $3\,988\,009$.

### 11 [C]
Uç had yiğindisining kvadrati: $(a + b + c)^2 = a^2 + b^2 + c^2 + 2ab + 2ac + 2bc$, bunda $a = 2x$, $b = 3y$, $c = -z$.
$4x^2 + 9y^2 + z^2 + 12xy - 4xz - 6yz$.

Javob: $4x^2+9y^2+z^2+12xy-4xz-6yz$.

### 12 [A]
$(a + 3b)^2 + (a - 3b)^2 = 2a^2 + 18b^2$ (örta hadlar qisqaradi).
$2a^2 + 18b^2 - 2(a^2 + 9b^2) = 0$.

Javob: $0$.

### 13 [D]
Kvadratlar ayirmasi: $A^2 - B^2 = (A - B)(A + B)$, bunda $A = x^2 - 3x + 2$, $B = x^2 + 3x - 2$.
$A - B = -6x + 4$, $A + B = 2x^2$.
$(-6x + 4) \cdot 2x^2 = -12x^3 + 8x^2$.

Javob: $-12x^3+8x^2$.

### 14 [C]
Çap tomonni oçamiz: $(ax - 2)^2 = a^2x^2 - 4ax + 4$.
Koeffitsiyentlarni tenglaymiz: $a^2 = 9$, $b = 4a$, bundan $b^2 = 16a^2 = 144$.
$a^2 - b^2 = 9 - 144 = -135$.

Javob: $-135$.

### 15 [A]
$(ax + b)^2 = a^2x^2 + 2abx + b^2$.
$a^2 = 16$, $2ab = 40$, ya'ni $ab = 20$. $a = 4$ da $b = 5$ ($a = -4$ da $b = -5$).
$a^2 - b^2 = 16 - 25 = -9$.

Javob: $-9$.

### 16 [B]
$25x^{10} = (5x^5)^2$, $x^4 = (x^2)^2$, $10x^7 = 2 \cdot 5x^5 \cdot x^2$.
Örta had manfiy, demak bu ayirmaning kvadrati: $(5x^5 - x^2)^2$.

Javob: $(5x^5-x^2)^2$.

### 17 [B]
$25x^6 = (5x^3)^2$, $9y^4 = (3y^2)^2$, $30x^3y^2 = 2 \cdot 5x^3 \cdot 3y^2$.
Demak $(5x^3 + 3y^2)^2$.

Javob: $(5x^3+3y^2)^2$.

### 18 [A]
$x^2 - 6x = (x - 3)^2 - 9$.
$x^2 - 6x + 14 = (x - 3)^2 - 9 + 14 = (x - 3)^2 + 5$.

Javob: $(x-3)^2+5$.

### 19 [D]
$x^2 + 8x = (x + 4)^2 - 16$.
$x^2 + 8x + 20 = (x + 4)^2 + 4$.

Javob: $(x+4)^2+4$.

### 20 [C]
Hadlarni guruhlaymiz: $(x^2 + 2xy + y^2) + (y^2 + 8y + 16) + 1$.
$= (x + y)^2 + (y + 4)^2 + 1$.

Javob: $(x+y)^2+(y+4)^2+1$.

### 21 [A]
Qavslarni oçsak, örta hadlar qisqaradi: $(x - 2)^2 + (x + 2)^2 = 2x^2 + 8$.
$2 \cdot 15 + 8 = 38$.

Javob: $38$.

### 22 [B]
Maxrajda töla kvadrat ajratamiz: $x^2 + 8x + 21 = (x + 4)^2 + 5 \ge 5$.
Demak $0 < \dfrac{35}{x^2 + 8x + 21} \le \dfrac{35}{5} = 7$, ifoda $(0; 7]$ oraliqdagi barça qiymatlarni qabul qiladi.
Butun qiymatlar: $1, 2, \ldots, 7$, ya'ni $7$ ta.

Javob: $7$.

## 2-test

### 1 [B]
Kvadratlar ayirmasi: $(m - 3)(m + 3) = m^2 - 9$.

Javob: $m^2-9$.

### 2 [B]
$(5m^{-1})^2 - (3n^{-2})^2 = 25m^{-2} - 9n^{-4}$.

Javob: $25m^{-2}-9n^{-4}$.

### 3 [C]
$(a - 4)(a + 4) = a^2 - 16$;
$(a^2 - 16)(a^2 + 16) = a^4 - 256$.

Javob: $a^4-256$.

### 4 [A]
$1008 \cdot 992 = (1000 + 8)(1000 - 8) = 1\,000\,000 - 64 = 999\,936$.

Javob: $999\,936$.

### 5 [C]
Yiğindining kvadrati: $(4m + 3)^2 = 16m^2 + 24m + 9$.

Javob: $16m^2+24m+9$.

### 6 [D]
Ayirmaning kvadrati: $(5n - 2)^2 = 25n^2 - 20n + 4$.

Javob: $25n^2-20n+4$.

### 7 [D]
Örta had $2 \cdot a \cdot \dfrac{4}{a} = 8$:
$\left(a + \dfrac{4}{a}\right)^2 = a^2 + 8 + \dfrac{16}{a^2}$.

Javob: $a^2+8+\dfrac{16}{a^2}$.

### 8 [B]
Örta had $2 \cdot a \cdot \dfrac{2}{a} = 4$:
$\left(a - \dfrac{2}{a}\right)^2 = a^2 - 4 + \dfrac{4}{a^2}$.

Javob: $a^2-4+\dfrac{4}{a^2}$.

### 9 [A]
$501^2 = (500 + 1)^2 = 250\,000 + 1000 + 1 = 251\,001$.

Javob: $251\,001$.

### 10 [C]
$499^2 = (500 - 1)^2 = 250\,000 - 1000 + 1 = 249\,001$.

Javob: $249\,001$.

### 11 [A]
Uç had yiğindisining kvadrati, bunda $a = 4m$, $b = -n$, $c = 2p$:
$16m^2 + n^2 + 4p^2 - 8mn + 16mp - 4np$.

Javob: $16m^2+n^2+4p^2-8mn+16mp-4np$.

### 12 [D]
$(3m + 2n)^2 + (3m - 2n)^2 = 18m^2 + 8n^2$.
$18m^2 + 8n^2 - 2(9m^2 + 4n^2) = 0$.

Javob: $0$.

### 13 [C]
$A = 2x^2 - x + 4$, $B = 2x^2 + x - 4$ deb, $A^2 - B^2 = (A - B)(A + B)$.
$A - B = -2x + 8$, $A + B = 4x^2$.
$(-2x + 8) \cdot 4x^2 = -8x^3 + 32x^2$.

Javob: $-8x^3+32x^2$.

### 14 [D]
$(ax - 1)^2 = a^2x^2 - 2ax + 1$, demak $a^2 = 16$, $b = 2a$, $b^2 = 4a^2 = 64$.
$a^2 - b^2 = 16 - 64 = -48$.

Javob: $-48$.

### 15 [B]
$a^2 = 25$, $2ab = 30$, ya'ni $ab = 15$. $a = 5$ da $b = 3$.
$a^2 - b^2 = 25 - 9 = 16$.

Javob: $16$.

### 16 [C]
$9m^6 = (3m^3)^2$, $4m^4 = (2m^2)^2$, $12m^5 = 2 \cdot 3m^3 \cdot 2m^2$.
Demak $(3m^3 + 2m^2)^2$.

Javob: $(3m^3+2m^2)^2$.

### 17 [B]
$4m^{10} = (2m^5)^2$, $49n^8 = (7n^4)^2$, $28m^5n^4 = 2 \cdot 2m^5 \cdot 7n^4$, örta had manfiy.
Demak $(2m^5 - 7n^4)^2$.

Javob: $(2m^5-7n^4)^2$.

### 18 [D]
$x^2 - 12x = (x - 6)^2 - 36$.
$x^2 - 12x + 40 = (x - 6)^2 + 4$.

Javob: $(x-6)^2+4$.

### 19 [A]
$x^2 + 10x = (x + 5)^2 - 25$.
$x^2 + 10x + 29 = (x + 5)^2 + 4$.

Javob: $(x+5)^2+4$.

### 20 [C]
Guruhlaymiz: $(x^2 + 2xy + y^2) + (y^2 + 10y + 25) + 2$.
$= (x + y)^2 + (y + 5)^2 + 2$.

Javob: $(x+y)^2+(y+5)^2+2$.

### 21 [A]
$(x - 5)^2 + (x + 5)^2 = 2x^2 + 50 = 2 \cdot 7 + 50 = 64$.

Javob: $64$.

### 22 [B]
$x^2 - 10x + 29 = (x - 5)^2 + 4 \ge 4$.
Demak ifoda $(0; 8]$ oraliqdagi barça qiymatlarni qabul qiladi.
Butun qiymatlar: $1, 2, \ldots, 8$, ya'ni $8$ ta.

Javob: $8$.

## 3-test

### 1 [C]
Kvadratlar ayirmasi: $(y - 11)(y + 11) = y^2 - 121$.

Javob: $y^2-121$.

### 2 [A]
$(4p^{-2})^2 - (2q^{-1})^2 = 16p^{-4} - 4q^{-2}$.

Javob: $16p^{-4}-4q^{-2}$.

### 3 [B]
$(m - 5)(m + 5) = m^2 - 25$;
$(m^2 - 25)(m^2 + 25) = m^4 - 625$.

Javob: $m^4-625$.

### 4 [A]
$503 \cdot 497 = (500 + 3)(500 - 3) = 250\,000 - 9 = 249\,991$.

Javob: $249\,991$.

### 5 [C]
Yiğindining kvadrati: $(5p + 1)^2 = 25p^2 + 10p + 1$.

Javob: $25p^2+10p+1$.

### 6 [D]
Ayirmaning kvadrati: $(3q - 4)^2 = 9q^2 - 24q + 16$.

Javob: $9q^2-24q+16$.

### 7 [B]
Örta had $2 \cdot m \cdot \dfrac{5}{m} = 10$:
$\left(m + \dfrac{5}{m}\right)^2 = m^2 + 10 + \dfrac{25}{m^2}$.

Javob: $m^2+10+\dfrac{25}{m^2}$.

### 8 [C]
Örta had $2 \cdot m \cdot \dfrac{6}{m} = 12$:
$\left(m - \dfrac{6}{m}\right)^2 = m^2 - 12 + \dfrac{36}{m^2}$.

Javob: $m^2-12+\dfrac{36}{m^2}$.

### 9 [B]
$10005^2 = (10\,000 + 5)^2 = 100\,000\,000 + 100\,000 + 25 = 100\,100\,025$.

Javob: $100\,100\,025$.

### 10 [D]
$9996^2 = (10\,000 - 4)^2 = 100\,000\,000 - 80\,000 + 16 = 99\,920\,016$.

Javob: $99\,920\,016$.

### 11 [D]
Uç had yiğindisining kvadrati, bunda $a = 5r$, $b = -2s$, $c = 3t$:
$25r^2 + 4s^2 + 9t^2 - 20rs + 30rt - 12st$.

Javob: $25r^2+4s^2+9t^2-20rs+30rt-12st$.

### 12 [A]
$(4p + q)^2 + (4p - q)^2 = 32p^2 + 2q^2$.
$32p^2 + 2q^2 - 2(16p^2 + q^2) = 0$.

Javob: $0$.

### 13 [A]
$A = 3x^2 - 2x + 5$, $B = 3x^2 + 2x - 5$ deb, $A^2 - B^2 = (A - B)(A + B)$.
$A - B = -4x + 10$, $A + B = 6x^2$.
$(-4x + 10) \cdot 6x^2 = -24x^3 + 60x^2$.

Javob: $-24x^3+60x^2$.

### 14 [C]
$(ax - 2)^2 = a^2x^2 - 4ax + 4$, demak $a^2 = 25$, $b = 4a$, $b^2 = 16a^2 = 400$.
$a^2 - b^2 = 25 - 400 = -375$.

Javob: $-375$.

### 15 [B]
$a^2 = 4$, $2ab = 20$, ya'ni $ab = 10$. $a = 2$ da $b = 5$.
$a^2 - b^2 = 4 - 25 = -21$.

Javob: $-21$.

### 16 [A]
$4p^{12} = (2p^6)^2$, $9p^4 = (3p^2)^2$, $12p^8 = 2 \cdot 2p^6 \cdot 3p^2$, örta had manfiy.
Demak $(2p^6 - 3p^2)^2$.

Javob: $(2p^6-3p^2)^2$.

### 17 [C]
$36p^4 = (6p^2)^2$, $25q^{10} = (5q^5)^2$, $60p^2q^5 = 2 \cdot 6p^2 \cdot 5q^5$.
Demak $(6p^2 + 5q^5)^2$.

Javob: $(6p^2+5q^5)^2$.

### 18 [D]
$x^2 - 14x = (x - 7)^2 - 49$.
$x^2 - 14x + 58 = (x - 7)^2 + 9$.

Javob: $(x-7)^2+9$.

### 19 [B]
$x^2 + 12x = (x + 6)^2 - 36$.
$x^2 + 12x + 40 = (x + 6)^2 + 4$.

Javob: $(x+6)^2+4$.

### 20 [C]
Guruhlaymiz: $(x^2 + 2xy + y^2) + (y^2 + 2y + 1) + 6$.
$= (x + y)^2 + (y + 1)^2 + 6$.

Javob: $(x+y)^2+(y+1)^2+6$.

### 21 [A]
$(x - 3)^2 + (x + 3)^2 = 2x^2 + 18 = 2 \cdot 20 + 18 = 58$.

Javob: $58$.

### 22 [D]
$x^2 + 12x + 41 = (x + 6)^2 + 5 \ge 5$.
Demak ifoda $(0; 9]$ oraliqdagi barça qiymatlarni qabul qiladi.
Butun qiymatlar: $1, 2, \ldots, 9$, ya'ni $9$ ta.

Javob: $9$.
