# 42. Ratsional tengsizliklar 2-qism

## 1-test

### 1 [B]
Birinçi tengsizlik: $2x^2 + 4x + 10 \le 26 \Rightarrow x^2 + 2x - 8 \le 0 \Rightarrow (x + 4)(x - 2) \le 0$, ya'ni $[-4; 2]$.
Ikkinçisi: $(x + 2)(x - 1) \ge 0$, ya'ni $(-\infty; -2] \cup [1; +\infty)$.
Kesişmasini olamiz.

Javob: $[-4; -2] \cup [1; 2]$.

### 2 [C]
Qöş tengsizlikni ikkita tengsizlikka ajratamiz.
Çap qismi: $0 < x^2 + 4x + 9$, diskriminant $16 - 36 < 0$, har doim bajariladi.
Öng qismi: $x^2 - 8x + 7 < 0 \Rightarrow (x - 1)(x - 7) < 0$, ya'ni $(1; 7)$.
Butun yeçimlar $2, 3, 4, 5, 6$, jami $5$ ta.

Javob: $5$.

### 3 [A]
$x^2 + 4x + 4 = (x + 2)^2 = t > 0$ deymiz. Unda $\dfrac{1}{t} > \dfrac{1}{25} \Rightarrow t < 25$ va $\dfrac{1}{t} < \dfrac{1}{4} \Rightarrow t > 4$.
$4 < (x + 2)^2 < 25 \Rightarrow 2 < |x + 2| < 5$.
$x + 2 \in (2; 5)$ yoki $x + 2 \in (-5; -2)$, ya'ni $x \in (0; 3)$ yoki $x \in (-7; -4)$.

Javob: $(-7; -4) \cup (0; 3)$.

### 4 [D]
$t = x^4$ deymiz: $t^2 - 82t + 81 \le 0 \Rightarrow (t - 1)(t - 81) \le 0$, ya'ni $1 \le x^4 \le 81$.
Bundan $1 \le |x| \le 3$.

Javob: $[-3; -1] \cup [1; 3]$.

### 5 [B]
$t = x^2 + 4x + 5 = (x + 2)^2 + 1 \ge 1$ deymiz: $t(t + 1) \ge 30 \Rightarrow (t + 6)(t - 5) \ge 0$.
$t + 6 > 0$, demak $t \ge 5$: $x^2 + 4x \ge 0 \Rightarrow x(x + 4) \ge 0$.

Javob: $(-\infty; -4] \cup [0; +\infty)$.

### 6 [A]
Köpaytuvçilarni juftlaymiz: $(x + 3)x = x^2 + 3x$, $(x + 2)(x + 1) = x^2 + 3x + 2$.
$t = x^2 + 3x$: $t(t + 2) \le 24 \Rightarrow (t + 6)(t - 4) \le 0$, ya'ni $-6 \le t \le 4$.
$x^2 + 3x + 6 \ge 0$ har doim bajariladi; $x^2 + 3x - 4 \le 0 \Rightarrow (x + 4)(x - 1) \le 0$.

Javob: $[-4; 1]$.

### 7 [C]
$t = x^2 + 2x + 1 = (x + 1)^2$ deymiz, unda $x^2 + 2x - 1 = t - 2$.
$(t - 2)^2 + t \le 58 \Rightarrow t^2 - 3t - 54 \le 0 \Rightarrow (t - 9)(t + 6) \le 0$, ya'ni $t \le 9$.
$(x + 1)^2 \le 9 \Rightarrow -3 \le x + 1 \le 3$.

Javob: $[-4; 2]$.

### 8 [A]
Bir tomonga ötkazamiz: $(x + 1)^4\bigl((x + 1)^5 - 1\bigr) \ge 0$.
Yo $x + 1 = 0$, yo $(x + 1)^5 \ge 1 \Rightarrow x + 1 \ge 1 \Rightarrow x \ge 0$.

Javob: $\{-1\} \cup [0; +\infty)$.

### 9 [B]
$x^{18} = (x^2)^9$. Toq daraja ösuvçi funksiya, demak $x + 6 \ge x^2$.
$x^2 - x - 6 \le 0 \Rightarrow (x - 3)(x + 2) \le 0$.

Javob: $[-2; 3]$.

### 10 [D]
Juft daraja: $a^{10} > b^{10} \Leftrightarrow |a| > |b|$. $x^2 + x - 6 = (x + 3)(x - 2)$.
$|x + 3| > |x + 3| \cdot |x - 2|$, bunda $x \ne -3$; $|x + 3| > 0$ ga bölamiz: $|x - 2| < 1$.
$1 < x < 3$.

Javob: $(1; 3)$.

### 11 [A]
Kasrlarning butun qismini ajratamiz: $\dfrac{x^2 + x + 2}{x + 1} = x + \dfrac{2}{x + 1}$, $\dfrac{x^3 - 4x^2 + 3}{x - 4} = x^2 + \dfrac{3}{x - 4}$.
Tengsizlik: $\dfrac{2}{x + 1} + \dfrac{3}{x - 4} \ge 0 \Rightarrow \dfrac{5(x - 1)}{(x + 1)(x - 4)} \ge 0$.
Nollar $-1, 1, 4$; işoralar öngdan çapga $+, -, +, -$.

Javob: $(-1; 1] \cup (4; +\infty)$.

### 12 [C]
Birinçi: $\dfrac{x - 2}{(x - 2)(x - 7)} < 0 \Rightarrow x \ne 2$, $x < 7$.
Ikkinçi: kasr nolga teng emas, demak $(x - 10)(x + 1) < 0$, ya'ni $(-1; 10)$.
Kesişma: $(-1; 2) \cup (2; 7)$. Butun yeçimlar: $0, 1, 3, 4, 5, 6$.
Ayirma: $6 - 0 = 6$.

Javob: $6$.

### 13 [D]
Ildiz osti manfiy emas: $-x^2 - 2x + 24 \ge 0 \Rightarrow (x + 6)(x - 4) \le 0$, ya'ni $[-6; 4]$.
Butun sonlar $-6, -5, \dots, 4$. $-4$ dan $4$ gaça yiğindi $0$, qoladi $-6 - 5 = -11$.

Javob: $-11$.

### 14 [C]
Ildiz osti: $\dfrac{x^2 - 9}{49 - x^2} \ge 0 \Leftrightarrow \dfrac{x^2 - 9}{x^2 - 49} \le 0$, ya'ni $9 \le x^2 < 49$.
Natural sonlar: $3, 4, 5, 6$.

Javob: $4$.

### 15 [B]
Şartlar: $x^2 - 16 \ge 0 \Rightarrow |x| \ge 4$; $(x - 7)(x + 2) \ge 0 \Rightarrow x \le -2$ yoki $x \ge 7$.
Aniqlaniş sohasi: $(-\infty; -4] \cup [7; +\infty)$.
Kirmaydigan butun sonlar: $-3, -2, \dots, 6$, jami $10$ ta.

Javob: $10$.

### 16 [D]
Şartlar: $-x^2 + 7x \ge 0 \Rightarrow x(x - 7) \le 0$, ya'ni $[0; 7]$, hamda $x \ne 3$.
$[0; 7]$ da $8$ ta butun son, $3$ ni çiqarsak $7$ ta.

Javob: $7$.

## 2-test

### 1 [B]
Birinçi: $2x^2 - 16x + 34 \le 20 \Rightarrow x^2 - 8x + 7 \le 0$, ya'ni $[1; 7]$.
Ikkinçi: $(x - 2)(x - 6) \ge 0$, ya'ni $(-\infty; 2] \cup [6; +\infty)$.
Kesişma.

Javob: $[1; 2] \cup [6; 7]$.

### 2 [C]
Çap qismi: $0 < x^2 - 6x + 11$, diskriminant $36 - 44 < 0$, har doim bajariladi.
Öng qismi: $x^2 < 16$, ya'ni $(-4; 4)$.
Butun yeçimlar $-3, \dots, 3$, jami $7$ ta.

Javob: $7$.

### 3 [A]
$t = (x - 3)^2 > 0$: $\dfrac{1}{t} > \dfrac{1}{9} \Rightarrow t < 9$, $\dfrac{1}{t} < 1 \Rightarrow t > 1$.
$1 < |x - 3| < 3$, ya'ni $x - 3 \in (1; 3)$ yoki $x - 3 \in (-3; -1)$.

Javob: $(0; 2) \cup (4; 6)$.

### 4 [C]
$t = x^4$: $t^2 - 272t + 4096 \le 0 \Rightarrow (t - 16)(t - 256) \le 0$, ya'ni $16 \le x^4 \le 256$.
Bundan $2 \le |x| \le 4$.

Javob: $[-4; -2] \cup [2; 4]$.

### 5 [D]
$t = x^2 - 2x + 4 = (x - 1)^2 + 3 \ge 3$: $t(t + 1) \ge 56 \Rightarrow (t + 8)(t - 7) \ge 0$, demak $t \ge 7$.
$x^2 - 2x - 3 \ge 0 \Rightarrow (x - 3)(x + 1) \ge 0$.

Javob: $(-\infty; -1] \cup [3; +\infty)$.

### 6 [B]
Juftlaymiz: $(x - 2)(x - 5) = x^2 - 7x + 10$, $(x - 3)(x - 4) = x^2 - 7x + 12$.
$t = x^2 - 7x + 10$: $t(t + 2) \le 120 \Rightarrow (t + 12)(t - 10) \le 0$, ya'ni $-12 \le t \le 10$.
$x^2 - 7x + 22 \ge 0$ har doim bajariladi; $x^2 - 7x \le 0 \Rightarrow x \in [0; 7]$.

Javob: $[0; 7]$.

### 7 [D]
$t = x^2 - 6x + 9 = (x - 3)^2$, unda $x^2 - 6x + 8 = t - 1$.
$(t - 1)^2 + t \le 13 \Rightarrow t^2 - t - 12 \le 0 \Rightarrow (t - 4)(t + 3) \le 0$, ya'ni $t \le 4$.
$|x - 3| \le 2$.

Javob: $[1; 5]$.

### 8 [A]
$(x - 3)^6\bigl((x - 3)^5 - 1\bigr) \ge 0$.
Yo $x = 3$, yo $x - 3 \ge 1 \Rightarrow x \ge 4$.

Javob: $\{3\} \cup [4; +\infty)$.

### 9 [C]
$x^{10} = (x^2)^5$, toq daraja ösuvçi: $7x - 10 \ge x^2$.
$x^2 - 7x + 10 \le 0 \Rightarrow (x - 2)(x - 5) \le 0$.

Javob: $[2; 5]$.

### 10 [B]
Juft daraja: $|x - 5| > |x(x - 5)| = |x| \cdot |x - 5|$, bunda $x \ne 5$.
$|x - 5|$ ga bölamiz: $|x| < 1$.

Javob: $(-1; 1)$.

### 11 [A]
Butun qismini ajratamiz: $\dfrac{x^2 - x - 4}{x - 1} = x - \dfrac{4}{x - 1}$, $\dfrac{x^3 - 6x^2 + 2}{x - 6} = x^2 + \dfrac{2}{x - 6}$.
Tengsizlik: $-\dfrac{4}{x - 1} + \dfrac{2}{x - 6} \ge 0 \Rightarrow \dfrac{-2(x - 11)}{(x - 1)(x - 6)} \ge 0 \Rightarrow \dfrac{x - 11}{(x - 1)(x - 6)} \le 0$.
Nollar $1, 6, 11$; işoralar öngdan çapga $+, -, +, -$.

Javob: $(-\infty; 1) \cup (6; 11]$.

### 12 [D]
Birinçi: $\dfrac{x + 4}{(x - 5)(x + 4)} < 0 \Rightarrow x \ne -4$, $x < 5$.
Ikkinçi: $(x - 8)(x + 2) < 0$, ya'ni $(-2; 8)$.
Kesişma: $(-2; 5)$. Butun yeçimlar $-1, \dots, 4$.
Ayirma: $4 - (-1) = 5$.

Javob: $5$.

### 13 [C]
$-x^2 + 6x \ge 0 \Rightarrow x(x - 6) \le 0$, ya'ni $[0; 6]$.
Butun sonlar yiğindisi: $0 + 1 + \dots + 6 = 21$.

Javob: $21$.

### 14 [D]
$\dfrac{x^2 - 1}{36 - x^2} \ge 0 \Leftrightarrow 1 \le x^2 < 36$.
Natural sonlar: $1, 2, 3, 4, 5$.

Javob: $5$.

### 15 [B]
Şartlar: $|x| \ge 2$; $(x - 1)(x - 5) \ge 0 \Rightarrow x \le 1$ yoki $x \ge 5$.
Aniqlaniş sohasi: $(-\infty; -2] \cup [5; +\infty)$.
Kirmaydigan butun sonlar: $-1, 0, 1, 2, 3, 4$, jami $6$ ta.

Javob: $6$.

### 16 [A]
Şartlar: $x^2 - 2x - 15 \le 0 \Rightarrow (x - 5)(x + 3) \le 0$, ya'ni $[-3; 5]$, hamda $x \ne 0$.
$[-3; 5]$ da $9$ ta butun son, $0$ ni çiqarsak $8$ ta.

Javob: $8$.

## 3-test

### 1 [B]
Birinçi: $2x^2 - 4x + 10 \le 40 \Rightarrow x^2 - 2x - 15 \le 0$, ya'ni $[-3; 5]$.
Ikkinçi: $x(x - 4) \ge 0$, ya'ni $(-\infty; 0] \cup [4; +\infty)$.
Kesişma.

Javob: $[-3; 0] \cup [4; 5]$.

### 2 [C]
Çap qismi: $0 < x^2 + 6$, har doim bajariladi.
Öng qismi: $x^2 - 11x + 18 < 0 \Rightarrow (x - 2)(x - 9) < 0$, ya'ni $(2; 9)$.
Butun yeçimlar $3, \dots, 8$, jami $6$ ta.

Javob: $6$.

### 3 [A]
$t = x^2 > 0$: $\dfrac{1}{t} > \dfrac{1}{36} \Rightarrow t < 36$, $\dfrac{1}{t} < \dfrac{1}{4} \Rightarrow t > 4$.
$4 < x^2 < 36 \Rightarrow 2 < |x| < 6$.

Javob: $(-6; -2) \cup (2; 6)$.

### 4 [D]
$t = x^4$: $(t - 1)(t - 256) \le 0$, ya'ni $1 \le x^4 \le 256$, bundan $1 \le |x| \le 4$.

Javob: $[-4; -1] \cup [1; 4]$.

### 5 [C]
$t = x^2 + 2 \ge 2$: $t(t + 1) \ge 132 \Rightarrow (t + 12)(t - 11) \ge 0$, demak $t \ge 11$.
$x^2 \ge 9 \Rightarrow |x| \ge 3$.

Javob: $(-\infty; -3] \cup [3; +\infty)$.

### 6 [B]
Juftlaymiz: $(x - 4)(x - 7) = x^2 - 11x + 28$, $(x - 5)(x - 6) = x^2 - 11x + 30$.
$t = x^2 - 11x + 28$: $t(t + 2) \le 24 \Rightarrow -6 \le t \le 4$.
$x^2 - 11x + 34 \ge 0$ har doim; $x^2 - 11x + 24 \le 0 \Rightarrow (x - 3)(x - 8) \le 0$.

Javob: $[3; 8]$.

### 7 [D]
$t = x^2$: $(t - 3)^2 + t \le 185 \Rightarrow t^2 - 5t - 176 \le 0 \Rightarrow (t - 16)(t + 11) \le 0$.
$t \ge 0$ bölgani uçun $x^2 \le 16$, ya'ni $|x| \le 4$.

Javob: $[-4; 4]$.

### 8 [A]
$(x + 2)^2\bigl((x + 2)^5 - 1\bigr) \ge 0$.
Yo $x = -2$, yo $x + 2 \ge 1 \Rightarrow x \ge -1$.

Javob: $\{-2\} \cup [-1; +\infty)$.

### 9 [C]
$x^{14} = (x^2)^7$, toq daraja ösuvçi: $-2x + 3 \ge x^2$.
$x^2 + 2x - 3 \le 0 \Rightarrow (x + 3)(x - 1) \le 0$.

Javob: $[-3; 1]$.

### 10 [B]
$x^2 + x - 12 = (x + 4)(x - 3)$. Juft daraja: $|x + 4| > |x + 4| \cdot |x - 3|$, $x \ne -4$.
Bölsak: $|x - 3| < 1$, ya'ni $2 < x < 4$.

Javob: $(2; 4)$.

### 11 [A]
Butun qismini ajratamiz: $\dfrac{x^2 + 2x + 4}{x + 2} = x + \dfrac{4}{x + 2}$, $\dfrac{x^3 - 3x^2 + 1}{x - 3} = x^2 + \dfrac{1}{x - 3}$.
Tengsizlik: $\dfrac{4}{x + 2} + \dfrac{1}{x - 3} \ge 0 \Rightarrow \dfrac{5(x - 2)}{(x + 2)(x - 3)} \ge 0$.
Nollar $-2, 2, 3$; işoralar öngdan çapga $+, -, +, -$.

Javob: $(-2; 2] \cup (3; +\infty)$.

### 12 [D]
Birinçi: $\dfrac{x - 1}{(x - 1)(x - 8)} < 0 \Rightarrow x \ne 1$, $x < 8$.
Ikkinçi: $(x - 2)(x - 11) < 0$, ya'ni $(2; 11)$.
Kesişma $(2; 8)$, butun yeçimlar $3, \dots, 7$.
Ayirma: $7 - 3 = 4$.

Javob: $4$.

### 13 [B]
$-x^2 - 4x + 12 \ge 0 \Rightarrow (x + 6)(x - 2) \le 0$, ya'ni $[-6; 2]$.
$-2$ dan $2$ gaça yiğindi $0$, qoladi $-6 - 5 - 4 - 3 = -18$.

Javob: $-18$.

### 14 [B]
$\dfrac{x^2 - 4}{81 - x^2} \ge 0 \Leftrightarrow 4 \le x^2 < 81$.
Natural sonlar: $2, 3, \dots, 8$, jami $7$ ta.

Javob: $7$.

### 15 [D]
Şartlar: $|x| \ge 5$; $(x - 8)(x + 3) \ge 0 \Rightarrow x \le -3$ yoki $x \ge 8$.
Aniqlaniş sohasi: $(-\infty; -5] \cup [8; +\infty)$.
Kirmaydigan butun sonlar: $-4, \dots, 7$, jami $12$ ta.

Javob: $12$.

### 16 [C]
Şartlar: $x^2 - 13x + 22 \le 0 \Rightarrow (x - 2)(x - 11) \le 0$, ya'ni $[2; 11]$, hamda $x \ne 7$.
$[2; 11]$ da $10$ ta butun son, $7$ ni çiqarsak $9$ ta.

Javob: $9$.
