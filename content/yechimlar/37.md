# 37. Viyet teoremasi 2-qism

## 1-test

### 1 [A]
Avval berilgan tenglamaning ildizlarini topamiz: $x^2 + 11x + 18 = (x+2)(x+9)$, ya'ni $x_1 = -2$, $x_2 = -9$.
Yangi ildizlar 3 ga katta: $y_1 = 1$, $y_2 = -6$.
Viyet teoremasiga köra: $y_1 + y_2 = -5$, $y_1 y_2 = -6$, demak tenglama $y^2 + 5y - 6 = 0$.

Javob: $x^2 + 5x - 6 = 0$.

### 2 [D]
$x^2 - 2x - 3 = (x-3)(x+1)$, ildizlar $x_1 = 3$, $x_2 = -1$.
Yangi ildizlar: $3 + \dfrac{1}{-1} = 2$ va $-1 + \dfrac{1}{3} = -\dfrac{2}{3}$.
Yiğindisi $\dfrac{4}{3}$, köpaytmasi $-\dfrac{4}{3}$. Viyet böyiça $x^2 - \dfrac{4}{3}x - \dfrac{4}{3} = 0$, 3 ga köpaytiramiz.

Javob: $3x^2 - 4x - 4 = 0$.

### 3 [B]
Kub tenglama $ax^3 + bx^2 + cx + d = 0$ uçun Viyet teoremasi: $x_1x_2 + x_2x_3 + x_3x_1 = \dfrac{c}{a}$.
Bu yerda $a = 3$, $c = -15$: $\dfrac{-15}{3} = -5$.

Javob: $-5$.

### 4 [D]
Viyet teoremasi: $x_1 + x_2 + x_3 = -\dfrac{b}{a} = 5$, $x_1x_2x_3 = -\dfrac{d}{a} = -24$.
$5 - (-24) = 29$.

Javob: $29$.

### 5 [C]
Kasrlarni umumiy maxrajga keltiramiz: $\dfrac{1}{x_1} + \dfrac{1}{x_2} + \dfrac{1}{x_3} = \dfrac{x_1x_2 + x_2x_3 + x_3x_1}{x_1x_2x_3}$.
Viyet böyiça: $x_1x_2 + x_2x_3 + x_3x_1 = 3$, $x_1x_2x_3 = -10$.
$\dfrac{3}{-10} = -\dfrac{3}{10}$.

Javob: $-\dfrac{3}{10}$.

### 6 [A]
Formula: $x_1^2 + x_2^2 + x_3^2 = (x_1 + x_2 + x_3)^2 - 2(x_1x_2 + x_2x_3 + x_3x_1)$.
Viyet böyiça yiğindi $4$, juft köpaytmalar yiğindisi $-11$.
$16 - 2 \cdot (-11) = 16 + 22 = 38$.

Javob: $38$.

### 7 [D]
Umumiy maxrajga keltiramiz: $\dfrac{1}{x_1x_2} + \dfrac{1}{x_2x_3} + \dfrac{1}{x_3x_1} = \dfrac{x_3 + x_1 + x_2}{x_1x_2x_3}$.
Viyet böyiça: $x_1 + x_2 + x_3 = 6$, $x_1x_2x_3 = -12$.
$\dfrac{6}{-12} = -\dfrac{1}{2}$.

Javob: $-\dfrac{1}{2}$.

### 8 [C]
$P(x) = x^3 - 9x^2 + 18x = (x - x_1)(x - x_2)(x - x_3)$ bölgani uçun $(2 - x_1)(2 - x_2)(2 - x_3) = P(2)$.
$P(2) = 8 - 36 + 36 = 8$.
Har qavsda işorani almaştirsak, uç marta $-1$ çiqadi: $(x_1 - 2)(x_2 - 2)(x_3 - 2) = -P(2) = -8$.

Javob: $-8$.

### 9 [B]
Har kasrni bölamiz: $\dfrac{x^2 + 3}{x} = x + \dfrac{3}{x}$. Demak ifoda $(x_1 + x_2) + 3\left(\dfrac{1}{x_1} + \dfrac{1}{x_2}\right) = (x_1 + x_2) + \dfrac{3(x_1 + x_2)}{x_1x_2}$.
Viyet böyiça $x_1 + x_2 = 7$, $x_1x_2 = 10$.
$7 + \dfrac{21}{10} = \dfrac{91}{10}$.

Javob: $\dfrac{91}{10}$.

### 10 [C]
Qavslarni oçamiz: $(3x_1 - 4)^2 + (3x_2 - 4)^2 = 9(x_1^2 + x_2^2) - 24(x_1 + x_2) + 32$.
Viyet böyiça $x_1 + x_2 = 6$, $x_1x_2 = 5$, $x_1^2 + x_2^2 = 36 - 10 = 26$.
$9 \cdot 26 - 24 \cdot 6 + 32 = 234 - 144 + 32 = 122$.

Javob: $122$.

### 11 [A]
$x^2 - 7x + 10 = (x-2)(x-5)$, ildizlar $2$ va $5$.
$|x_1^2 - x_2^2| = |4 - 25| = 21$.

Javob: $21$.

### 12 [A]
Tenglamadan $x^2 = 5x - 3$, demak $x^2 - 4x = x - 3$.
Ifoda: $x - 3 + \dfrac{3}{x} = \dfrac{x^2 - 3x + 3}{x} = \dfrac{5x - 3 - 3x + 3}{x} = \dfrac{2x}{x} = 2$.

Javob: $2$.

## 2-test

### 1 [A]
$x^2 + 8x - 20 = (x+10)(x-2)$, ildizlar $-10$ va $2$.
Yangi ildizlar 5 ga katta: $-5$ va $7$.
Viyet böyiça yiğindi $2$, köpaytma $-35$, demak tenglama $x^2 - 2x - 35 = 0$.

Javob: $x^2 - 2x - 35 = 0$.

### 2 [B]
$x^2 - 4 = 0$ ning ildizlari $x_1 = 2$, $x_2 = -2$.
Yangi ildizlar: $2 + \dfrac{1}{-2} = \dfrac{3}{2}$ va $-2 + \dfrac{1}{2} = -\dfrac{3}{2}$.
Yiğindi $0$, köpaytma $-\dfrac{9}{4}$: $x^2 - \dfrac{9}{4} = 0$, 4 ga köpaytiramiz.

Javob: $4x^2 - 9 = 0$.

### 3 [D]
Kub tenglama uçun Viyet teoremasi: $x_1x_2 + x_2x_3 + x_3x_1 = \dfrac{c}{a}$.
$\dfrac{24}{2} = 12$.

Javob: $12$.

### 4 [C]
Viyet böyiça: $x_1 + x_2 + x_3 = -\dfrac{-2}{2} = 1$, $x_1x_2x_3 = -\dfrac{-30}{2} = 15$.
$1 - 15 = -14$.

Javob: $-14$.

### 5 [B]
$\dfrac{1}{x_1} + \dfrac{1}{x_2} + \dfrac{1}{x_3} = \dfrac{x_1x_2 + x_2x_3 + x_3x_1}{x_1x_2x_3}$.
Viyet böyiça surat $36$, maxraj $36$.
$\dfrac{36}{36} = 1$.

Javob: $1$.

### 6 [A]
$x_1^2 + x_2^2 + x_3^2 = (x_1 + x_2 + x_3)^2 - 2(x_1x_2 + x_2x_3 + x_3x_1)$.
Viyet böyiça yiğindi $-1$, juft köpaytmalar yiğindisi $-10$.
$1 + 20 = 21$.

Javob: $21$.

### 7 [C]
$\dfrac{1}{x_1x_2} + \dfrac{1}{x_2x_3} + \dfrac{1}{x_3x_1} = \dfrac{x_1 + x_2 + x_3}{x_1x_2x_3}$.
Viyet böyiça $x_1 + x_2 + x_3 = 4$, $x_1x_2x_3 = -30$.
$\dfrac{4}{-30} = -\dfrac{2}{15}$.

Javob: $-\dfrac{2}{15}$.

### 8 [D]
$P(x) = (x - x_1)(x - x_2)(x - x_3)$ bölgani uçun $(-1 - x_1)(-1 - x_2)(-1 - x_3) = P(-1)$.
$P(-1) = -1 - 6 + 9 + 14 = 16$.
Har qavsdan $-1$ çiqarsak: $(x_1 + 1)(x_2 + 1)(x_3 + 1) = -P(-1) = -16$.

Javob: $-16$.

### 9 [C]
$\dfrac{x^2 + 4}{x} = x + \dfrac{4}{x}$, demak ifoda $(x_1 + x_2) + \dfrac{4(x_1 + x_2)}{x_1x_2}$.
Viyet böyiça $x_1 + x_2 = 4$, $x_1x_2 = -12$.
$4 + \dfrac{16}{-12} = 4 - \dfrac{4}{3} = \dfrac{8}{3}$.

Javob: $\dfrac{8}{3}$.

### 10 [A]
Qavslarni oçamiz: $25(x_1^2 + x_2^2) - 20(x_1 + x_2) + 8$.
Viyet böyiça $x_1 + x_2 = 2$, $x_1x_2 = -8$, $x_1^2 + x_2^2 = 4 + 16 = 20$.
$25 \cdot 20 - 20 \cdot 2 + 8 = 500 - 40 + 8 = 468$.

Javob: $468$.

### 11 [D]
$|x_1^2 - x_2^2| = |x_1 - x_2| \cdot |x_1 + x_2|$.
Viyet böyiça $x_1 + x_2 = 6$, $x_1x_2 = -3$, $(x_1 - x_2)^2 = 36 + 12 = 48$, $|x_1 - x_2| = 4\sqrt{3}$.
$4\sqrt{3} \cdot 6 = 24\sqrt{3}$.

Javob: $24\sqrt{3}$.

### 12 [B]
Tenglamadan $x^2 = 6x - 5$, demak $x^2 - 4x = 2x - 5$.
Ifoda: $2x - 5 + \dfrac{10}{x} = \dfrac{2x^2 - 5x + 10}{x} = \dfrac{12x - 10 - 5x + 10}{x} = \dfrac{7x}{x} = 7$.

Javob: $7$.

## 3-test

### 1 [C]
$x^2 + 7x - 8 = (x+8)(x-1)$, ildizlar $-8$ va $1$.
Yangi ildizlar 6 ga katta: $-2$ va $7$.
Viyet böyiça yiğindi $5$, köpaytma $-14$: $x^2 - 5x - 14 = 0$.

Javob: $x^2 - 5x - 14 = 0$.

### 2 [D]
$x^2 - 3x - 4 = (x-4)(x+1)$, ildizlar $4$ va $-1$.
Yangi ildizlar: $4 + \dfrac{1}{-1} = 3$ va $-1 + \dfrac{1}{4} = -\dfrac{3}{4}$.
Yiğindi $\dfrac{9}{4}$, köpaytma $-\dfrac{9}{4}$: $x^2 - \dfrac{9}{4}x - \dfrac{9}{4} = 0$, 4 ga köpaytiramiz.

Javob: $4x^2 - 9x - 9 = 0$.

### 3 [B]
Kub tenglama uçun Viyet: $x_1x_2 + x_2x_3 + x_3x_1 = \dfrac{c}{a}$.
$\dfrac{-48}{4} = -12$.

Javob: $-12$.

### 4 [D]
Viyet böyiça: $x_1 + x_2 + x_3 = -\dfrac{-3}{3} = 1$, $x_1x_2x_3 = -\dfrac{72}{3} = -24$.
$1 - (-24) = 25$.

Javob: $25$.

### 5 [A]
$\dfrac{1}{x_1} + \dfrac{1}{x_2} + \dfrac{1}{x_3} = \dfrac{x_1x_2 + x_2x_3 + x_3x_1}{x_1x_2x_3}$.
Viyet böyiça surat $4$, maxraj $-48$.
$\dfrac{4}{-48} = -\dfrac{1}{12}$.

Javob: $-\dfrac{1}{12}$.

### 6 [C]
$x_1^2 + x_2^2 + x_3^2 = (x_1 + x_2 + x_3)^2 - 2(x_1x_2 + x_2x_3 + x_3x_1)$.
Viyet böyiça yiğindi $8$, juft köpaytmalar yiğindisi $9$.
$64 - 18 = 46$.

Javob: $46$.

### 7 [B]
$\dfrac{1}{x_1x_2} + \dfrac{1}{x_2x_3} + \dfrac{1}{x_3x_1} = \dfrac{x_1 + x_2 + x_3}{x_1x_2x_3}$.
Viyet böyiça $x_1 + x_2 + x_3 = -1$, $x_1x_2x_3 = 24$.
$\dfrac{-1}{24} = -\dfrac{1}{24}$.

Javob: $-\dfrac{1}{24}$.

### 8 [B]
$P(x) = (x - x_1)(x - x_2)(x - x_3)$ uçun $(3 - x_1)(3 - x_2)(3 - x_3) = P(3)$.
$P(3) = 27 - 117 + 132 - 32 = 10$.
Işoralarni almaştirsak: $(x_1 - 3)(x_2 - 3)(x_3 - 3) = -P(3) = -10$.

Javob: $-10$.

### 9 [A]
$\dfrac{x^2 + 2}{x} = x + \dfrac{2}{x}$, demak ifoda $(x_1 + x_2) + \dfrac{2(x_1 + x_2)}{x_1x_2}$.
Viyet böyiça $x_1 + x_2 = 10$, $x_1x_2 = 21$.
$10 + \dfrac{20}{21} = \dfrac{230}{21}$.

Javob: $\dfrac{230}{21}$.

### 10 [B]
Qavslarni oçamiz: $4(x_1^2 + x_2^2) - 20(x_1 + x_2) + 50$.
Viyet böyiça $x_1 + x_2 = -1$, $x_1x_2 = -6$, $x_1^2 + x_2^2 = 1 + 12 = 13$.
$4 \cdot 13 + 20 + 50 = 122$.

Javob: $122$.

### 11 [D]
$x^2 - 4x - 5 = (x-5)(x+1)$, ildizlar $5$ va $-1$.
$|x_1^2 - x_2^2| = |25 - 1| = 24$.

Javob: $24$.

### 12 [A]
Tenglamadan $x^2 = 7x - 6$, demak $x^2 - 5x = 2x - 6$.
Ifoda: $2x - 6 + \dfrac{12}{x} = \dfrac{2x^2 - 6x + 12}{x} = \dfrac{14x - 12 - 6x + 12}{x} = \dfrac{8x}{x} = 8$.

Javob: $8$.
