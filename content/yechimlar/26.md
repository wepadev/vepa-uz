# 26. Çiziqli tenglamalar sistemasi

## 1-test

### 1 [B]
Örniga qöyiş usulini qöllaymiz: $y = -2x + 7$ ni ikkinçi tenglamaga qöyamiz.
$3x + 2(-2x + 7) = 13$, $-x + 14 = 13$, $x = 1$.
$y = -2 + 7 = 5$.

Javob: $(1; 5)$.

### 2 [A]
Tenglamalarni qöşamiz: $2y = 10$, $y = 5$.
Birinçisidan $x = 3 - 5 = -2$.

Javob: $(-2; 5)$.

### 3 [D]
Birinçi tenglamadan $y = 4x + 8$.
Ikkinçisiga qöyamiz: $3x + 2(4x + 8) = 5$, $11x = -11$, $x = -1$.
$y = -4 + 8 = 4$.

Javob: $(-1; 4)$.

### 4 [C]
Qavslarni oçib soddalaştiramiz: $2x + 3y = 10$ va $x + 2y = 7$.
Ikkinçisidan $x = 7 - 2y$, birinçisiga qöyamiz: $14 - 4y + 3y = 10$, $y = 4$.
$x = 7 - 8 = -1$.

Javob: $(-1; 4)$.

### 5 [B]
Birinçi tenglamani $15$ ga köpaytiramiz: $5(2x - y) + 3(x + 4y) = -5$, ya'ni $13x + 7y = -5$.
Ikkinçisidan $x = 2y - 8$: $13(2y - 8) + 7y = -5$, $33y = 99$, $y = 3$.
$x = 6 - 8 = -2$.

Javob: $(-2; 3)$.

### 6 [D]
Ikkinçi tenglamadan: $x + y = 2(x + 2y)$, bundan $x = -3y$.
Birinçisini $20$ ga köpaytiramiz: $5(x + 2) + 4(3y - 1) = 9$, ya'ni $5x + 12y = 3$.
$-15y + 12y = 3$, $y = -1$, $x = 3$ (bunda $x + 2y = 1 \ne 0$).

Javob: $(3; -1)$.

### 7 [C]
Kvadratlar ayirmasi formulasi: $16x^2 - y^2 = (4x - y)(4x + y)$.
$4x + y = 2$ bölgani uçun $2(4x - y) = -20$, ya'ni $4x - y = -10$.
Qöşamiz: $8x = -8$, $x = -1$; $y = 2 - 4x = 6$.

Javob: $(-1; 6)$.

### 8 [A]
Ikkinçi tenglamadan $x = -2 + 3y - z$ ni boşqalarga qöyamiz:
$3(-2 + 3y - z) + y - 2z = -11 \Rightarrow 2y - z = -1$,
$2(-2 + 3y - z) + 2y + 3z = 7 \Rightarrow 8y + z = 11$.
Qöşamiz: $10y = 10$, $y = 1$, $z = 3$, $x = -2 + 3 - 3 = -2$.

Javob: $(-2; 1; 3)$.

### 9 [B]
$x = -2$, $y = 5$ ni qöyamiz: $-2a - 10b = -26$ va $-8a - 5b = -34$.
Ya'ni $a + 5b = 13$ va $8a + 5b = 34$.
Ayiramiz: $7a = 21$, $a = 3$; $5b = 10$, $b = 2$.

Javob: $(3; 2)$.

### 10 [D]
Öng tomonni oçamiz: $Ax^2 + Ax + Bx^2 - 2Bx = (A + B)x^2 + (A - 2B)x$.
Ayniyatda $x^2$ oldidagi koeffitsiyentlar teng: $A + B = 5$.

Javob: $5$.

### 11 [C]
$x^2 - x - 6 = (x - 3)(x + 2)$. Umumiy maxrajga keltiramiz:
$5x - 7 = A(x + 2) + B(x - 3) = (A + B)x + (2A - 3B)$.
$x$ oldidagi koeffitsiyentlar teng: $A + B = 5$.

Javob: $5$.

### 12 [D]
Sistema yeçimga ega bölmasligi uçun $\dfrac{a_1}{a_2} = \dfrac{b_1}{b_2} \ne \dfrac{c_1}{c_2}$ bölişi kerak.
$\dfrac{a - 1}{2a + 4} = \dfrac{2}{-1}$, $a - 1 = -4a - 8$, $5a = -7$, $a = -\dfrac{7}{5}$.
Bunda $\dfrac{3}{-1} = -3 \ne -2$, şart bajariladi.

Javob: $-\dfrac{7}{5}$.

### 13 [B]
Çeksiz köp yeçim uçun barça koeffitsiyentlar proporsional: $\dfrac{a-3}{3a-14} = \dfrac{b+2}{b} = \dfrac{-8}{-4} = 2$.
$a - 3 = 6a - 28$, $a = 5$.
$b + 2 = 2b$, $b = 2$.

Javob: $(5; 2)$.

### 14 [A]
$u = \dfrac{1}{x}$, $v = \dfrac{1}{y}$ belgilaymiz: $3u + 8v = \dfrac{1}{2}$, $7u - 4v = -\dfrac{9}{2}$.
Ikkinçisini $2$ ga köpaytirib qöşamiz: $17u = -\dfrac{17}{2}$, $u = -\dfrac{1}{2}$.
$8v = \dfrac{1}{2} + \dfrac{3}{2} = 2$, $v = \dfrac{1}{4}$.
Demak, $x = -2$, $y = 4$.

Javob: $(-2; 4)$.

### 15 [C]
$u = \dfrac{1}{2x+y}$, $v = \dfrac{1}{x-3y}$: $3u + 5v = 2$, $6u - 2v = \dfrac{8}{5}$.
Birinçisini $2$ ga köpaytirib ayiramiz: $12v = \dfrac{12}{5}$, $v = \dfrac{1}{5}$, $u = \dfrac{1}{3}$.
$2x + y = 3$, $x - 3y = 5$. $x = 5 + 3y$: $10 + 7y = 3$, $y = -1$, $x = 2$.

Javob: $(2; -1)$.

## 2-test

### 1 [B]
$y = 4x + 1$ ni ikkinçi tenglamaga qöyamiz: $5x - 2(4x + 1) = 1$.
$-3x - 2 = 1$, $x = -1$, $y = -4 + 1 = -3$.

Javob: $(-1; -3)$.

### 2 [C]
Tenglamalarni qöşamiz: $2y = -2$, $y = -1$.
$x = 5 - y = 6$.

Javob: $(6; -1)$.

### 3 [A]
Birinçisini $2$ ga, ikkinçisini $3$ ga köpaytirib qöşamiz:
$-6x + 10y = -8$, $6x + 21y = 39$ $\Rightarrow$ $31y = 31$, $y = 1$.
$-3x = -4 - 5 = -9$, $x = 3$.

Javob: $(3; 1)$.

### 4 [B]
Soddalaştiramiz: $3x + 4y = 7$ va $2x + y = 8$.
$y = 8 - 2x$: $3x + 32 - 8x = 7$, $x = 5$, $y = -2$.

Javob: $(5; -2)$.

### 5 [D]
Birinçi tenglamani $12$ ga köpaytiramiz: $3(3x + 2y) + 2(x - 3y) = 44$.
$y$ lar qisqaradi: $11x = 44$, $x = 4$.
$y = 10 - 2x = 2$.

Javob: $(4; 2)$.

### 6 [A]
Ikkinçi tenglamadan: $x + y = -(x + 3y)$, $2x = -4y$, $x = -2y$.
Birinçisini $21$ ga köpaytiramiz: $3(3x + 2) + 7(2y + 5) = 33$, ya'ni $9x + 14y = -8$.
$-18y + 14y = -8$, $y = 2$, $x = -4$.

Javob: $(-4; 2)$.

### 7 [D]
$25x^2 - y^2 = (5x - y)(5x + y) = 91$ va $5x + y = 7$, demak $5x - y = 13$.
Qöşamiz: $10x = 20$, $x = 2$; $y = 7 - 10 = -3$.

Javob: $(2; -3)$.

### 8 [B]
Birinçisidan $z = 11 - 2x + y$ ni qöyamiz:
$-x + 3y + 2(11 - 2x + y) = -3 \Rightarrow x - y = 5$,
$3x + 2y - 2(11 - 2x + y) = 6 \Rightarrow 7x = 28$, $x = 4$.
$y = -1$, $z = 11 - 8 - 1 = 2$.

Javob: $(4; -1; 2)$.

### 9 [D]
$x = 4$, $y = -1$ ni qöyamiz: $12a + 2b = -18$ va $4a + 5b = 7$.
Birinçisidan $b = -9 - 6a$: $4a - 45 - 30a = 7$, $-26a = 52$, $a = -2$.
$b = -9 + 12 = 3$.

Javob: $(-2; 3)$.

### 10 [C]
Öng tomon: $(A + B)x^2 + (3A - B)x$.
$x^2$ oldidagi koeffitsiyentlarni tenglaymiz: $A + B = 7$.

Javob: $7$.

### 11 [D]
$x^2 - 7x + 10 = (x - 2)(x - 5)$, şuning uçun $2x + 9 = A(x - 5) + B(x - 2)$.
$x$ oldidagi koeffitsiyentlar: $A + B = 2$.

Javob: $2$.

### 12 [B]
Yeçim yöq bölişi uçun $\dfrac{a_1}{a_2} = \dfrac{b_1}{b_2} \ne \dfrac{c_1}{c_2}$.
$\dfrac{2a + 3}{a - 5} = \dfrac{-1}{-1} = 1$, $2a + 3 = a - 5$, $a = -8$.
Bunda $\dfrac{2}{7} \ne 1$, şart bajariladi.

Javob: $-8$.

### 13 [C]
Çeksiz köp yeçim uçun $\dfrac{a+1}{a+4} = \dfrac{b-2}{3b-7} = \dfrac{5}{10} = \dfrac{1}{2}$.
$2a + 2 = a + 4$, $a = 2$.
$2b - 4 = 3b - 7$, $b = 3$.

Javob: $(2; 3)$.

### 14 [A]
$u = \dfrac{1}{x}$, $v = \dfrac{1}{y}$: $10u + 3v = -1$, $4u + 6v = -\dfrac{26}{5}$.
Birinçisini $2$ ga köpaytirib ayiramiz: $16u = -2 + \dfrac{26}{5} = \dfrac{16}{5}$, $u = \dfrac{1}{5}$.
$3v = -1 - 2 = -3$, $v = -1$.
Demak, $x = 5$, $y = -1$.

Javob: $(5; -1)$.

### 15 [B]
$u = \dfrac{1}{2x+y}$, $v = \dfrac{1}{x-2y}$: $2u + 7v = 1$, $5u - 3v = \dfrac{38}{7}$.
Birinçisini $5$ ga, ikkinçisini $2$ ga köpaytirib ayiramiz: $41v = 5 - \dfrac{76}{7} = -\dfrac{41}{7}$, $v = -\dfrac{1}{7}$.
$2u = 1 + 1$, $u = 1$.
$2x + y = 1$, $x - 2y = -7$: $x = 2y - 7$, $5y - 14 = 1$, $y = 3$, $x = -1$.

Javob: $(-1; 3)$.

## 3-test

### 1 [B]
$y = -3x - 2$ ni ikkinçi tenglamaga qöyamiz: $4x - 3x - 2 = 0$, $x = 2$.
$y = -6 - 2 = -8$.

Javob: $(2; -8)$.

### 2 [A]
Tenglamalarni qöşamiz: $2y = 18$, $y = 9$.
$x = 13 - 9 = 4$.

Javob: $(4; 9)$.

### 3 [D]
Birinçisini $2$ ga bölamiz: $3x + y = -11$. Ikkinçisidan $x = 4y + 18$.
$3(4y + 18) + y = -11$, $13y = -65$, $y = -5$.
$x = -20 + 18 = -2$.

Javob: $(-2; -5)$.

### 4 [B]
Soddalaştiramiz: $x + 2y = 15$ va $y + 3 = x + y$, ya'ni $x = 3$.
$3 + 2y = 15$, $y = 6$.

Javob: $(3; 6)$.

### 5 [D]
Ikkinçisidan $y = 4x$. Birinçisini $10$ ga köpaytiramiz: $2(x - 2y) + 5(3x + y) = -21$, ya'ni $17x + y = -21$.
$17x + 4x = -21$, $x = -1$, $y = -4$.

Javob: $(-1; -4)$.

### 6 [C]
Ikkinçi tenglamadan: $x + y = 4(x - y)$, $5y = 3x$.
Birinçisini $12$ ga köpaytiramiz: $2(2x + 3) + 3(y - 2) = 29$, ya'ni $4x + 3y = 29$.
$x = \dfrac{5y}{3}$: $\dfrac{20y}{3} + 3y = 29$, $\dfrac{29y}{3} = 29$, $y = 3$, $x = 5$.

Javob: $(5; 3)$.

### 7 [D]
$9x^2 - y^2 = (3x - y)(3x + y) = 11$ va $3x + y = -11$, demak $3x - y = -1$.
Qöşamiz: $6x = -12$, $x = -2$; $y = -11 + 6 = -5$.

Javob: $(-2; -5)$.

### 8 [B]
Ikkinçisidan $y = 15 - 4x + z$ ni qöyamiz:
$x - 2(15 - 4x + z) + 3z = -16 \Rightarrow 9x + z = 14$,
$-2x + 3(15 - 4x + z) + 2z = -3 \Rightarrow -14x + 5z = -48$.
$z = 14 - 9x$: $-14x + 70 - 45x = -48$, $x = 2$, $z = -4$, $y = 15 - 8 - 4 = 3$.

Javob: $(2; 3; -4)$.

### 9 [C]
$x = 2$, $y = 3$ ni qöyamiz: $10a - 3b = -2$ va $4a - 9b = -32$.
Birinçisini $3$ ga köpaytirib ayiramiz: $26a = 26$, $a = 1$.
$3b = 10 + 2 = 12$, $b = 4$.

Javob: $(1; 4)$.

### 10 [A]
Öng tomon: $(A + B)x^2 + (2A - 3B)x$.
$x^2$ oldidagi koeffitsiyentlarni tenglaymiz: $A + B = 6$.

Javob: $6$.

### 11 [D]
$x^2 + 3x - 4 = (x - 1)(x + 4)$, şuning uçun $6x - 1 = A(x + 4) + B(x - 1)$.
$x$ oldidagi koeffitsiyentlar: $A + B = 6$.

Javob: $6$.

### 12 [C]
Yeçim yöq bölişi uçun $\dfrac{3a - 2}{a + 1} = \dfrac{5}{-1} \ne \dfrac{-2}{6}$.
$3a - 2 = -5a - 5$, $8a = -3$, $a = -\dfrac{3}{8}$.

Javob: $-\dfrac{3}{8}$.

### 13 [A]
Çeksiz köp yeçim uçun $\dfrac{a-4}{2a-4} = \dfrac{b+1}{b+4} = \dfrac{-3}{6} = -\dfrac{1}{2}$.
$2a - 8 = -2a + 4$, $a = 3$.
$2b + 2 = -b - 4$, $b = -2$.

Javob: $(3; -2)$.

### 14 [A]
$u = \dfrac{1}{x}$, $v = \dfrac{1}{y}$: $6u - 4v = 0$, $9u + 2v = -4$.
Ikkinçisini $2$ ga köpaytirib qöşamiz: $24u = -8$, $u = -\dfrac{1}{3}$.
$4v = 6u = -2$, $v = -\dfrac{1}{2}$.
Demak, $x = -3$, $y = -2$.

Javob: $(-3; -2)$.

### 15 [C]
$u = \dfrac{1}{x-y}$, $v = \dfrac{1}{2x+3y}$: $6u + 11v = 3$, $3u - 22v = -1$.
Ikkinçisini $2$ ga köpaytirib ayiramiz: $55v = 5$, $v = \dfrac{1}{11}$; $6u = 2$, $u = \dfrac{1}{3}$.
$x - y = 3$, $2x + 3y = 11$: $x = y + 3$, $5y + 6 = 11$, $y = 1$, $x = 4$.

Javob: $(4; 1)$.
