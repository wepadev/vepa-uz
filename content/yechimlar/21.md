# 21. Köpaytuvçilarga ajratiş (1-qism)

## 1-test

### 1 [A]
$24$ va $36$ ning EKUBi $12$, uni qavsdan çiqaramiz:
$24x + 36y = 12 \cdot 2x + 12 \cdot 3y = 12(2x + 3y)$.

Javob: $12(2x+3y)$.

### 2 [B]
Koeffitsiyentlar EKUBi $4$, harflarning eng kiçik darajalari $x^2$ va $y$. Umumiy köpaytuvçi $4x^2y$:
$8x^3y^3 - 20x^2y^2 + 12x^2y = 4x^2y(2xy^2 - 5y + 3)$.

Javob: $4x^2y(2xy^2-5y+3)$.

### 3 [D]
Har qöşiluvçida $(x + 2y)$ bor, uni qavsdan çiqaramiz:
$(x + 2y)(3 + 2x + 7y)$.

Javob: $(x+2y)(2x+7y+3)$.

### 4 [C]
$-p + q = -(p - q)$, demak ifoda $(p - q)(4m^2 + n^2) - (p - q)(m^2 - 2n^2)$.
$(p - q)(4m^2 + n^2 - m^2 + 2n^2) = (p - q)(3m^2 + 3n^2)$.

Javob: $(p-q)(3m^2+3n^2)$.

### 5 [A]
Qavslarni $(2y - 3)$ orqali yozamiz: $-b(-8y + 12) = 4b(2y - 3)$, $c(4y - 6) = 2c(2y - 3)$.
Demak $(2y - 3)(a + 4b + 2c)$.

Javob: $(2y-3)(a+4b+2c)$.

### 6 [D]
Guruhlaymiz: $a^2(a + 3) + (a + 3) = (a + 3)(a^2 + 1)$.

Javob: $(a+3)(a^2+1)$.

### 7 [C]
Umumiy köpaytuvçi $2\dfrac{1}{3} = \dfrac{7}{3}$ ni qavsdan çiqaramiz:
$\dfrac{7}{3}\left(15 + 8\dfrac{2}{3} + 6\dfrac{1}{3}\right) = \dfrac{7}{3} \cdot 30 = 70$.

Javob: $70$.

### 8 [A]
Umumiy köpaytuvçi $7^2 \cdot 13$:
$7^2 \cdot 13(2 \cdot 7 - 13) = 49 \cdot 13 \cdot 1 = 637$.

Javob: $637$.

### 9 [D]
Guruhlaymiz: $a^2(a + 5) + 2(a + 5) = (a + 5)(a^2 + 2)$.

Javob: $(a+5)(a^2+2)$.

### 10 [B]
Guruhlaymiz: $-2q^2(3a - 5b) + p(3a - 5b) = (3a - 5b)(p - 2q^2)$.
Ikkala qavsdagi işoralarni almaştirsak: $(-3a + 5b)(2q^2 - p)$.

Javob: $(-3a+5b)(2q^2-p)$.

### 11 [D]
Guruhlaymiz: $-a(a^2 - b^2) - 5(a^2 - b^2) + 2(a + 5)$.
$= -(a + 5)(a^2 - b^2) + 2(a + 5) = (a + 5)(-a^2 + b^2 + 2)$.

Javob: $(a+5)(-a^2+b^2+2)$.

### 12 [C]
Qavslarni oçib guruhlaymiz: $ab^2 - a + a^2b - b = ab(a + b) - (a + b) = (a + b)(ab - 1)$.
$12 \cdot (5 - 1) = 48$.

Javob: $48$.

### 13 [B]
Guruhlaymiz: $72^2 \cdot 8 - 8^2 \cdot 72 + 72 - 8 = 72 \cdot 8(72 - 8) + 64$.
$= 576 \cdot 64 + 64 = 64 \cdot 577 = 36\,928$.

Javob: $36928$.

### 14 [C]
Köpaytmasi $24$, yiğindisi $11$ bölgan sonlar: $3$ va $8$.
$a^2 - 11a + 24 = (a - 3)(a - 8)$.

Javob: $(a-3)(a-8)$.

### 15 [A]
Örta hadni ajratamiz: $3a^2 + 15a + a + 5 = 3a(a + 5) + (a + 5) = (3a + 1)(a + 5)$.

Javob: $(3a+1)(a+5)$.

### 16 [C]
Örta hadni ajratamiz: $4a^2 + 12ab + ab + 3b^2 = 4a(a + 3b) + b(a + 3b) = (4a + b)(a + 3b)$.

Javob: $(4a+b)(a+3b)$.

### 17 [B]
Ikkala tomonga $1$ qöşamiz: $ab + a + b + 1 = 91$, ya'ni $(a + 1)(b + 1) = 91 = 7 \cdot 13$.
$a = 6$, $b = 12$ (yoki aksinça), $a + b = 18$.

Javob: $18$.

### 18 [A]
Ikkala tomonga $9$ qöşamiz: $(a + 3)(b + 3) = 143 = 11 \cdot 13$.
$a = 8$, $b = 10$, $a + b = 18$.

Javob: $18$.

## 2-test

### 1 [B]
$28$ va $42$ ning EKUBi $14$: $28m - 42n = 14(2m - 3n)$.

Javob: $14(2m-3n)$.

### 2 [C]
Umumiy köpaytuvçi $5mn^2$:
$15m^3n^2 - 20mn^3 + 10mn^2 = 5mn^2(3m^2 - 4n + 2)$.

Javob: $5mn^2(3m^2-4n+2)$.

### 3 [A]
Umumiy köpaytuvçi $(m + 4n)$: $(m + 4n)(1 + 6m + 3n)$.

Javob: $(m+4n)(6m+3n+1)$.

### 4 [D]
$-a + b = -(a - b)$:
$(a - b)(3x^2 - 2y^2 - 6x^2 - y^2) = (a - b)(-3x^2 - 3y^2)$.

Javob: $(a-b)(-3x^2-3y^2)$.

### 5 [C]
$-b(-15x + 6) = 3b(5x - 2)$, $c(20x - 8) = 4c(5x - 2)$.
Demak $(5x - 2)(a + 3b + 4c)$.

Javob: $(5x-2)(a+3b+4c)$.

### 6 [B]
Guruhlaymiz: $m^2(m + 4) + (m + 4) = (m + 4)(m^2 + 1)$.

Javob: $(m+4)(m^2+1)$.

### 7 [D]
Umumiy köpaytuvçi $1\dfrac{3}{4} = \dfrac{7}{4}$:
$\dfrac{7}{4}\left(18 + 9\dfrac{1}{2} + 4\dfrac{1}{2}\right) = \dfrac{7}{4} \cdot 32 = 56$.

Javob: $56$.

### 8 [C]
Umumiy köpaytuvçi $3^2 \cdot 11$:
$9 \cdot 11(4 \cdot 3 - 11) = 99 \cdot 1 = 99$.

Javob: $99$.

### 9 [A]
Guruhlaymiz: $m^2(m + 2) + 7(m + 2) = (m + 2)(m^2 + 7)$.

Javob: $(m+2)(m^2+7)$.

### 10 [D]
Guruhlaymiz: $-3q^2(5a - 4b) + p(5a - 4b) = (5a - 4b)(p - 3q^2) = (-5a + 4b)(3q^2 - p)$.

Javob: $(-5a+4b)(3q^2-p)$.

### 11 [B]
Guruhlaymiz: $-m(m^2 - n^2) - 2(m^2 - n^2) + 7(m + 2)$.
$= -(m + 2)(m^2 - n^2) + 7(m + 2) = (m + 2)(-m^2 + n^2 + 7)$.

Javob: $(m+2)(-m^2+n^2+7)$.

### 12 [D]
$a(b^2 - 1) + b(a^2 - 1) = ab(a + b) - (a + b) = (a + b)(ab - 1)$.
$8 \cdot 6 = 48$.

Javob: $48$.

### 13 [A]
Guruhlaymiz: $43 \cdot 5(43 - 5) + (43 - 5) = 38(215 + 1) = 38 \cdot 216 = 8208$.

Javob: $8208$.

### 14 [C]
Köpaytmasi $36$, yiğindisi $13$ bölgan sonlar: $4$ va $9$.
$m^2 - 13m + 36 = (m - 4)(m - 9)$.

Javob: $(m-4)(m-9)$.

### 15 [B]
Örta hadni ajratamiz: $4m^2 + 8m + 3m + 6 = 4m(m + 2) + 3(m + 2) = (4m + 3)(m + 2)$.

Javob: $(4m+3)(m+2)$.

### 16 [D]
Örta hadni ajratamiz: $2a^2 + 4ab + 3ab + 6b^2 = 2a(a + 2b) + 3b(a + 2b) = (2a + 3b)(a + 2b)$.

Javob: $(2a+3b)(a+2b)$.

### 17 [C]
$1$ qöşamiz: $(a + 1)(b + 1) = 85 = 5 \cdot 17$.
$a = 4$, $b = 16$, $a + b = 20$.

Javob: $20$.

### 18 [B]
$16$ qöşamiz: $(a + 4)(b + 4) = 187 = 11 \cdot 17$.
$a = 7$, $b = 13$, $a + b = 20$.

Javob: $20$.

## 3-test

### 1 [C]
$45$ va $60$ ning EKUBi $15$: $45a + 60b = 15(3a + 4b)$.

Javob: $15(3a+4b)$.

### 2 [B]
Umumiy köpaytuvçi $7a^2b$:
$14a^3b^2 + 28a^2b^3 - 21a^2b = 7a^2b(2ab + 4b^2 - 3)$.

Javob: $7a^2b(2ab+4b^2-3)$.

### 3 [C]
Umumiy köpaytuvçi $(a + 5b)$: $(a + 5b)(4 + 3a + 2b)$.

Javob: $(a+5b)(3a+2b+4)$.

### 4 [A]
$-p + q = -(p - q)$:
$(p - q)(5m^2 + 4n^2 - 2m^2 + 3n^2) = (p - q)(3m^2 + 7n^2)$.

Javob: $(p-q)(3m^2+7n^2)$.

### 5 [D]
$-b(-8y + 10) = 2b(4y - 5)$, $c(20y - 25) = 5c(4y - 5)$.
Demak $(4y - 5)(a + 2b + 5c)$.

Javob: $(4y-5)(a+2b+5c)$.

### 6 [C]
Guruhlaymiz: $y^2(y + 5) + (y + 5) = (y + 5)(y^2 + 1)$.

Javob: $(y+5)(y^2+1)$.

### 7 [B]
Umumiy köpaytuvçi $2\dfrac{2}{5} = \dfrac{12}{5}$:
$\dfrac{12}{5}\left(10 + 6\dfrac{3}{4} + 3\dfrac{1}{4}\right) = \dfrac{12}{5} \cdot 20 = 48$.

Javob: $48$.

### 8 [D]
Umumiy köpaytuvçi $5^2 \cdot 14$:
$25 \cdot 14(3 \cdot 5 - 14) = 350 \cdot 1 = 350$.

Javob: $350$.

### 9 [B]
Guruhlaymiz: $y^2(y + 4) + 3(y + 4) = (y + 4)(y^2 + 3)$.

Javob: $(y+4)(y^2+3)$.

### 10 [A]
Guruhlaymiz: $-5q^2(3a - 2b) + p(3a - 2b) = (3a - 2b)(p - 5q^2) = (-3a + 2b)(5q^2 - p)$.

Javob: $(-3a+2b)(5q^2-p)$.

### 11 [D]
Guruhlaymiz: $-x(x^2 - y^2) - 4(x^2 - y^2) + 3(x + 4)$.
$= -(x + 4)(x^2 - y^2) + 3(x + 4) = (x + 4)(-x^2 + y^2 + 3)$.

Javob: $(x+4)(-x^2+y^2+3)$.

### 12 [A]
$a(b^2 - 1) + b(a^2 - 1) = (a + b)(ab - 1) = 11 \cdot 3 = 33$.

Javob: $33$.

### 13 [A]
Guruhlaymiz: $64 \cdot 6(64 - 6) + (64 - 6) = 58(384 + 1) = 58 \cdot 385 = 22\,330$.

Javob: $22330$.

### 14 [C]
Köpaytmasi $55$, yiğindisi $16$ bölgan sonlar: $5$ va $11$.
$y^2 - 16y + 55 = (y - 5)(y - 11)$.

Javob: $(y-5)(y-11)$.

### 15 [C]
Örta hadni ajratamiz: $5y^2 + 15y + 2y + 6 = 5y(y + 3) + 2(y + 3) = (5y + 2)(y + 3)$.

Javob: $(5y+2)(y+3)$.

### 16 [B]
Örta hadni ajratamiz: $5a^2 + 5ab + 3ab + 3b^2 = 5a(a + b) + 3b(a + b) = (5a + 3b)(a + b)$.

Javob: $(5a+3b)(a+b)$.

### 17 [A]
$1$ qöşamiz: $(a + 1)(b + 1) = 143 = 11 \cdot 13$.
$a = 10$, $b = 12$, $a + b = 22$.

Javob: $22$.

### 18 [D]
$25$ qöşamiz: $(a + 5)(b + 5) = 221 = 13 \cdot 17$.
$a = 8$, $b = 12$, $a + b = 20$.

Javob: $20$.
