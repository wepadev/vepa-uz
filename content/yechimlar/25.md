# 25. Çiziqli tenglamalar

## 1-test

### 1 [A]
Ikkala tomonni $x$ oldidagi koeffitsiyentga, ya'ni $8$ ga bölamiz:
$x = \dfrac{-32}{8} = -4$.

Javob: $-4$.

### 2 [D]
Ikkala tomonni $4$ ga köpaytiramiz: $-x - 7 = -8$.
Bundan $-x = -1$, ya'ni $x = 1$.

Javob: $1$.

### 3 [B]
Qavslarni oçamiz: $18x - 12 - 10x - 2 = -46$.
Öxşaş hadlarni yiğamiz: $8x - 14 = -46$, $8x = -32$.
Demak, $x = -4$.

Javob: $-4$.

### 4 [C]
$2$ ni öng tomonga ötkazamiz: $\dfrac{x-3}{4} = \dfrac{3}{4} - 2 = -\dfrac{5}{4}$.
Ikkala tomonni $4$ ga köpaytiramiz: $x - 3 = -5$, $x = -2$.

Javob: $-2$.

### 5 [C]
Proporsiyaning asosiy xossasidan (çetki hadlar köpaytmasi örta hadlar köpaytmasiga teng) foydalanamiz:
$2x - 5 = 3(-4x + 3) = -12x + 9$.
$14x = 14$, $x = 1$.
Tekşiramiz: $x = 1$ da maxrajlar $-1$ va $-3$, nolga teng emas.

Javob: $1$.

### 6 [A]
Qavslarni içkaridan boşlab oçamiz:
$3x + (2x - 10) = 5x - 10$,
$1x - (5x - 10) = -4x + 10$,
$4x + (-4x + 10) = 10$.
Tenglama: $6x - 10 = -28$, $6x = -18$, $x = -3$.

Javob: $-3$.

### 7 [D]
Çap tomon: $(x+3)^2 = x^2 + 6x + 9$.
Öng tomon: $(38 + x)x - 23 = x^2 + 38x - 23$.
$x^2$ lar qisqaradi: $6x + 9 = 38x - 23$, $32x = 32$, $x = 1$.

Javob: $1$.

### 8 [D]
Proporsiya xossasi bilan köpaytiramiz: $(3x+4)(6x-5) = (2x-1)(9x+1)$.
$18x^2 + 9x - 20 = 18x^2 - 7x - 1$.
$16x = 19$, $x = \dfrac{19}{16}$ (maxrajlar bu qiymatda nolga aylanmaydi).

Javob: $\dfrac{19}{16}$.

### 9 [B]
Kasrning surat va maxrajini $x$ ga köpaytiramiz: $\dfrac{\frac{5}{x}+1}{2-\frac{3}{x}} = \dfrac{5+x}{2x-3}$.
Tenglama: $7 - \dfrac{5+x}{2x-3} = 4$, ya'ni $\dfrac{5+x}{2x-3} = 3$.
$5 + x = 6x - 9$, $5x = 14$, $x = \dfrac{14}{5}$.

Javob: $\dfrac{14}{5}$.

### 10 [C]
Umumiy maxraj $30$ ga köpaytiramiz:
$6(x+4) + 10(2x-1) = 15(x+3) + 90$.
$26x + 14 = 15x + 135$, $11x = 121$, $x = 11$.

Javob: $11$.

### 11 [A]
Ildiz $x = 4$ ni tenglamaga qöyamiz:
$8(4 + a) - 4a = a + 20$.
$32 + 4a = a + 20$, $3a = -12$, $a = -4$.

Javob: $-4$.

### 12 [B]
Ikkala tomonni $2x+3$ ga köpaytiramiz: $2xy + 3y = 4x - 1$.
$x$ li hadlarni bir tomonga yiğamiz: $2xy - 4x = -3y - 1$, $x(2y - 4) = -3y - 1$.
$x = \dfrac{-3y-1}{2y-4}$.

Javob: $\dfrac{-3y-1}{2y-4}$.

### 13 [D]
Tenglamani $kx = b$ körinişga keltiramiz: $ax - 3a = 7x + 7$, $(a - 7)x = 3a + 7$.
$kx = b$ tenglama $k = 0$, $b \ne 0$ bölsa yeçimga ega emas.
$a = 7$ da $0 \cdot x = 28$ — yeçim yöq.

Javob: $7$.

### 14 [A]
$(a^2 - 25)x = a + 5$ körinişga keltiramiz.
Çeksiz köp yeçim uçun $a^2 - 25 = 0$ va $a + 5 = 0$ bölişi kerak.
Ikkalasi faqat $a = -5$ da bajariladi.

Javob: $-5$.

### 15 [D]
$ax - 2a + 3 = 4x$, ya'ni $(a - 4)x = 2a - 3$.
$x$ oldidagi koeffitsiyent nolga teng bölmasa, yagona yeçim bor: $a - 4 \ne 0$.

Javob: $a \ne 4$.

### 16 [C]
Öng tomondagi kasrni soddalaştiramiz: $\dfrac{b^2 - 16a^2}{ab - 4a^2} = \dfrac{(b-4a)(b+4a)}{a(b-4a)} = \dfrac{b+4a}{a}$.
Tenglama: $\dfrac{x + b}{a} = \dfrac{b + 4a}{a}$, bundan $x + b = b + 4a$.
$x = 4a$.

Javob: $4a$.

### 17 [B]
Qavslarni oçamiz: $4x(a+b+c) - (a^2+b^2+c^2) = 2(ab+bc+ca)$.
$4x(a+b+c) = a^2+b^2+c^2+2ab+2bc+2ca = (a+b+c)^2$.
$a+b+c \ne 0$ ga bölamiz: $x = \dfrac{a+b+c}{4}$.

Javob: $\dfrac{a+b+c}{4}$.

### 18 [C]
Kasrni tomonma-tomon "yeçamiz":
$\dfrac{10}{8 - \dots} = 2 \Rightarrow 8 - \dfrac{12}{2 + \frac{6}{x+2}} = 5$,
$\dfrac{12}{2 + \frac{6}{x+2}} = 3 \Rightarrow 2 + \dfrac{6}{x+2} = 4$,
$\dfrac{6}{x+2} = 2 \Rightarrow x + 2 = 3$, $x = 1$.

Javob: $1$.

### 19 [A]
Bir xil maxrajli kasrlarni bir tomonga yiğamiz:
$\dfrac{x-2}{4x+3} + \dfrac{3x+5}{4x+3} = \dfrac{2x-3}{7} - \dfrac{5x+1}{7}$.
Çap tomon $\dfrac{4x+3}{4x+3} = 1$, öng tomon $\dfrac{-3x-4}{7}$.
$-3x - 4 = 7$, $x = -\dfrac{11}{3}$ (bu qiymatda $4x+3 \ne 0$).

Javob: $-\dfrac{11}{3}$.

### 20 [B]
Suratlar yiğindisi: $1 + 2 + \dots + (x-1) = \dfrac{(x-1)x}{2}$.
Demak, çap tomon $\dfrac{(x-1)x}{2x} = \dfrac{x-1}{2}$.
$\dfrac{x-1}{2} = 8$, $x = 17$.

Javob: $17$.

### 21 [D]
Ifoda biror maxraj nolga aylanganda ma'noga ega bölmaydi:
$a - 1 = 0 \Rightarrow a = 1$;
$4 - \dfrac{1}{a-1} = 0 \Rightarrow a - 1 = \dfrac{1}{4}$, $a = \dfrac{5}{4}$;
$5 - \dfrac{10}{4 - \frac{1}{a-1}} = 0 \Rightarrow 4 - \dfrac{1}{a-1} = 2$, $a - 1 = \dfrac{1}{2}$, $a = \dfrac{3}{2}$.
Yiğindi: $1 + \dfrac{5}{4} + \dfrac{3}{2} = \dfrac{15}{4}$.

Javob: $\dfrac{15}{4}$.

### 22 [A]
Çeksiz kasrning maxraji $x + \dfrac{45}{x + \dots}$ butun çap tomonning özi, ya'ni $9$ ga teng.
Demak, $x + \dfrac{45}{9} = 9$, $x + 5 = 9$, $x = 4$.

Javob: $4$.

### 23 [C]
$\dfrac{1}{n(n+3)} = \dfrac{1}{3}\left(\dfrac{1}{n} - \dfrac{1}{n+3}\right)$ ayirmasidan foydalanamiz:
$\dfrac{1}{1 \cdot 4} + \dots + \dfrac{1}{13 \cdot 16} = \dfrac{1}{3}\left(1 - \dfrac{1}{16}\right) = \dfrac{5}{16}$.
$\dfrac{5x}{16} = \dfrac{5}{2}$, $x = 8$.

Javob: $8$.

### 24 [D]
$r = \dfrac{a}{b}$ belgilaymiz: $x = \dfrac{r}{r+4}$, $y = \dfrac{1}{4r+1}$.
Ikkinçisidan $4r + 1 = \dfrac{1}{y}$, $r = \dfrac{1-y}{4y}$.
$x = \dfrac{\frac{1-y}{4y}}{\frac{1-y}{4y} + 4} = \dfrac{1-y}{1 - y + 16y} = \dfrac{1-y}{1+15y}$.

Javob: $\dfrac{1-y}{1+15y}$.

## 2-test

### 1 [A]
Ikkala tomonni $9$ ga bölamiz: $x = \dfrac{45}{9} = 5$.

Javob: $5$.

### 2 [D]
Ikkala tomonni $5$ ga köpaytiramiz: $-x - 6 = 15$.
$-x = 21$, $x = -21$.

Javob: $-21$.

### 3 [C]
Qavslarni oçamiz: $-20x + 5 + 6x + 15 = -22$.
$-14x + 20 = -22$, $-14x = -42$, $x = 3$.

Javob: $3$.

### 4 [B]
$1$ ni öng tomonga ötkazamiz: $\dfrac{x+5}{6} = \dfrac{1}{6} + 1 = \dfrac{7}{6}$.
$x + 5 = 7$, $x = 2$.

Javob: $2$.

### 5 [D]
Proporsiya xossasidan: $3x - 9 = 2(5x + 1) = 10x + 2$.
$-7x = 11$, $x = -\dfrac{11}{7}$ (maxrajlar nolga aylanmaydi).

Javob: $-\dfrac{11}{7}$.

### 6 [C]
Qavslarni içkaridan oçamiz:
$2x + (4x - 12) = 6x - 12$,
$5x - (6x - 12) = -x + 12$,
$3x + (-x + 12) = 2x + 12$.
Tenglama: $8x - (2x + 12) = 12$, $6x = 24$, $x = 4$.

Javob: $4$.

### 7 [D]
Çap tomon: $x^2 - 2x + 1$. Öng tomon: $(26 + x)x - 55 = x^2 + 26x - 55$.
$x^2$ qisqaradi: $-2x + 1 = 26x - 55$, $28x = 56$, $x = 2$.

Javob: $2$.

### 8 [B]
Proporsiya xossasidan: $(4x-3)(10x-1) = (5x+2)(8x+7)$.
$40x^2 - 34x + 3 = 40x^2 + 51x + 14$.
$-85x = 11$, $x = -\dfrac{11}{85}$.

Javob: $-\dfrac{11}{85}$.

### 9 [A]
Kasrning surat va maxrajini $x$ ga köpaytiramiz: $\dfrac{2 + 3x}{5x - 2}$.
Tenglama: $4 - \dfrac{2+3x}{5x-2} = 1$, ya'ni $\dfrac{2+3x}{5x-2} = 3$.
$2 + 3x = 15x - 6$, $12x = 8$, $x = \dfrac{2}{3}$.

Javob: $\dfrac{2}{3}$.

### 10 [B]
Umumiy maxraj $12$ ga köpaytiramiz:
$3(3x-2) + 2(x+4) = 4(2x+2) + 12$.
$11x + 2 = 8x + 20$, $3x = 18$, $x = 6$.

Javob: $6$.

### 11 [D]
$x = 5$ ni qöyamiz: $10(5 + a) - 5a = a + 30$.
$50 + 5a = a + 30$, $4a = -20$, $a = -5$.

Javob: $-5$.

### 12 [A]
Ikkala tomonni $3x - 1$ ga köpaytiramiz: $3xy - y = 5x + 2$.
$3xy - 5x = y + 2$, $x(3y - 5) = y + 2$.
$x = \dfrac{y+2}{3y-5}$.

Javob: $\dfrac{y+2}{3y-5}$.

### 13 [C]
$ax + 2a = 4x + 24$, ya'ni $(a - 4)x = 24 - 2a$.
$a = 4$ da $0 \cdot x = 16$ hosil böladi — yeçim yöq.

Javob: $4$.

### 14 [B]
$(a^2 - 36)x = a + 6$.
Çeksiz köp yeçim uçun $a^2 - 36 = 0$ va $a + 6 = 0$, ya'ni $a = -6$.

Javob: $-6$.

### 15 [A]
$ax + 5a - 1 = 6x$, ya'ni $(a - 6)x = 1 - 5a$.
Yagona yeçim uçun koeffitsiyent noldan farqli: $a \ne 6$.

Javob: $a \ne 6$.

### 16 [D]
$\dfrac{b^2 - 25a^2}{ab - 5a^2} = \dfrac{(b-5a)(b+5a)}{a(b-5a)} = \dfrac{b+5a}{a}$.
Tenglama: $\dfrac{x+b}{a} = \dfrac{b+5a}{a}$, $x + b = b + 5a$, $x = 5a$.

Javob: $5a$.

### 17 [C]
Qavslarni oçamiz: $5x(a+b+c) = a^2+b^2+c^2 + 2(ab+bc+ca) = (a+b+c)^2$.
$a+b+c \ne 0$ ga bölamiz: $x = \dfrac{a+b+c}{5}$.

Javob: $\dfrac{a+b+c}{5}$.

### 18 [B]
Tomonma-tomon yeçamiz:
$\dfrac{14}{9 - \dots} = 2 \Rightarrow 9 - \dfrac{10}{3 + \frac{8}{x+1}} = 7$,
$\dfrac{10}{3 + \frac{8}{x+1}} = 2 \Rightarrow 3 + \dfrac{8}{x+1} = 5$,
$\dfrac{8}{x+1} = 2 \Rightarrow x + 1 = 4$, $x = 3$.

Javob: $3$.

### 19 [A]
Bir xil maxrajlilarni yiğamiz:
$\dfrac{3x+4}{5x+3} + \dfrac{2x-1}{5x+3} = \dfrac{-x+2}{6} - \dfrac{2x-5}{6}$.
Çap tomon $\dfrac{5x+3}{5x+3} = 1$, öng tomon $\dfrac{-3x+7}{6}$.
$-3x + 7 = 6$, $x = \dfrac{1}{3}$.

Javob: $\dfrac{1}{3}$.

### 20 [D]
$1 + 2 + \dots + (x-1) = \dfrac{(x-1)x}{2}$, şuning uçun çap tomon $\dfrac{x-1}{2}$.
$\dfrac{x-1}{2} = 9$, $x = 19$.

Javob: $19$.

### 21 [C]
Maxrajlarni nolga tenglaymiz:
$a - 4 = 0 \Rightarrow a = 4$;
$5 - \dfrac{1}{a-4} = 0 \Rightarrow a - 4 = \dfrac{1}{5}$, $a = \dfrac{21}{5}$;
$3 - \dfrac{9}{5 - \frac{1}{a-4}} = 0 \Rightarrow 5 - \dfrac{1}{a-4} = 3$, $a - 4 = \dfrac{1}{2}$, $a = \dfrac{9}{2}$.
Yiğindi: $4 + \dfrac{21}{5} + \dfrac{9}{2} = \dfrac{40 + 42 + 45}{10} = \dfrac{127}{10}$.

Javob: $\dfrac{127}{10}$.

### 22 [C]
Çeksiz kasrning maxraji butun çap tomonga, ya'ni $10$ ga teng.
$x + \dfrac{70}{10} = 10$, $x = 3$.

Javob: $3$.

### 23 [A]
$\dfrac{1}{n(n+2)} = \dfrac{1}{2}\left(\dfrac{1}{n} - \dfrac{1}{n+2}\right)$ dan foydalanamiz:
$\dfrac{1}{3 \cdot 5} + \dots + \dfrac{1}{15 \cdot 17} = \dfrac{1}{2}\left(\dfrac{1}{3} - \dfrac{1}{17}\right) = \dfrac{7}{51}$.
$\dfrac{7x}{51} = \dfrac{14}{17}$, $x = \dfrac{14 \cdot 51}{17 \cdot 7} = 6$.

Javob: $6$.

### 24 [B]
$r = \dfrac{a}{b}$: $x = \dfrac{r}{r+5}$, $y = \dfrac{1}{5r+1}$.
Bundan $r = \dfrac{1-y}{5y}$.
$x = \dfrac{\frac{1-y}{5y}}{\frac{1-y}{5y} + 5} = \dfrac{1-y}{1 - y + 25y} = \dfrac{1-y}{1+24y}$.

Javob: $\dfrac{1-y}{1+24y}$.

## 3-test

### 1 [C]
Ikkala tomonni $11$ ga bölamiz: $x = \dfrac{-33}{11} = -3$.

Javob: $-3$.

### 2 [B]
Ikkala tomonni $6$ ga köpaytiramiz: $-x - 5 = -24$.
$-x = -19$, $x = 19$.

Javob: $19$.

### 3 [A]
Qavslarni oçamiz: $14x + 21 - 12x + 8 = 39$.
$2x + 29 = 39$, $2x = 10$, $x = 5$.

Javob: $5$.

### 4 [D]
$3$ ni öng tomonga ötkazamiz: $\dfrac{x-2}{7} = \dfrac{5}{7} - 3 = -\dfrac{16}{7}$.
$x - 2 = -16$, $x = -14$.

Javob: $-14$.

### 5 [B]
Proporsiya xossasidan: $9x - 1 = 4(2x + 7) = 8x + 28$.
$x = 29$ (maxrajlar nolga aylanmaydi).

Javob: $29$.

### 6 [A]
Qavslarni içkaridan oçamiz:
$6x + (3x - 18) = 9x - 18$,
$2x - (9x - 18) = -7x + 18$,
$5x + (-7x + 18) = -2x + 18$.
Tenglama: $9x - (-2x + 18) = -40$, $11x - 18 = -40$, $11x = -22$, $x = -2$.

Javob: $-2$.

### 7 [C]
Çap tomon: $x^2 + 8x + 16$. Öng tomon: $(49 + x)x - 25 = x^2 + 49x - 25$.
$x^2$ qisqaradi: $8x + 16 = 49x - 25$, $41x = 41$, $x = 1$.

Javob: $1$.

### 8 [D]
Proporsiya xossasidan: $(5x+1)(6x+5) = (2x+3)(15x-4)$.
$30x^2 + 31x + 5 = 30x^2 + 37x - 12$.
$6x = 17$, $x = \dfrac{17}{6}$.

Javob: $\dfrac{17}{6}$.

### 9 [D]
Kasrning surat va maxrajini $x$ ga köpaytiramiz: $\dfrac{7 + 2x}{4x - 1}$.
Tenglama: $8 - \dfrac{7+2x}{4x-1} = 5$, ya'ni $\dfrac{7+2x}{4x-1} = 3$.
$7 + 2x = 12x - 3$, $10x = 10$, $x = 1$.

Javob: $1$.

### 10 [C]
Umumiy maxraj $10$ ga köpaytiramiz:
$5(x+3) + 2(2x-1) = (x+3) + 50$.
$9x + 13 = x + 53$, $8x = 40$, $x = 5$.

Javob: $5$.

### 11 [B]
$x = 6$ ni qöyamiz: $12(6 + a) - 6a = a + 42$.
$72 + 6a = a + 42$, $5a = -30$, $a = -6$.

Javob: $-6$.

### 12 [A]
Ikkala tomonni $x + 4$ ga köpaytiramiz: $xy + 4y = 2x - 7$.
$xy - 2x = -4y - 7$, $x(y - 2) = -4y - 7$.
$x = \dfrac{-4y-7}{y-2}$.

Javob: $\dfrac{-4y-7}{y-2}$.

### 13 [A]
$ax - 5a = 6x - 6$, ya'ni $(a - 6)x = 5a - 6$.
$a = 6$ da $0 \cdot x = 24$ — yeçim yöq.

Javob: $6$.

### 14 [C]
$(a^2 - 49)x = a + 7$.
Çeksiz köp yeçim uçun $a^2 - 49 = 0$ va $a + 7 = 0$, ya'ni $a = -7$.

Javob: $-7$.

### 15 [B]
$ax - 4a - 2 = 7x$, ya'ni $(a - 7)x = 4a + 2$.
Yagona yeçim uçun $a - 7 \ne 0$.

Javob: $a \ne 7$.

### 16 [D]
$\dfrac{b^2 - 36a^2}{ab - 6a^2} = \dfrac{(b-6a)(b+6a)}{a(b-6a)} = \dfrac{b+6a}{a}$.
Tenglama: $x + b = b + 6a$, $x = 6a$.

Javob: $6a$.

### 17 [D]
Qavslarni oçamiz: $6x(a+b+c) = a^2+b^2+c^2 + 2(ab+bc+ca) = (a+b+c)^2$.
$a+b+c \ne 0$ ga bölamiz: $x = \dfrac{a+b+c}{6}$.

Javob: $\dfrac{a+b+c}{6}$.

### 18 [B]
Tomonma-tomon yeçamiz:
$\dfrac{20}{7 - \dots} = 4 \Rightarrow 7 - \dfrac{12}{4 + \frac{10}{x+3}} = 5$,
$\dfrac{12}{4 + \frac{10}{x+3}} = 2 \Rightarrow 4 + \dfrac{10}{x+3} = 6$,
$\dfrac{10}{x+3} = 2 \Rightarrow x + 3 = 5$, $x = 2$.

Javob: $2$.

### 19 [A]
Bir xil maxrajlilarni yiğamiz:
$\dfrac{2x-3}{6x-2} + \dfrac{4x+1}{6x-2} = \dfrac{3x+6}{9} - \dfrac{7x+2}{9}$.
Çap tomon $\dfrac{6x-2}{6x-2} = 1$, öng tomon $\dfrac{-4x+4}{9}$.
$-4x + 4 = 9$, $x = -\dfrac{5}{4}$.

Javob: $-\dfrac{5}{4}$.

### 20 [C]
Çap tomon $\dfrac{(x-1)x}{2x} = \dfrac{x-1}{2}$.
$\dfrac{x-1}{2} = 10$, $x = 21$.

Javob: $21$.

### 21 [D]
Maxrajlarni nolga tenglaymiz:
$a - 3 = 0 \Rightarrow a = 3$;
$5 - \dfrac{1}{a-3} = 0 \Rightarrow a = 3 + \dfrac{1}{5} = \dfrac{16}{5}$;
$6 - \dfrac{12}{5 - \frac{1}{a-3}} = 0 \Rightarrow 5 - \dfrac{1}{a-3} = 2$, $a - 3 = \dfrac{1}{3}$, $a = \dfrac{10}{3}$.
Yiğindi: $3 + \dfrac{16}{5} + \dfrac{10}{3} = \dfrac{45 + 48 + 50}{15} = \dfrac{143}{15}$.

Javob: $\dfrac{143}{15}$.

### 22 [B]
Çeksiz kasrning maxraji butun çap tomonga, ya'ni $12$ ga teng.
$x + \dfrac{60}{12} = 12$, $x = 7$.

Javob: $7$.

### 23 [A]
$\dfrac{1}{n(n+3)} = \dfrac{1}{3}\left(\dfrac{1}{n} - \dfrac{1}{n+3}\right)$ dan foydalanamiz:
$\dfrac{1}{2 \cdot 5} + \dots + \dfrac{1}{17 \cdot 20} = \dfrac{1}{3}\left(\dfrac{1}{2} - \dfrac{1}{20}\right) = \dfrac{3}{20}$.
$\dfrac{3x}{20} = \dfrac{3}{2}$, $x = 10$.

Javob: $10$.

### 24 [C]
$r = \dfrac{a}{b}$: $x = \dfrac{r}{r+6}$, $y = \dfrac{1}{6r+1}$.
Bundan $r = \dfrac{1-y}{6y}$.
$x = \dfrac{\frac{1-y}{6y}}{\frac{1-y}{6y} + 6} = \dfrac{1-y}{1 - y + 36y} = \dfrac{1-y}{1+35y}$.

Javob: $\dfrac{1-y}{1+35y}$.
