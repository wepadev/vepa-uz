# 49. Irratsional tengsizliklar

## 1-test

### 1 [C]
Arifmetik kvadrat ildiz doim nomanfiy: $\sqrt{-2x^2 + 5x + 1} \ge 0$.
U manfiy bölişi mumkin emas.

Javob: $\varnothing$.

### 2 [D]
Juft darajali ildiz nomanfiy, demak $\sqrt[6]{3x + 12} \le 0$ faqat nolga teng bölganda bajariladi:
$3x + 12 = 0 \Rightarrow x = -4$.

Javob: $\{-4\}$.

### 3 [B]
Ildiz nomanfiy, demak u $-2$ dan doim katta. Faqat aniqlaniş sohasini topamiz:
$\dfrac{3x + 9}{x - 2} \ge 0$. Intervallar usuli: $x \le -3$ yoki $x > 2$ ($x = 2$ maxrajni nolga aylantiradi).

Javob: $(-\infty; -3] \cup (2; +\infty)$.

### 4 [A]
Toq darajali ildiz har qanday son uçun aniqlangan va ösuvçi. Beşinçi darajaga kötaramiz:
$x^2 - 6x + 4 > -1 \Rightarrow x^2 - 6x + 5 > 0 \Rightarrow (x - 1)(x - 5) > 0$.
$x < 1$ yoki $x > 5$.

Javob: $(-\infty; 1) \cup (5; +\infty)$.

### 5 [B]
Ikkala tomon nomanfiy, kvadratga kötaramiz:
$3x + 3 > 9 \Rightarrow x > 2$ (bunda ildiz içi ham musbat).

Javob: $(2; +\infty)$.

### 6 [C]
Kvadratga kötaramiz: $\dfrac{x - 1}{10 - x} > \dfrac{1}{4}$.
$\dfrac{4(x - 1) - (10 - x)}{4(10 - x)} > 0 \Rightarrow \dfrac{5x - 14}{10 - x} > 0$.
Intervallar usuli: $\dfrac{14}{5} < x < 10$.

Javob: $\Bigl(\dfrac{14}{5}; 10\Bigr)$.

### 7 [A]
$x \ne -4$ da $\dfrac{x + 4}{3x + 12} = \dfrac{x + 4}{3(x + 4)} = \dfrac{1}{3}$.
$\sqrt{\dfrac{1}{3}} < 1$ doim töğri. Faqat $x = -4$ çiqarib taşlanadi.

Javob: $(-\infty; -4) \cup (-4; +\infty)$.

### 8 [D]
$\sqrt[4]{(x - 2)^2} = \sqrt{|x - 2|}$. Kvadratga kötaramiz:
$|x - 2| \le 1 \Rightarrow -1 \le x - 2 \le 1 \Rightarrow 1 \le x \le 3$.

Javob: $[1; 3]$.

### 9 [B]
Toq darajali ildiz ösuvçi, yettinçi darajaga kötaramiz:
$-x^2 - 2x + 4 > 1 \Rightarrow x^2 + 2x - 3 < 0 \Rightarrow (x + 3)(x - 1) < 0$.
$-3 < x < 1$.

Javob: $(-3; 1)$.

### 10 [A]
$\sqrt{A} > \sqrt{B}$ tengsizlik $A > B \ge 0$ ga teng kuçli:
$-2x + 12 > x \ge 0 \Rightarrow 0 \le x < 4$.

Javob: $[0; 4)$.

### 11 [D]
$\sqrt{A} < \sqrt{B} \iff 0 \le A < B$:
$0 \le x + 2 < -x + 4$.
$x \ge -2$ va $2x < 2 \Rightarrow x < 1$.

Javob: $[-2; 1)$.

### 12 [C]
Aniqlaniş sohasi: $(x - 1)(x - 5) \ge 0 \Rightarrow x \le 1$ yoki $x \ge 5$.
$x = 1$ va $x = 5$ da ifoda nol, tengsizlik bajariladi. Qolgan nuqtalarda ildiz musbat, demak $x + 2 \ge 0$, ya'ni $x \ge -2$.
Birlaştiramiz: $[-2; 1] \cup [5; +\infty)$.

Javob: $[-2; 1] \cup [5; +\infty)$.

### 13 [C]
Aniqlaniş sohasi: $(x - 2)(x + 1) \ge 0 \Rightarrow x \le -1$ yoki $x \ge 2$.
Ildiz musbat bölgan nuqtalarda: $x^2 - x - 20 = (x - 5)(x + 4) \le 0 \Rightarrow -4 \le x \le 5$.
$x = -1$, $x = 2$ (ildiz nol) ham kiradi. Kesişma: $[-4; -1] \cup [2; 5]$.

Javob: $[-4; -1] \cup [2; 5]$.

### 14 [D]
Aniqlaniş sohasi: $x^2 \ge 25$, $x \ne 8$, ya'ni $x \le -5$ yoki $x \ge 5$, $x \ne 8$.
$x = \pm 5$ da surat nol, tengsizlik bajariladi ($x = -2$, $x = 0$ sohaga kirmaydi).
Qolgan nuqtalarda $|x + 2|\sqrt{x^2 - 25} > 0$, demak $\dfrac{x}{x - 8} \le 0 \Rightarrow 0 \le x < 8$, sohada bu $(5; 8)$.

Javob: $\{-5\} \cup [5; 8)$.

### 15 [D]
Belgilaymiz: $t = \sqrt[4]{x} \ge 0$, $\sqrt{x} = t^2$.
$2t^2 - 5t + 2 \ge 0 \Rightarrow (2t - 1)(t - 2) \ge 0 \Rightarrow t \le \dfrac{1}{2}$ yoki $t \ge 2$.
$0 \le x \le \dfrac{1}{16}$ yoki $x \ge 16$.

Javob: $\Bigl[0; \dfrac{1}{16}\Bigr] \cup [16; +\infty)$.

### 16 [A]
Aniqlaniş sohasi: $\dfrac{x - 8}{x + 8} > 0 \Rightarrow x < -8$ yoki $x > 8$.
$t = \sqrt{\dfrac{x - 8}{x + 8}} > 0$: $t - \dfrac{1}{t} < \dfrac{8}{3} \Rightarrow 3t^2 - 8t - 3 < 0 \Rightarrow (3t + 1)(t - 3) < 0 \Rightarrow t < 3$.
$\dfrac{x - 8}{x + 8} < 9 \Rightarrow \dfrac{-8x - 80}{x + 8} < 0 \Rightarrow \dfrac{x + 10}{x + 8} > 0 \Rightarrow x < -10$ yoki $x > -8$.
Soha bilan kesişma: $x < -10$ yoki $x > 8$.

Javob: $(-\infty; -10) \cup (8; +\infty)$.

### 17 [C]
Aniqlaniş sohasi: $-x^2 + 8x \ge 0 \Rightarrow 0 \le x \le 8$. Bu yerda $x + 4 > 0$, kvadratga kötaramiz:
$-x^2 + 8x < x^2 + 8x + 16 \Rightarrow 2x^2 + 16 > 0$ — doim töğri.

Javob: $[0; 8]$.

### 18 [B]
Tengsizlik: $\sqrt{3x + 22} > -2x$, soha $x \ge -\dfrac{22}{3}$.
$x \ge 0$ da öng tomon $\le 0$, çap tomon musbat: hammasi yeçim.
$x < 0$ da kvadratga kötaramiz: $3x + 22 > 4x^2 \Rightarrow 4x^2 - 3x - 22 < 0 \Rightarrow -2 < x < \dfrac{11}{4}$, ya'ni $-2 < x < 0$.
Birlaştiramiz: $x > -2$.

Javob: $(-2; +\infty)$.

### 19 [B]
Şartlar: $x + 6 \ge 0$ va $\sqrt{x + 6} \ge x$.
$-6 \le x < 0$ da tengsizlik doim töğri.
$x \ge 0$ da: $x + 6 \ge x^2 \Rightarrow x^2 - x - 6 \le 0 \Rightarrow -2 \le x \le 3$, ya'ni $0 \le x \le 3$.

Javob: $[-6; 3]$.

### 20 [A]
Soha: $x \ge 3$. E'tibor beramiz: $(x - 3) + (4x + 8) = 5x + 5$. Kvadratga kötaramiz:
$5x + 5 + 2\sqrt{(x - 3)(4x + 8)} \le 5x + 5 \Rightarrow \sqrt{(x - 3)(4x + 8)} \le 0$.
Bu faqat $x = 3$ yoki $x = -2$ da; sohada faqat $x = 3$.

Javob: $\{3\}$.

### 21 [D]
$a = \sqrt[3]{x - 3}$, $b = \sqrt[3]{x + 3}$, $c = \sqrt[3]{2x}$; $a^3 + b^3 = c^3$. Kub funksiya ösuvçi, şuning uçun:
$a + b \ge c \iff (a + b)^3 \ge c^3 \iff 3ab(a + b) \ge 0$.
$ab \ge 0 \iff x^2 \ge 9$; $a + b \ge 0 \iff x \ge 0$.
$ab(a + b) \ge 0$: $x \ge 3$ (ikkalasi nomanfiy) yoki $-3 \le x \le 0$ (ikkalasi nomusbat).

Javob: $[-3; 0] \cup [3; +\infty)$.

### 22 [C]
Soha: $(x - 3)(x - 6) \ge 0 \Rightarrow x \le 3$ yoki $x \ge 6$. Maxraj: $-3x^2 + 2x + 33 = -(x + 3)(3x - 11)$.
$x = 3$, $x = 6$ da surat nol, maxraj nol emas: yeçim.
Qolgan nuqtalarda tengsizlik $\dfrac{(x + 2)(x - 1)}{(x + 3)(3x - 11)} \ge 0$ ga teng, intervallar usuli: $x < -3$, $-2 \le x \le 1$, $x > \dfrac{11}{3}$.
Soha bilan: $(-\infty; -3) \cup [-2; 1] \cup [6; +\infty)$, va $\{3\}$.

Javob: $(-\infty; -3) \cup [-2; 1] \cup \{3\} \cup [6; +\infty)$.

### 23 [A]
Soha: $x \ge 5$. $x = 5$ da $0 \le 0$ — töğri.
$x > 5$ da $\sqrt{x - 5} > 0$ ga bölamiz: $\dfrac{1}{x + 1} \le \dfrac{1}{3x + 1}$. Maxrajlar musbat, demak $3x + 1 \le x + 1 \Rightarrow x \le 0$ — mos emas.

Javob: $\{5\}$.

### 24 [D]
$a = x^2 - 2x - 15$, $b = 3x^2 - 15x$ desak, $a + b = 4x^2 - 17x - 15$. Tengsizlik: $\sqrt{a} + \sqrt{b} \le \sqrt{a + b}$.
Kvadratga kötarsak, $2\sqrt{ab} \le 0$, ya'ni $a, b \ge 0$ va ulardan biri nol.
$a = (x - 5)(x + 3) = 0 \Rightarrow x = 5$ yoki $x = -3$; ikkalasida $b \ge 0$.
$b = 3x(x - 5) = 0 \Rightarrow x = 0$ ($a = -15 < 0$, mos emas) yoki $x = 5$.

Javob: $\{-3\} \cup \{5\}$.

### 25 [C]
Har bir qöşiluvçi $x^2$ ösganda kamayadi, eng katta qiymati $x = 0$ da:
$2\cdot 6 + 5 + 3\cdot 2 = 23$.
Demak, çap tomon $\le 23$, tenglik faqat $x = 0$ da.

Javob: $\{0\}$.

## 2-test

### 1 [A]
$\sqrt{x^2 - 6x + 5} \ge 0$ doim, manfiy bölolmaydi.

Javob: $\varnothing$.

### 2 [B]
Juft darajali ildiz nomanfiy, demak u nolga teng bölişi kerak:
$5x - 10 = 0 \Rightarrow x = 2$.

Javob: $\{2\}$.

### 3 [D]
Ildiz doim $-3$ dan katta, faqat aniqlaniş sohasini topamiz:
$\dfrac{x}{x - 5} \ge 0 \Rightarrow x \le 0$ yoki $x > 5$.

Javob: $(-\infty; 0] \cup (5; +\infty)$.

### 4 [D]
Kub ildiz ösuvçi, kubga kötaramiz:
$3x^2 + 12x - 8 > -8 \Rightarrow 3x(x + 4) > 0 \Rightarrow x < -4$ yoki $x > 0$.

Javob: $(-\infty; -4) \cup (0; +\infty)$.

### 5 [C]
Kvadratga kötaramiz: $4x + 21 > 25 \Rightarrow x > 1$.

Javob: $(1; +\infty)$.

### 6 [D]
Kvadratga kötaramiz: $\dfrac{x + 5}{4 - x} > 4$.
$\dfrac{x + 5 - 4(4 - x)}{4 - x} > 0 \Rightarrow \dfrac{5x - 11}{4 - x} > 0 \Rightarrow \dfrac{11}{5} < x < 4$.

Javob: $\Bigl(\dfrac{11}{5}; 4\Bigr)$.

### 7 [B]
$x \ne 5$ da $\dfrac{x - 5}{5(x - 5)} = \dfrac{1}{5}$, $\sqrt{\dfrac{1}{5}} < 2$ doim töğri.
Faqat $x = 5$ çiqarib taşlanadi.

Javob: $(-\infty; 5) \cup (5; +\infty)$.

### 8 [A]
$\sqrt[4]{(x - 5)^2} = \sqrt{|x - 5|} \le 2 \Rightarrow |x - 5| \le 4$.
$1 \le x \le 9$.

Javob: $[1; 9]$.

### 9 [B]
Kubga kötaramiz: $-x^2 + 8x + 1 > 1 \Rightarrow x(8 - x) > 0 \Rightarrow 0 < x < 8$.

Javob: $(0; 8)$.

### 10 [D]
$\sqrt{A} > \sqrt{B} \iff A > B \ge 0$:
$-3x + 18 > x + 2 \ge 0 \Rightarrow x < 4$ va $x \ge -2$.

Javob: $[-2; 4)$.

### 11 [A]
$\sqrt{A} < \sqrt{B} \iff 0 \le A < B$:
$0 \le x < -2x + 12 \Rightarrow 0 \le x < 4$.

Javob: $[0; 4)$.

### 12 [C]
Soha: $(x - 2)(x - 6) \ge 0 \Rightarrow x \le 2$ yoki $x \ge 6$.
$x = 2$, $x = 6$ da ifoda nol. Qolgan nuqtalarda ildiz musbat, demak $x \ge 0$.
Natija: $[0; 2] \cup [6; +\infty)$.

Javob: $[0; 2] \cup [6; +\infty)$.

### 13 [C]
Soha: $x(x + 3) \ge 0 \Rightarrow x \le -3$ yoki $x \ge 0$.
$x^2 + 3x - 18 = (x + 6)(x - 3) \le 0 \Rightarrow -6 \le x \le 3$.
Kesişma ($x = -3$, $x = 0$ ham kiradi): $[-6; -3] \cup [0; 3]$.

Javob: $[-6; -3] \cup [0; 3]$.

### 14 [A]
Soha: $x^2 \ge 9$, $x \ne 7$.
$x = \pm 3$ da surat nol — yeçim ($x = -1$, $x = 1$ sohaga kirmaydi).
Qolgan nuqtalarda $\dfrac{x - 1}{x - 7} \le 0 \Rightarrow 1 \le x < 7$, sohada $(3; 7)$.

Javob: $\{-3\} \cup [3; 7)$.

### 15 [A]
$t = \sqrt[4]{x} \ge 0$: $3t^2 - 13t + 4 \ge 0 \Rightarrow (3t - 1)(t - 4) \ge 0$.
$t \le \dfrac{1}{3}$ yoki $t \ge 4 \Rightarrow 0 \le x \le \dfrac{1}{81}$ yoki $x \ge 256$.

Javob: $\Bigl[0; \dfrac{1}{81}\Bigr] \cup [256; +\infty)$.

### 16 [B]
Soha: $\dfrac{x - 15}{x + 15} > 0 \Rightarrow x < -15$ yoki $x > 15$.
$t = \sqrt{\dfrac{x - 15}{x + 15}} > 0$: $t - \dfrac{1}{t} < \dfrac{15}{4} \Rightarrow 4t^2 - 15t - 4 < 0 \Rightarrow (4t + 1)(t - 4) < 0 \Rightarrow t < 4$.
$\dfrac{x - 15}{x + 15} < 16 \Rightarrow \dfrac{-15x - 255}{x + 15} < 0 \Rightarrow \dfrac{x + 17}{x + 15} > 0$.
$x < -17$ yoki $x > -15$; soha bilan: $x < -17$ yoki $x > 15$.

Javob: $(-\infty; -17) \cup (15; +\infty)$.

### 17 [B]
Soha: $-x^2 + 10x \ge 0 \Rightarrow 0 \le x \le 10$, bu yerda $x + 5 > 0$.
Kvadratga kötaramiz: $-x^2 + 10x < x^2 + 10x + 25 \Rightarrow 2x^2 + 25 > 0$ — doim töğri.

Javob: $[0; 10]$.

### 18 [C]
$\sqrt{x + 84} > -3x$, soha $x \ge -84$.
$x \ge 0$ da doim töğri.
$x < 0$ da: $x + 84 > 9x^2 \Rightarrow 9x^2 - x - 84 < 0 \Rightarrow -3 < x < \dfrac{28}{9}$, ya'ni $-3 < x < 0$.

Javob: $(-3; +\infty)$.

### 19 [B]
Şart: $\sqrt{x + 12} \ge x$, $x \ge -12$.
$-12 \le x < 0$ da doim töğri.
$x \ge 0$ da: $x^2 - x - 12 \le 0 \Rightarrow -3 \le x \le 4$, ya'ni $0 \le x \le 4$.

Javob: $[-12; 4]$.

### 20 [D]
Soha: $x \ge 5$. $(3x - 15) + 2x = 5x - 15$, kvadratga kötaramiz:
$2\sqrt{(3x - 15)\cdot 2x} \le 0 \Rightarrow (3x - 15)\cdot 2x = 0 \Rightarrow x = 5$ yoki $x = 0$.
Sohada faqat $x = 5$.

Javob: $\{5\}$.

### 21 [C]
$a = \sqrt[3]{x - 5}$, $b = \sqrt[3]{x + 5}$, $c = \sqrt[3]{2x}$, $a^3 + b^3 = c^3$.
$a + b \ge c \iff (a + b)^3 \ge c^3 \iff 3ab(a + b) \ge 0$.
$ab \ge 0 \iff x^2 \ge 25$; $a + b \ge 0 \iff x \ge 0$.
Natija: $x \ge 5$ yoki $-5 \le x \le 0$.

Javob: $[-5; 0] \cup [5; +\infty)$.

### 22 [A]
Soha: $(x - 2)(x + 1) \ge 0 \Rightarrow x \le -1$ yoki $x \ge 2$. Maxraj: $-3x^2 - 22x - 7 = -(3x + 1)(x + 7)$.
$x = -1$, $x = 2$ da surat nol — yeçim.
Qolgan nuqtalarda $\dfrac{(x + 3)(x + 6)}{(3x + 1)(x + 7)} \ge 0$: $x < -7$, $-6 \le x \le -3$, $x > -\dfrac{1}{3}$.
Soha bilan: $(-\infty; -7) \cup [-6; -3] \cup [2; +\infty)$, va $\{-1\}$.

Javob: $(-\infty; -7) \cup [-6; -3] \cup \{-1\} \cup [2; +\infty)$.

### 23 [D]
Soha: $x \ge 1$. $x = 1$ da $0 \le 0$ — töğri.
$x > 1$ da ildizga bölamiz: $\dfrac{1}{x + 4} \le \dfrac{1}{2x + 4} \Rightarrow 2x + 4 \le x + 4 \Rightarrow x \le 0$ — mos emas.

Javob: $\{1\}$.

### 24 [C]
$a = 3x^2 - 15x - 18$, $b = 2x^2 - 16x + 24$, $a + b = 5x^2 - 31x + 6$. Kvadratga kötarsak, $2\sqrt{ab} \le 0$: $a, b \ge 0$ va biri nol.
$a = 3(x - 6)(x + 1) = 0 \Rightarrow x = 6$ yoki $x = -1$; ikkalasida $b \ge 0$ ($b(-1) = 42$).
$b = 2(x - 2)(x - 6) = 0 \Rightarrow x = 2$ ($a = -36 < 0$, mos emas) yoki $x = 6$.

Javob: $\{-1\} \cup \{6\}$.

### 25 [C]
Har bir qöşiluvçining eng katta qiymati $x = 0$ da:
$7 + 3\cdot 4 + 2\cdot 3 = 25$.
Demak, çap tomon $\le 25$, tenglik faqat $x = 0$ da.

Javob: $\{0\}$.

## 3-test

### 1 [A]
Kvadrat ildiz manfiy bölmaydi.

Javob: $\varnothing$.

### 2 [B]
Juft darajali ildiz nomanfiy, demak u nolga teng:
$4x + 20 = 0 \Rightarrow x = -5$.

Javob: $\{-5\}$.

### 3 [D]
Ildiz doim $-1$ dan katta, aniqlaniş sohasini topamiz:
$\dfrac{4x - 8}{x - 7} \ge 0 \Rightarrow x \le 2$ yoki $x > 7$.

Javob: $(-\infty; 2] \cup (7; +\infty)$.

### 4 [C]
Toq darajali ildiz ösuvçi:
$2x^2 - 16x + 23 > -1 \Rightarrow x^2 - 8x + 12 > 0 \Rightarrow (x - 2)(x - 6) > 0$.
$x < 2$ yoki $x > 6$.

Javob: $(-\infty; 2) \cup (6; +\infty)$.

### 5 [B]
Kvadratga kötaramiz: $5x + 14 > 4 \Rightarrow x > -2$.

Javob: $(-2; +\infty)$.

### 6 [A]
Kvadratga kötaramiz: $\dfrac{x}{9 - x} > \dfrac{1}{4}$.
$\dfrac{4x - (9 - x)}{4(9 - x)} > 0 \Rightarrow \dfrac{5x - 9}{9 - x} > 0 \Rightarrow \dfrac{9}{5} < x < 9$.

Javob: $\Bigl(\dfrac{9}{5}; 9\Bigr)$.

### 7 [D]
$x \ne 0$ da $\dfrac{x}{4x} = \dfrac{1}{4}$, $\sqrt{\dfrac{1}{4}} = \dfrac{1}{2} < 1$ — töğri.
Faqat $x = 0$ çiqarib taşlanadi.

Javob: $(-\infty; 0) \cup (0; +\infty)$.

### 8 [D]
$\sqrt[4]{(x + 1)^2} = \sqrt{|x + 1|} \le 3 \Rightarrow |x + 1| \le 9$.
$-10 \le x \le 8$.

Javob: $[-10; 8]$.

### 9 [C]
Töqqizinçi darajaga kötaramiz (toq daraja):
$-x^2 - 6x + 1 > 1 \Rightarrow x(x + 6) < 0 \Rightarrow -6 < x < 0$.

Javob: $(-6; 0)$.

### 10 [A]
$-4x + 25 > x \ge 0 \Rightarrow 0 \le x < 5$.

Javob: $[0; 5)$.

### 11 [D]
$0 \le 3x - 6 < -x + 10$:
$x \ge 2$ va $4x < 16 \Rightarrow x < 4$.

Javob: $[2; 4)$.

### 12 [C]
Soha: $(x - 4)(x + 2) \ge 0 \Rightarrow x \le -2$ yoki $x \ge 4$.
$x = -2$, $x = 4$ da ifoda nol. Qolgan nuqtalarda $x + 5 \ge 0$, ya'ni $x \ge -5$.
Natija: $[-5; -2] \cup [4; +\infty)$.

Javob: $[-5; -2] \cup [4; +\infty)$.

### 13 [B]
Soha: $(x - 3)(x - 6) \ge 0 \Rightarrow x \le 3$ yoki $x \ge 6$.
$x^2 - 9x + 8 = (x - 1)(x - 8) \le 0 \Rightarrow 1 \le x \le 8$.
Kesişma: $[1; 3] \cup [6; 8]$.

Javob: $[1; 3] \cup [6; 8]$.

### 14 [A]
Soha: $x^2 \ge 36$, $x \ne 9$.
$x = \pm 6$ da surat nol — yeçim ($x = 3$, $x = -2$ sohaga kirmaydi).
Qolgan nuqtalarda $\dfrac{x + 2}{x - 9} \le 0 \Rightarrow -2 \le x < 9$, sohada $(6; 9)$.

Javob: $\{-6\} \cup [6; 9)$.

### 15 [B]
$t = \sqrt[4]{x} \ge 0$: $4t^2 - 9t + 2 \ge 0 \Rightarrow (4t - 1)(t - 2) \ge 0$.
$t \le \dfrac{1}{4}$ yoki $t \ge 2 \Rightarrow 0 \le x \le \dfrac{1}{256}$ yoki $x \ge 16$.

Javob: $\Bigl[0; \dfrac{1}{256}\Bigr] \cup [16; +\infty)$.

### 16 [D]
Soha: $x < -24$ yoki $x > 24$.
$t = \sqrt{\dfrac{x - 24}{x + 24}} > 0$: $t - \dfrac{1}{t} < \dfrac{24}{5} \Rightarrow 5t^2 - 24t - 5 < 0 \Rightarrow (5t + 1)(t - 5) < 0 \Rightarrow t < 5$.
$\dfrac{x - 24}{x + 24} < 25 \Rightarrow \dfrac{-24x - 624}{x + 24} < 0 \Rightarrow \dfrac{x + 26}{x + 24} > 0$.
$x < -26$ yoki $x > -24$; soha bilan: $x < -26$ yoki $x > 24$.

Javob: $(-\infty; -26) \cup (24; +\infty)$.

### 17 [C]
Soha: $0 \le x \le 12$, bu yerda $x + 6 > 0$.
Kvadratga kötaramiz: $-x^2 + 12x < x^2 + 12x + 36 \Rightarrow 2x^2 + 36 > 0$ — doim töğri.

Javob: $[0; 12]$.

### 18 [B]
$\sqrt{x + 20} > -x$, soha $x \ge -20$.
$x \ge 0$ da doim töğri.
$x < 0$ da: $x + 20 > x^2 \Rightarrow x^2 - x - 20 < 0 \Rightarrow -4 < x < 5$, ya'ni $-4 < x < 0$.

Javob: $(-4; +\infty)$.

### 19 [C]
Şart: $\sqrt{x + 20} \ge x$, $x \ge -20$.
$-20 \le x < 0$ da doim töğri.
$x \ge 0$ da: $x^2 - x - 20 \le 0 \Rightarrow -4 \le x \le 5$, ya'ni $0 \le x \le 5$.

Javob: $[-20; 5]$.

### 20 [A]
Soha: $x \ge 2$. $(2x - 4) + (5x + 5) = 7x + 1$, kvadratga kötaramiz:
$2\sqrt{(2x - 4)(5x + 5)} \le 0 \Rightarrow x = 2$ yoki $x = -1$.
Sohada faqat $x = 2$.

Javob: $\{2\}$.

### 21 [D]
$a = \sqrt[3]{x - 6}$, $b = \sqrt[3]{x + 6}$, $c = \sqrt[3]{2x}$, $a^3 + b^3 = c^3$.
$a + b \ge c \iff 3ab(a + b) \ge 0$.
$ab \ge 0 \iff x^2 \ge 36$; $a + b \ge 0 \iff x \ge 0$.
Natija: $x \ge 6$ yoki $-6 \le x \le 0$.

Javob: $[-6; 0] \cup [6; +\infty)$.

### 22 [C]
Soha: $(x - 5)(x - 8) \ge 0 \Rightarrow x \le 5$ yoki $x \ge 8$. Maxraj: $-3x^2 + 14x + 17 = -(3x - 17)(x + 1)$.
$x = 5$, $x = 8$ da surat nol — yeçim.
Qolgan nuqtalarda $\dfrac{x(x - 3)}{(3x - 17)(x + 1)} \ge 0$: $x < -1$, $0 \le x \le 3$, $x > \dfrac{17}{3}$.
Soha bilan: $(-\infty; -1) \cup [0; 3] \cup [8; +\infty)$, va $\{5\}$.

Javob: $(-\infty; -1) \cup [0; 3] \cup \{5\} \cup [8; +\infty)$.

### 23 [B]
Soha: $x \ge 4$. $x = 4$ da $0 \le 0$ — töğri.
$x > 4$ da: $\dfrac{1}{x + 3} \le \dfrac{1}{4x + 3} \Rightarrow 4x + 3 \le x + 3 \Rightarrow x \le 0$ — mos emas.

Javob: $\{4\}$.

### 24 [A]
$a = 2x^2 - 16x + 14$, $b = 4x^2 - 40x + 84$, $a + b = 6x^2 - 56x + 98$. Demak $2\sqrt{ab} \le 0$: $a, b \ge 0$ va biri nol.
$a = 2(x - 1)(x - 7) = 0 \Rightarrow x = 1$ ($b = 48$) yoki $x = 7$.
$b = 4(x - 3)(x - 7) = 0 \Rightarrow x = 3$ ($a = -16 < 0$, mos emas) yoki $x = 7$.

Javob: $\{1\} \cup \{7\}$.

### 25 [D]
Har bir qöşiluvçining eng katta qiymati $x = 0$ da:
$3\cdot 5 + 2\cdot 3 + 4\cdot 1 = 25$.
Çap tomon $\le 25$, tenglik faqat $x = 0$ da.

Javob: $\{0\}$.
