# 20. Qisqa köpaytiriş formulalari (3-qism)

## 1-test

### 1 [B]
Tenglikni kvadratga oşiramiz: $\left(a + \dfrac{4}{a}\right)^2 = a^2 + 8 + \dfrac{16}{a^2} = 49$.
$a^2 + \dfrac{16}{a^2} = 49 - 8 = 41$.

Javob: $41$.

### 2 [C]
$\dfrac{a^4 + 25}{a^2} = a^2 + \dfrac{25}{a^2}$.
$\left(a - \dfrac{5}{a}\right)^2 = a^2 - 10 + \dfrac{25}{a^2} = 36$, demak $a^2 + \dfrac{25}{a^2} = 46$.

Javob: $46$.

### 3 [B]
$x^3 - y^3 = (x - y)^3 + 3xy(x - y)$ formulasidan foydalanamiz, bunda $x = a$, $y = \dfrac{4}{a}$, $xy = 4$:
$a^3 - \dfrac{64}{a^3} = 3^3 + 3 \cdot 4 \cdot 3 = 27 + 36 = 63$.

Javob: $63$.

### 4 [D]
$\dfrac{a^6 + 125}{a^3} = a^3 + \dfrac{125}{a^3}$.
$x^3 + y^3 = (x + y)^3 - 3xy(x + y)$, bunda $xy = a \cdot \dfrac{5}{a} = 5$:
$(-5)^3 - 3 \cdot 5 \cdot (-5) = -125 + 75 = -50$.

Javob: $-50$.

### 5 [C]
Kvadratga oşiramiz ($3a \cdot \dfrac{1}{a} = 3$): $9a^2 - 6 + \dfrac{1}{a^2} = 16$, demak $9a^2 + \dfrac{1}{a^2} = 22$.
Yana kvadratga oşiramiz: $81a^4 + 18 + \dfrac{1}{a^4} = 484$.
$81a^4 + \dfrac{1}{a^4} = 466$.

Javob: $466$.

### 6 [D]
$(a + b - c)^2 = a^2 + b^2 + c^2 + 2(ab - bc - ca)$.
Şartga köra $ab - bc - ca = 0$, demak $a^2 + b^2 + c^2 = 5^2 = 25$.

Javob: $25$.

### 7 [B]
$a^2 + b^2 = (a - b)^2 + 2ab = 36 + 4 = 40$.
$a^4 + b^4 = (a^2 + b^2)^2 - 2a^2b^2 = 1600 - 8 = 1592$.

Javob: $1592$.

### 8 [A]
Kvadratlar ayirmasini ketma-ket qöllaymiz:
$(1 - a)(1 + a) = 1 - a^2$, $(1 - a^2)(1 + a^2) = 1 - a^4$, va hokazo.
Oxirida $(1 - a^{64})(1 + a^{64}) = 1 - a^{128}$.

Javob: $1-a^{128}$.

### 9 [C]
$A$ ni $3^2 - 1 = 8$ ga köpaytirib, kvadratlar ayirmasini ketma-ket qöllaymiz:
$8A = (3^2 - 1)(3^2 + 1) \cdots (3^{128} + 1) = 3^{256} - 1$.
$A = \dfrac{3^{256} - 1}{8}$, demak $A - \dfrac{3^{256}}{8} = -\dfrac{1}{8}$.

Javob: $-\dfrac{1}{8}$.

### 10 [A]
$s_n = x^n + y^n$ uçun $s_n = a s_{n-1} - b s_{n-2}$.
$s_2 = a^2 - 2b$, $s_3 = a^3 - 3ab$, $s_4 = a s_3 - b s_2 = a^4 - 4a^2b + 2b^2$.
$s_5 = a s_4 - b s_3 = a^5 - 4a^3b + 2ab^2 - a^3b + 3ab^2 = a^5 - 5a^3b + 5ab^2$.

Javob: $a^5-5a^3b+5ab^2$.

### 11 [B]
$a^2 + \dfrac{1}{a^2} = 25 - 2 = 23$, $a^3 + \dfrac{1}{a^3} = 125 - 3 \cdot 5 = 110$.
$a^5 + \dfrac{1}{a^5} = \left(a^2 + \dfrac{1}{a^2}\right)\left(a^3 + \dfrac{1}{a^3}\right) - \left(a + \dfrac{1}{a}\right) = 23 \cdot 110 - 5 = 2525$.

Javob: $2525$.

### 12 [D]
$y = -\dfrac{2}{x}$ deb olsak, $x + y = 5$, $xy = -2$ va $x^5 + y^5 = x^5 - \dfrac{32}{x^5}$.
$x^5 + y^5 = a^5 - 5a^3b + 5ab^2$ formulasiga $a = 5$, $b = -2$ ni qöyamiz:
$3125 + 1250 + 100 = 4475$.

Javob: $4475$.

### 13 [A]
$a^2 = 2^{20} + 2^{11} + 1 = (2^{10})^2 + 2 \cdot 2^{10} + 1 = (2^{10} + 1)^2$.
$a = 2^{10} + 1$, demak $\dfrac{a - 1}{2^7} = \dfrac{2^{10}}{2^7} = 2^3 = 8$.

Javob: $8$.

### 14 [C]
Tenglikni $(x - 1)$ ga köpaytiramiz ($x = 1$ şartni qanoatlantirmaydi): $x^6 - 1 = 8(x - 1)$.
$x^6 = 8x - 7$, demak $x^6 - 8x = -7$.

Javob: $-7$.

## 2-test

### 1 [C]
Kvadratga oşiramiz: $m^2 + 10 + \dfrac{25}{m^2} = 64$.
$m^2 + \dfrac{25}{m^2} = 54$.

Javob: $54$.

### 2 [D]
$\dfrac{m^4 + 64}{m^2} = m^2 + \dfrac{64}{m^2}$.
$\left(m - \dfrac{8}{m}\right)^2 = m^2 - 16 + \dfrac{64}{m^2} = 25$, demak $m^2 + \dfrac{64}{m^2} = 41$.

Javob: $41$.

### 3 [B]
$x^3 - y^3 = (x - y)^3 + 3xy(x - y)$, bunda $xy = 5$:
$m^3 - \dfrac{125}{m^3} = 4^3 + 3 \cdot 5 \cdot 4 = 64 + 60 = 124$.

Javob: $124$.

### 4 [C]
$\dfrac{m^6 + 216}{m^3} = m^3 + \dfrac{216}{m^3}$, $xy = 6$:
$(-6)^3 - 3 \cdot 6 \cdot (-6) = -216 + 108 = -108$.

Javob: $-108$.

### 5 [A]
Kvadratga oşiramiz ($2m \cdot \dfrac{3}{m} = 6$): $4m^2 - 12 + \dfrac{9}{m^2} = 25$, demak $4m^2 + \dfrac{9}{m^2} = 37$.
Yana kvadratga oşiramiz: $16m^4 + 72 + \dfrac{81}{m^4} = 1369$.
$16m^4 + \dfrac{81}{m^4} = 1297$.

Javob: $1297$.

### 6 [A]
$(a + b - c)^2 = a^2 + b^2 + c^2 + 2(ab - bc - ca) = a^2 + b^2 + c^2$, çunki $ab - bc - ca = 0$.
Demak $a^2 + b^2 + c^2 = 36$.

Javob: $36$.

### 7 [D]
$m^2 + n^2 = (m - n)^2 + 2mn = 49 + 6 = 55$.
$m^4 + n^4 = 55^2 - 2 \cdot 9 = 3025 - 18 = 3007$.

Javob: $3007$.

### 8 [C]
Kvadratlar ayirmasini ketma-ket qöllaymiz: $1 - m^2$, $1 - m^4$, ..., $(1 - m^{128})(1 + m^{128}) = 1 - m^{256}$.

Javob: $1-m^{256}$.

### 9 [B]
$A$ ni $4^2 - 1 = 15$ ga köpaytiramiz: $15A = 4^{512} - 1$.
$A = \dfrac{4^{512} - 1}{15}$, demak $A - \dfrac{4^{512}}{15} = -\dfrac{1}{15}$.

Javob: $-\dfrac{1}{15}$.

### 10 [A]
$x^6 + y^6 = (x^3 + y^3)^2 - 2x^3y^3$, $x^3 + y^3 = a^3 - 3ab$.
$(a^3 - 3ab)^2 - 2b^3 = a^6 - 6a^4b + 9a^2b^2 - 2b^3$.

Javob: $a^6-6a^4b+9a^2b^2-2b^3$.

### 11 [D]
$a^2 + \dfrac{1}{a^2} = 36 - 2 = 34$, $a^3 + \dfrac{1}{a^3} = 216 - 18 = 198$.
$a^5 + \dfrac{1}{a^5} = 34 \cdot 198 - 6 = 6732 - 6 = 6726$.

Javob: $6726$.

### 12 [B]
$y = -\dfrac{3}{m}$ deb olsak, $m + y = 4$, $my = -3$, $m^5 + y^5 = m^5 - \dfrac{243}{m^5}$.
$a^5 - 5a^3b + 5ab^2$ ga $a = 4$, $b = -3$ ni qöyamiz:
$1024 + 960 + 180 = 2164$.

Javob: $2164$.

### 13 [D]
$a^2 = 2^{24} + 2^{13} + 1 = (2^{12} + 1)^2$, demak $a = 2^{12} + 1$.
$\dfrac{a - 1}{2^8} = \dfrac{2^{12}}{2^8} = 16$.

Javob: $16$.

### 14 [C]
$(x - 1)$ ga köpaytiramiz: $x^6 - 1 = 12(x - 1)$.
$x^6 - 12x = -11$.

Javob: $-11$.

## 3-test

### 1 [C]
Kvadratga oşiramiz: $y^2 + 12 + \dfrac{36}{y^2} = 81$.
$y^2 + \dfrac{36}{y^2} = 69$.

Javob: $69$.

### 2 [B]
$\left(y - \dfrac{10}{y}\right)^2 = y^2 - 20 + \dfrac{100}{y^2} = 49$.
$\dfrac{y^4 + 100}{y^2} = y^2 + \dfrac{100}{y^2} = 69$.

Javob: $69$.

### 3 [D]
$x^3 - y^3 = (x - y)^3 + 3xy(x - y)$, bunda $xy = 6$:
$5^3 + 3 \cdot 6 \cdot 5 = 125 + 90 = 215$.

Javob: $215$.

### 4 [A]
$\dfrac{y^6 + 512}{y^3} = y^3 + \dfrac{512}{y^3}$, $xy = 8$:
$(-6)^3 - 3 \cdot 8 \cdot (-6) = -216 + 144 = -72$.

Javob: $-72$.

### 5 [A]
Kvadratga oşiramiz ($4y \cdot \dfrac{1}{y} = 4$): $16y^2 - 8 + \dfrac{1}{y^2} = 36$, demak $16y^2 + \dfrac{1}{y^2} = 44$.
Yana kvadratga oşiramiz: $256y^4 + 32 + \dfrac{1}{y^4} = 1936$.
$256y^4 + \dfrac{1}{y^4} = 1904$.

Javob: $1904$.

### 6 [B]
$(a + b - c)^2 = a^2 + b^2 + c^2 + 2(ab - bc - ca) = a^2 + b^2 + c^2$.
Demak $a^2 + b^2 + c^2 = 49$.

Javob: $49$.

### 7 [D]
$x^2 + y^2 = (x - y)^2 + 2xy = 25 + 8 = 33$.
$x^4 + y^4 = 33^2 - 2 \cdot 16 = 1089 - 32 = 1057$.

Javob: $1057$.

### 8 [A]
Kvadratlar ayirmasini ketma-ket qöllaymiz: oxirida $(1 - y^{256})(1 + y^{256}) = 1 - y^{512}$.

Javob: $1-y^{512}$.

### 9 [C]
$A$ ni $5^2 - 1 = 24$ ga köpaytiramiz: $24A = 5^{1024} - 1$.
$A - \dfrac{5^{1024}}{24} = -\dfrac{1}{24}$.

Javob: $-\dfrac{1}{24}$.

### 10 [B]
$s_n = x^n + y^n$ uçun $s_n = a s_{n-1} - b s_{n-2}$.
$s_5 = a^5 - 5a^3b + 5ab^2$, $s_6 = a^6 - 6a^4b + 9a^2b^2 - 2b^3$.
$s_7 = a s_6 - b s_5 = a^7 - 6a^5b + 9a^3b^2 - 2ab^3 - a^5b + 5a^3b^2 - 5ab^3 = a^7 - 7a^5b + 14a^3b^2 - 7ab^3$.

Javob: $a^7-7a^5b+14a^3b^2-7ab^3$.

### 11 [A]
$a^2 + \dfrac{1}{a^2} = 49 - 2 = 47$, $a^3 + \dfrac{1}{a^3} = 343 - 21 = 322$.
$a^5 + \dfrac{1}{a^5} = 47 \cdot 322 - 7 = 15\,134 - 7 = 15\,127$.

Javob: $15127$.

### 12 [C]
$x = -\dfrac{4}{y}$ deb olsak, $y + x = 3$, $xy = -4$, $y^5 + x^5 = y^5 - \dfrac{1024}{y^5}$.
$a^5 - 5a^3b + 5ab^2$ ga $a = 3$, $b = -4$ ni qöyamiz:
$243 + 540 + 240 = 1023$.

Javob: $1023$.

### 13 [D]
$a^2 = 2^{28} + 2^{15} + 1 = (2^{14} + 1)^2$, demak $a = 2^{14} + 1$.
$\dfrac{a - 1}{2^9} = \dfrac{2^{14}}{2^9} = 32$.

Javob: $32$.

### 14 [B]
$(x - 1)$ ga köpaytiramiz: $x^6 - 1 = 15(x - 1)$.
$x^6 - 15x = -14$.

Javob: $-14$.
