# 51. Arifmetik progressiya yiğindisi

## 1-test

### 1 [D]
Yiğindi formulasi: $S_n = \dfrac{2a_1 + (n - 1)d}{2}\cdot n$.
$S_{18} = \dfrac{2\cdot(-5) + 17\cdot 4}{2}\cdot 18 = 58\cdot 9 = 522$.

Javob: $522$.

### 2 [A]
$S_n = \dfrac{a_1 + a_n}{2}\cdot n$:
$S_{14} = \dfrac{-3 + 36}{2}\cdot 14 = 33\cdot 7 = 231$.

Javob: $231$.

### 3 [D]
$S_{17} = \dfrac{a_1 + a_{17}}{2}\cdot 17 = \dfrac{-8 + 40}{2}\cdot 17 = 16\cdot 17 = 272$.

Javob: $272$.

### 4 [C]
$a_7 - a_3 = 4d = -12 \Rightarrow d = -3$, $a_1 = a_3 - 2d = 11$.
$S_{14} = \dfrac{2\cdot 11 + 13\cdot(-3)}{2}\cdot 14 = (22 - 39)\cdot 7 = -119$.

Javob: $-119$.

### 5 [B]
$S_{11} = \dfrac{a_1 + a_{11}}{2}\cdot 11 = 33 \Rightarrow a_1 + a_{11} = 6$.
$a_1 = 6 - (-7) = 13$.

Javob: $13$.

### 6 [C]
Toq sondagi hadlar yiğindisi örta had bilan ifodalanadi: $S_{11} = 11a_6$.
$S_{11} = 11\cdot(-9) = -99$.

Javob: $-99$.

### 7 [A]
$S_{10} = 5(2a_1 + 9d) = 20 \Rightarrow 2a_1 + 9d = 4$.
$a_3 = a_1 + 2d = -3 \Rightarrow 2a_1 + 4d = -6$. Ayiramiz: $5d = 10 \Rightarrow d = 2$, $a_1 = -7$.
$a_{14} = -7 + 13\cdot 2 = 19$.

Javob: $19$.

### 8 [C]
$a_9 - a_5 = 4d = -12 \Rightarrow d = -3$.
$a_1 + a_{14} = a_5 + a_{10} = a_5 + a_9 + d = 18 - 3 = 15$.
$S_{14} = \dfrac{15}{2}\cdot 14 = 105$.

Javob: $105$.

### 9 [B]
$d = 13{,}5 - 12{,}7 = 0{,}8$. Hadlar soni: $\dfrac{26{,}3 - 12{,}7}{0{,}8} + 1 = 17 + 1 = 18$.
$S = \dfrac{12{,}7 + 26{,}3}{2}\cdot 18 = 39\cdot 9 = 351$.

Javob: $351$.

### 10 [D]
$a_1 = 23$, $a_{15} = -30 + 25 = -5$.
$S_{15} = \dfrac{23 + (-5)}{2}\cdot 15 = 9\cdot 15 = 135$.

Javob: $135$.

### 11 [A]
$a_n = S_n - S_{n-1}$:
$a_{18} = S_{18} - S_{17} = 2(18^2 - 17^2) + 5 = 2\cdot 35 + 5 = 75$.

Javob: $75$.

### 12 [C]
Uç xonali $24$ ga karrali sonlar: $120 = 24\cdot 5$ dan $984 = 24\cdot 41$ gaça, jami $41 - 5 + 1 = 37$ ta.
$S = \dfrac{120 + 984}{2}\cdot 37 = 552\cdot 37 = 20424$.

Javob: $20424$.

### 13 [B]
Sonlar $9k + 4$ körinişda: $13, 22, \ldots, 94$ ($k = 1, \ldots, 10$), jami $10$ ta.
$S = \dfrac{13 + 94}{2}\cdot 10 = 535$.

Javob: $535$.

### 14 [D]
Oraliqdagi $7$ ga karrali sonlar: $-91 = 7\cdot(-13)$ dan $161 = 7\cdot 23$ gaça, jami $23 + 13 + 1 = 37$ ta.
$S = \dfrac{-91 + 161}{2}\cdot 37 = 35\cdot 37 = 1295$.

Javob: $1295$.

### 15 [A]
Doiralar soni $1 + 2 + \ldots + 45$:
$S = \dfrac{45\cdot 46}{2} = 1035$.

Javob: $1035$.

### 16 [C]
Sotuvlar $d = -2$ bölgan progressiya, $n = 15$:
$315 = \dfrac{2a_1 - 2\cdot 14}{2}\cdot 15 \Rightarrow 21 = a_1 - 14 \Rightarrow a_1 = 35$.

Javob: $35$.

### 17 [D]
$a_1 = x + 5$, $d = (2x + 9) - (x + 5) = x + 4$.
$S_{12} = 6\bigl(2(x + 5) + 11(x + 4)\bigr) = 6(13x + 54) = 168$.
$13x + 54 = 28 \Rightarrow x = -2$.

Javob: $-2$.

### 18 [B]
Qöşiluvçilar soni $10$ ta, suratlar yiğindisi: $10x + (1 + 3 + \ldots + 19) = 10x + 100$.
$\dfrac{10x + 100}{x} = -10 \Rightarrow 10x + 100 = -10x \Rightarrow x = -5$.
$\dfrac{x + 2}{x - 1} = \dfrac{-3}{-6} = \dfrac{1}{2}$.

Javob: $\dfrac{1}{2}$.

### 19 [A]
Formula: $1^2 + 2^2 + \ldots + n^2 = \dfrac{n(n + 1)(2n + 1)}{6}$.
$\dfrac{15\cdot 16\cdot 31}{6} = 1240$.

Javob: $1240$.

### 20 [C]
Formula: $1^3 + 2^3 + \ldots + n^3 = \Bigl(\dfrac{n(n + 1)}{2}\Bigr)^2$.
$\Bigl(\dfrac{12\cdot 13}{2}\Bigr)^2 = 78^2 = 6084$.

Javob: $6084$.

### 17 [B]

### 19 [A]

### 20 [C]

Javob: $29241$.
