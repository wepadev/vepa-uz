# 8. Oddiy kasrlar 1-qism

## 1-test

### 1 [D]
Kasrni qisqartiriş uçun surat va maxrajni ularning EKUBiga bölamiz: $\operatorname{EKUB}(28;42) = 14$.
$\dfrac{28}{42} = \dfrac{28:14}{42:14} = \dfrac{2}{3}$.

Javob: $\dfrac{2}{3}$.

### 2 [B]
Avval $10$ ga, keyin $90$ ga qisqartiramiz:
$\dfrac{2250}{3150} = \dfrac{225}{315} = \dfrac{225:45}{315:45} = \dfrac{5}{7}$.

Javob: $\dfrac{5}{7}$.

### 3 [C]
Butun qismni maxrajga köpaytirib, suratga qöşamiz:
$6\dfrac{5}{8} = \dfrac{6\cdot8 + 5}{8} = \dfrac{53}{8}$.

Javob: $\dfrac{53}{8}$.

### 4 [C]
Suratni maxrajga qoldiqli bölamiz: $137 = 15\cdot9 + 2$.
Bölinma butun qism, qoldiq yangi surat böladi: $\dfrac{137}{15} = 9\dfrac{2}{15}$.

Javob: $9\dfrac{2}{15}$.

### 5 [A]
Umumiy maxraj — maxrajlarning EKUKi: $\operatorname{EKUK}(20;30) = 60$.
Qöşimça köpaytuvçilar: $60:20 = 3$, $60:30 = 2$.
$\dfrac{7}{20} = \dfrac{21}{60}$, $\dfrac{11}{30} = \dfrac{22}{60}$.

Javob: $\dfrac{21}{60}$ va $\dfrac{22}{60}$.

### 6 [C]
Kasrlarni umumiy maxraj $108$ ga keltiramiz:
$a = \dfrac{7}{54} = \dfrac{14}{108}$, $b = \dfrac{5}{36} = \dfrac{15}{108}$.
$14 < 15$, demak $a < b$.

Javob: $a<b$.

### 7 [D]
Umumiy maxraj $\operatorname{EKUK}(9;72;30) = 360$ ga keltiramiz:
$a = \dfrac{160}{360}$, $b = \dfrac{155}{360}$, $c = \dfrac{156}{360}$.
$155 < 156 < 160$, demak $b < c < a$.

Javob: $b<c<a$.

### 8 [D]
Umumiy maxraj $720$ ga keltiramiz:
$a = \dfrac{9}{16} = \dfrac{405}{720}$, $b = \dfrac{5}{9} = \dfrac{400}{720}$, $c = \dfrac{11}{20} = \dfrac{396}{720}$.
$396 < 400 < 405$, demak $c < b < a$.

Javob: $c<b<a$.

### 9 [A]
Maxrajlari bir xil kasrlarni qöşişda suratlar qöşiladi, maxraj özgarmaydi:
$\dfrac{5}{14} + \dfrac{6}{14} = \dfrac{11}{14}$.

Javob: $\dfrac{11}{14}$.

### 10 [C]
Kasr qismlarni qöşamiz: $\dfrac{15}{19} + \dfrac{4}{19} = \dfrac{19}{19} = 1$.
$3 + 1 = 4$.

Javob: $4$.

### 11 [B]
$\dfrac{3}{13} < \dfrac{8}{13}$, şuning uçun kamayuvçidan bir butunni kasrga aylantiramiz:
$16\dfrac{3}{13} = 15\dfrac{16}{13}$.
$15\dfrac{16}{13} - 9\dfrac{8}{13} = 6\dfrac{8}{13}$.

Javob: $6\dfrac{8}{13}$.

### 12 [B]
Kasrlarni köpaytirişda avval qisqartiramiz:
$\dfrac{45}{64}\cdot\dfrac{32}{75} = \dfrac{45\cdot32}{64\cdot75} = \dfrac{3\cdot1}{2\cdot5} = \dfrac{3}{10}$.

Javob: $\dfrac{3}{10}$.

### 13 [D]
Aralaş sonlarni notöğri kasrga aylantiramiz:
$2\dfrac{2}{5}\cdot1\dfrac{7}{8} = \dfrac{12}{5}\cdot\dfrac{15}{8} = \dfrac{12\cdot15}{5\cdot8} = \dfrac{9}{2} = 4\dfrac{1}{2}$.

Javob: $4\dfrac{1}{2}$.

### 14 [A]
Kasrga bölish — teskari kasrga köpaytiriş:
$\dfrac{30}{49}:\dfrac{45}{56} = \dfrac{30}{49}\cdot\dfrac{56}{45} = \dfrac{2\cdot8}{7\cdot3} = \dfrac{16}{21}$.

Javob: $\dfrac{16}{21}$.

### 15 [C]
Notöğri kasrlarga aylantirib, teskari kasrga köpaytiramiz:
$\dfrac{15}{4}:\dfrac{3}{2} = \dfrac{15}{4}\cdot\dfrac{2}{3} = \dfrac{5}{2} = 2\dfrac{1}{2}$.

Javob: $2\dfrac{1}{2}$.

### 16 [D]
Umumiy maxraj $\operatorname{EKUK}(12;18) = 36$:
$\dfrac{11}{12} - \dfrac{7}{18} = \dfrac{33}{36} - \dfrac{14}{36} = \dfrac{19}{36}$.

Javob: $\dfrac{19}{36}$.

### 17 [B]
Kasr qismlarni umumiy maxraj $60$ ga keltiramiz: $\dfrac{1}{15} = \dfrac{4}{60}$, $\dfrac{5}{12} = \dfrac{25}{60}$.
$4 < 25$, şuning uçun bir butun olamiz: $7\dfrac{4}{60} = 6\dfrac{64}{60}$.
$6\dfrac{64}{60} - 3\dfrac{25}{60} = 3\dfrac{39}{60} = 3\dfrac{13}{20}$.

Javob: $3\dfrac{13}{20}$.

### 18 [A]
$8$ ni $7\dfrac{9}{9}$ deb yozamiz:
$7\dfrac{9}{9} - 4\dfrac{7}{9} = 3\dfrac{2}{9}$.

Javob: $3\dfrac{2}{9}$.

### 19 [A]
Kasr çiziği bölişni bildiradi:
$5 : \dfrac{15}{4} = 5\cdot\dfrac{4}{15} = \dfrac{20}{15} = \dfrac{4}{3} = 1\dfrac{1}{3}$.

Javob: $1\dfrac{1}{3}$.

### 20 [B]
Kasrni songa bölish uçun maxrajni şu songa köpaytiramiz:
$\dfrac{9}{14} : 6 = \dfrac{9}{14\cdot6} = \dfrac{9}{84} = \dfrac{3}{28}$.

Javob: $\dfrac{3}{28}$.
