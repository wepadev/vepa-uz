# 40. Köphadlar

## 1-test

### 1 [C]
Birhad (köphad) da özgaruvçilar faqat natural yoki nol daraja bilan qatnaşadi va maxrajda özgaruvçi bölmaydi.
$\sqrt{a} = a^{\frac{1}{2}}$ köphad emas; $5a^2b^3$ köphad; $\dfrac{7}{4}m^0n^6 = \dfrac{7}{4}n^6$ köphad; $\dfrac{p^5}{q}$ maxrajda özgaruvçi bor, köphad emas.
Demak ikkitasi köphad.

Javob: $2$.

### 2 [A]
Birhad bölişi uçun daraja körsatkiçlari manfiy bölmagan butun son bölişi kerak.
$\dfrac{18}{n}$ butun bölişi uçun $n$ soni $18$ ning böluvçisi: $1, 2, 3, 6, 9, 18$.
$6 - n \ge 0$ şartidan $n \le 6$. Qoladi: $1, 2, 3, 6$.

Javob: $\{1; 2; 3; 6\}$.

### 3 [C]
Darajaning xossalari bilan soddalaştiramiz: $(a^2b^3)^3a = a^6b^9 \cdot a = a^7b^9$.
Birhad darajasi körsatkiçlar yiğindisi: $7 + 9 = 16$.

Javob: $16$.

### 4 [D]
$3^n$ son koeffitsiyent, darajaga qöşilmaydi. Birhad darajasi: $4n + 3$.
$4n + 3 = 31 \Rightarrow 4n = 28 \Rightarrow n = 7$.

Javob: $7$.

### 5 [B]
Köphadda daraja körsatkiçlari manfiy bölmagan butun sonlar bölişi kerak.
$n - 3 \ge 0$ va $5 - n \ge 0$, ya'ni $3 \le n \le 5$.

Javob: $\{3; 4; 5\}$.

### 6 [A]
Köphad darajasi uning hadlari darajalarining eng kattasi.
Hadlar darajalari: $y^8 \to 8$, $4x^5y^2 \to 7$, $-2x^3y^6 \to 9$, $x^2y \to 3$.
Eng kattasi $9$.

Javob: $9$.

### 7 [A]
Köpaytmaning darajasi köpaytuvçilar darajalari yiğindisiga teng.
$2x^5 + x^2 - 3$ ning darajasi $5$, $(x - 1)^3$ niki $3$.
$5 + 3 = 8$.

Javob: $8$.

### 8 [B]
Ozod had $P(0)$ ga teng: köpaytuvçilarning ozod hadlarini köpaytiramiz.
$5 \cdot (-2) = -10$.

Javob: $-10$.

### 9 [D]
Barça koeffitsiyentlar yiğindisi $P(1)$ ga teng.
$P(1) = (2 - 1 - 1)^{15} + 5 + 2 = 0 + 7 = 7$.

Javob: $7$.

### 10 [C]
Juft darajalar oldidagi koeffitsiyentlar yiğindisi $\dfrac{P(1) + P(-1)}{2}$ ga teng.
$P(1) = 81 - 2 + 5 - 3 = 81$, $P(-1) = 1 - 2 - 5 - 3 = -9$.
$\dfrac{81 - 9}{2} = 36$.

Javob: $36$.

### 11 [B]
Juft darajalar koeffitsiyentlari yiğindisi $\dfrac{P(1) + P(-1)}{2}$.
$P(1) = 2 \cdot 5 = 10$, $P(-1) = (1 - 2 - 1)(-1 - 1 + 3) = -2$.
$\dfrac{10 - 2}{2} = 4$.

Javob: $4$.

### 12 [D]
Bezu teoremasi: $P(x)$ ni $x - a$ ga bölgandagi qoldiq $P(a)$ ga teng. Bu yerda $a = -1$.
$P(-1) = -2 - 1 - 4 - 1 = -8$.

Javob: $-8$.

### 13 [A]
Bezu teoremasiga köra qoldiqsiz bölinişi uçun $P(3) = 0$.
$P(3) = 1 + 9 + 3a + 8 = 18 + 3a = 0 \Rightarrow a = -6$.

Javob: $-6$.

### 14 [C]
Ozod had $P(0)$ ga teng.
$P(0) = (-2)^3 + a = a - 8 = 5 \Rightarrow a = 13$.

Javob: $13$.

### 15 [D]
Koeffitsiyentlar yiğindisi $P(1)$.
$P(1) = (1 - a)^3 + 8 = 0 \Rightarrow (1 - a)^3 = -8 \Rightarrow 1 - a = -2 \Rightarrow a = 3$.

Javob: $3$.

### 16 [B]
Bezu teoremasi: qoldiq $P(-3)$.
$P(-3) = -27 + 9 - 3a + 16 = -2 - 3a = 4 \Rightarrow a = -2$.

Javob: $-2$.

### 17 [C]
$P(1)$ barça koeffitsiyentlar yiğindisi, $P(-1)$ esa juft va toq koeffitsiyentlar yiğindilari ayirmasi.
$P(1) = 27 + a + b + 4 = 13 + 15 = 28 \Rightarrow a + b = -3$.
$P(-1) = 1 + a - b + 4 = 13 - 15 = -2 \Rightarrow a - b = -7$.
Bundan $a = -5$, $b = 2$.

Javob: $(-5; 2)$.

### 18 [A]
$x$ örniga $3x - 2$ ni qöyamiz:
$(3x - 2)^2 - 4(3x - 2) + 2 = 9x^2 - 12x + 4 - 12x + 8 + 2 = 9x^2 - 24x + 14$.

Javob: $9x^2 - 24x + 14$.

### 19 [D]
Öng tomon kvadrat bölgani uçun $P(x) = ax^2 + bx + c$ deymiz.
$P(x - 2) + P(x + 1) = a(2x^2 - 2x + 5) + b(2x - 1) + 2c$.
Koeffitsiyentlarni tenglaymiz: $2a = 4 \Rightarrow a = 2$; $-2a + 2b = -6 \Rightarrow b = -1$; $5a - b + 2c = 19 \Rightarrow c = 4$.

Javob: $2x^2 - x + 4$.

### 20 [A]
$Q(x) = (x - 1)(x - 4)$, demak $P(1) = 0$ va $P(4) = 0$.
$P(1) = 13 + a + b = 0 \Rightarrow a + b = -13$.
$P(4) = 76 + 16a + 4b = 0 \Rightarrow 4a + b = -19$.
Ayiramiz: $3a = -6$, $a = -2$, $b = -11$.

Javob: $(-2; -11)$.

## 2-test

### 1 [A]
Köphadda özgaruvçilar faqat manfiy bölmagan butun darajada qatnaşadi.
$x^{2{,}4}$ köphad emas; $-3x^2y$, $\dfrac{1}{5}z^7$ va $t^{12}u^0 = t^{12}$ köphad.
Demak uçtasi.

Javob: $3$.

### 2 [B]
$\dfrac{20}{n}$ butun bölişi uçun $n$ soni $20$ ning böluvçisi: $1, 2, 4, 5, 10, 20$.
$5 - n \ge 0$ şartidan $n \le 5$. Qoladi: $1, 2, 4, 5$.

Javob: $\{1; 2; 4; 5\}$.

### 3 [D]
$(m^4n)^2m^3 = m^8n^2 \cdot m^3 = m^{11}n^2$.
Daraja: $11 + 2 = 13$.

Javob: $13$.

### 4 [A]
$5^n$ koeffitsiyent. Birhad darajasi $5n + 2 = 32 \Rightarrow n = 6$.

Javob: $6$.

### 5 [C]
Daraja körsatkiçlari manfiy bölmasligi kerak: $n - 1 \ge 0$ va $3 - n \ge 0$, ya'ni $1 \le n \le 3$.

Javob: $\{1; 2; 3\}$.

### 6 [D]
Hadlar darajalari: $x^9 \to 9$, $-3x^7y \to 8$, $5x^2y^6 \to 8$, $xy^2 \to 3$.
Köphad darajasi eng kattasi: $9$.

Javob: $9$.

### 7 [C]
Köpaytma darajasi köpaytuvçilar darajalari yiğindisi: $4 + 6 = 10$.

Javob: $10$.

### 8 [C]
Ozod had köpaytuvçilar ozod hadlari köpaytmasi: $(-3) \cdot (-7) = 21$.

Javob: $21$.

### 9 [A]
Koeffitsiyentlar yiğindisi $P(1)$.
$P(1) = (1 - 2 + 2)^9 - 3 + 4 = 1 + 1 = 2$.

Javob: $2$.

### 10 [D]
Juft darajalar koeffitsiyentlari yiğindisi $\dfrac{P(1) + P(-1)}{2}$.
$P(1) = 256 + 1 - 6 + 4 = 255$, $P(-1) = 16 + 1 + 6 + 4 = 27$.
$\dfrac{255 + 27}{2} = 141$.

Javob: $141$.

### 11 [B]
$P(1) = 4 \cdot (-1) = -4$, $P(-1) = (2 + 1 + 3)(-1 + 3 + 1) = 18$.
Juft darajalar koeffitsiyentlari yiğindisi: $\dfrac{-4 + 18}{2} = 7$.

Javob: $7$.

### 12 [B]
Bezu teoremasi: qoldiq $P(1)$.
$P(1) = 1 - 2 + 1 + 6 = 6$.

Javob: $6$.

### 13 [D]
Qoldiqsiz bölinişi uçun $P(4) = 0$.
$P(4) = 1 + 16 + 4a + 11 = 28 + 4a = 0 \Rightarrow a = -7$.

Javob: $-7$.

### 14 [B]
Ozod had $P(0) = 27 + a = 0 \Rightarrow a = -27$.

Javob: $-27$.

### 15 [C]
Koeffitsiyentlar yiğindisi $P(1) = (1 - a)^5 + 1 = 0$.
$(1 - a)^5 = -1 \Rightarrow 1 - a = -1 \Rightarrow a = 2$.

Javob: $2$.

### 16 [A]
Bezu teoremasi: qoldiq $P(-1)$.
$P(-1) = -1 + 4 - a + 1 = 4 - a = -2 \Rightarrow a = 6$.

Javob: $6$.

### 17 [D]
$P(1) = 0 + a + b + 6 = -6 + 13 = 7 \Rightarrow a + b = 1$.
$P(-1) = -32 + a - b + 6 = -6 - 13 = -19 \Rightarrow a - b = 7$.
Bundan $a = 4$, $b = -3$.

Javob: $(4; -3)$.

### 18 [B]
$x$ örniga $x + 4$ ni qöyamiz:
$3(x + 4)^2 + (x + 4) - 1 = 3x^2 + 24x + 48 + x + 3 = 3x^2 + 25x + 51$.

Javob: $3x^2 + 25x + 51$.

### 19 [A]
$P(x) = ax^2 + bx + c$ deymiz: $P(x - 1) + P(x + 3) = a(2x^2 + 4x + 10) + b(2x + 2) + 2c$.
$2a = 6 \Rightarrow a = 3$; $4a + 2b = 16 \Rightarrow b = 2$; $10a + 2b + 2c = 32 \Rightarrow c = -1$.

Javob: $3x^2 + 2x - 1$.

### 20 [C]
$Q(x) = (x + 2)(x + 5)$, demak $P(-2) = 0$, $P(-5) = 0$.
$P(-2) = -28 + 4a - 2b = 0 \Rightarrow 2a - b = 14$.
$P(-5) = -145 + 25a - 5b = 0 \Rightarrow 5a - b = 29$.
Ayiramiz: $3a = 15$, $a = 5$, $b = -4$.

Javob: $(5; -4)$.

## 3-test

### 1 [D]
$4x^{-2}$ manfiy daraja, köphad emas; $x^2y^3z^4$ va $\dfrac{2}{7}a^6$ köphad; $b^{\frac{1}{3}}c^2$ kasr daraja, köphad emas.
Demak ikkitasi.

Javob: $2$.

### 2 [C]
$\dfrac{30}{n}$ butun bölişi uçun $n$ soni $30$ ning böluvçisi: $1, 2, 3, 5, 6, 10, 15, 30$.
$6 - n \ge 0$ şartidan $n \le 6$. Qoladi: $1, 2, 3, 5, 6$.

Javob: $\{1; 2; 3; 5; 6\}$.

### 3 [B]
$(p^2q^2)^4q = p^8q^8 \cdot q = p^8q^9$.
Daraja: $8 + 9 = 17$.

Javob: $17$.

### 4 [A]
$2^n$ koeffitsiyent. Birhad darajasi $2n + 7 = 25 \Rightarrow n = 9$.

Javob: $9$.

### 5 [C]
$n - 4 \ge 0$ va $6 - n \ge 0$, ya'ni $4 \le n \le 6$.

Javob: $\{4; 5; 6\}$.

### 6 [D]
Hadlar darajalari: $2x^4y^5 \to 9$, $-x^6y^3 \to 9$, $3x^2y^8 \to 10$, $xy \to 2$.
Eng kattasi $10$.

Javob: $10$.

### 7 [B]
Köpaytma darajasi: $2 + 7 = 9$.

Javob: $9$.

### 8 [B]
Ozod had: $8 \cdot 3 = 24$.

Javob: $24$.

### 9 [A]
Koeffitsiyentlar yiğindisi $P(1) = (3 - 4 + 1)^{12} + 2 - 5 = 0 - 3 = -3$.

Javob: $-3$.

### 10 [C]
$P(1) = 625 - 3 + 2 - 5 = 619$, $P(-1) = 1 - 3 - 2 - 5 = -9$.
Juft darajalar koeffitsiyentlari yiğindisi: $\dfrac{619 - 9}{2} = 305$.

Javob: $305$.

### 11 [A]
$P(1) = (-1) \cdot 4 = -4$, $P(-1) = (1 + 4 + 2)(-2 - 1 + 1) = -14$.
Juft darajalar koeffitsiyentlari yiğindisi: $\dfrac{-4 - 14}{2} = -9$.

Javob: $-9$.

### 12 [D]
Bezu teoremasi: qoldiq $P(3)$.
$P(3) = 81 + 18 - 3 + 4 = 100$.

Javob: $100$.

### 13 [C]
Qoldiqsiz bölinişi uçun $P(5) = 0$.
$P(5) = 8 + 25 + 5a + 7 = 40 + 5a = 0 \Rightarrow a = -8$.

Javob: $-8$.

### 14 [A]
Ozod had $P(0) = 1 + a = -4 \Rightarrow a = -5$.

Javob: $-5$.

### 15 [C]
$P(1) = (1 - a)^3 + 1 - 28 = 0 \Rightarrow (1 - a)^3 = 27 \Rightarrow 1 - a = 3 \Rightarrow a = -2$.

Javob: $-2$.

### 16 [D]
Bezu teoremasi: qoldiq $P(-4)$.
$P(-4) = -64 + 32 - 4a + 49 = 17 - 4a = 5 \Rightarrow a = 3$.

Javob: $3$.

### 17 [B]
$P(1) = 256 + a + b - 2 = 140 + 125 = 265 \Rightarrow a + b = 11$.
$P(-1) = 16 + a - b - 2 = 140 - 125 = 15 \Rightarrow a - b = 1$.
Bundan $a = 6$, $b = 5$.

Javob: $(6; 5)$.

### 18 [A]
$x$ örniga $2x - 3$ ni qöyamiz:
$2(2x - 3)^2 - 5(2x - 3) + 3 = 8x^2 - 24x + 18 - 10x + 15 + 3 = 8x^2 - 34x + 36$.

Javob: $8x^2 - 34x + 36$.

### 19 [D]
$P(x) = ax^2 + bx + c$: $P(x - 3) + P(x + 2) = a(2x^2 - 2x + 13) + b(2x - 1) + 2c$.
$2a = 2 \Rightarrow a = 1$; $-2a + 2b = -8 \Rightarrow b = -3$; $13a - b + 2c = 26 \Rightarrow c = 5$.

Javob: $x^2 - 3x + 5$.

### 20 [D]
$Q(x) = (x - 3)(x + 4)$, demak $P(3) = 0$, $P(-4) = 0$.
$P(3) = -33 + 9a + 3b = 0 \Rightarrow 3a + b = 11$.
$P(-4) = -124 + 16a - 4b = 0 \Rightarrow 4a - b = 31$.
Qöşamiz: $7a = 42$, $a = 6$, $b = -7$.

Javob: $(6; -7)$.
